# Test-NameResolution（名前解決確認）

指定した名前について、hosts・DNS サーバー・OS の結果を別々に調べて突き合わせ、どこで引けているか、食い違いがないかを一覧にします。結果は画面に表示し、CSV にも保存します。

「名前でつながらない」「違うサーバーにつながる」というときに、hosts・DNS・キャッシュのどこが原因かを切り分けるための道具です。サーバーの移行で DNS を切り替えた後に、新しい IP アドレスになったかを確かめることもできます。hosts や DNS のキャッシュを変更することはありません。

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Test-NameResolution.ps1 -Target "web01.example.local,db01.example.local"
```

調べたい PC やサーバーの上で実行してください。結果は、その PC から見たものです。

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# 対象のひな形（names.csv）を作る
powershell -ExecutionPolicy Bypass -File .\Test-NameResolution.ps1 -NewList .\names.csv

# CSV に書いた名前を調べる
powershell -ExecutionPolicy Bypass -File .\Test-NameResolution.ps1 -List .\names.csv

# 切り替え後の IP アドレスになっているかを確かめる
powershell -ExecutionPolicy Bypass -File .\Test-NameResolution.ps1 -Target "web01.example.local=10.0.2.10"

# 指定した DNS サーバーに聞く（OS の設定の DNS サーバーには聞かない）
powershell -ExecutionPolicy Bypass -File .\Test-NameResolution.ps1 -Target web01.example.local -Server "10.0.2.53,10.0.2.54"

# hosts に書かれた名前をすべて調べて、DNS と比べる
powershell -ExecutionPolicy Bypass -File .\Test-NameResolution.ps1 -Hosts

# 逆引き（IP アドレスから名前）も確かめる
powershell -ExecutionPolicy Bypass -File .\Test-NameResolution.ps1 -List .\names.csv -Reverse

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Test-NameResolution.ps1 -Target web01.example.local -NoSave
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Target` | 調べる名前。カンマで区切って複数指定できます。`名前=IP アドレス` の形で、[期待する IP アドレス](#期待する-ip-アドレス)を書けます。IP アドレスを書くと、逆引きを調べます | 指定なし |
| `-List` | 対象を書いた CSV ファイル（[対象の書き方](#対象の書き方)を参照） | 指定なし |
| `-Hosts` | hosts に書かれた名前をすべて調べます | なし |
| `-NewList` | 対象のひな形の CSV を作って終わります。同じ名前のファイルがあるときは、上書きせずに止まります | 指定なし |
| `-Server` | 聞く DNS サーバーの IP アドレス。カンマで区切って複数指定できます。指定すると、OS の設定の DNS サーバーには聞きません | OS の設定のすべての DNS サーバー |
| `-Reverse` | 得られた IP アドレスの逆引きも調べます（[逆引き](#逆引き)を参照） | なし |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします | なし |
| `-ConfigFile` | 設定ファイルのパス（[設定ファイル](#設定ファイル)を参照）。コマンドラインで指定した値は、設定ファイルより優先します | 指定なし |

`-Target`、`-List`、`-Hosts` は、一緒に指定できます。同じ名前は 1 回だけ調べます。

## 対象の書き方

Excel やメモ帳で、次のような CSV を作ります。`-NewList` で作ったひな形を書き換えると簡単です。

```csv
名前,期待する IP,メモ
# 先頭が # の行は調べません,,
web01.example.local,10.0.2.10,切り替え後の Web サーバー
db01.example.local,,データベース
mail.example.local,10.0.2.25;10.0.2.26,メールサーバー（2 台）
```

- 1 行目は見出しです。`名前` の列は必須、`期待する IP` と `メモ` の列は省略できます。英語の見出し（`Name`、`Expected`、`Memo`）でもかまいません
- 名前には、コンピューター名・FQDN・IP アドレスを書けます
- 期待する IP アドレスが複数あるときは、`;` で区切ります
- 名前が空の行と、名前が `#` で始まる行は飛ばします
- そのほかの書き方と、書き間違いがあったときの動きは、[Test-Connectivity の CSV ファイル](../Test-Connectivity/README.md#csv-ファイル-list)と同じです。間違いがあると、調べ始める前に、何行目かを表示して止まります

## 設定ファイル

同じ条件で繰り返し調べるときは、パラメーターを設定ファイルにまとめておけます。設定ファイルを使わなくても、パラメーターだけで動きます。

```ini
# Test-NameResolution の設定ファイル
# 「項目 = 値」の形で、1 行に 1 つずつ書きます。# か ; で始まる行はコメントです

# Target と Server は、複数の行に分けて書けます
Target = web01.example.local=10.0.2.10
Target = db01.example.local
List = .\names.csv
Hosts = false
Server = 10.0.2.53
Reverse = true
OutputFolder = .\記録
NoSave = false
```

- 書ける項目は、`Target`、`List`、`Hosts`、`Server`、`Reverse`、`OutputFolder`、`NoSave` です。`NewList` は書けません
- `Hosts`、`Reverse`、`NoSave` は `true` か `false` で書きます
- コマンドラインで `-Target`、`-Server` を指定すると、設定ファイルの同じ項目は使いません（両方を合わせることはしません）
- 設定ファイルで `true` にした `Hosts`、`Reverse`、`NoSave` は、コマンドラインから取り消せません。元に戻したいときは、設定ファイルを直してください
- そのほかの書き方（空の値、引用符、コメント、環境変数、相対パス、文字コード）と、書き間違いがあったときの動きは、[Get-DiskUsage の設定ファイル](../Get-DiskUsage/README.md#設定ファイル)と同じです

## 調べ方と判定

名前ごとに、次の 3 つを別々に調べて突き合わせます。

| 調べるもの | 分かること |
| --- | --- |
| hosts | hosts に書かれている IP アドレスと、何行目か。hosts の場所は OS の設定（通常は `C:\Windows\System32\drivers\etc\hosts`）に従います |
| DNS サーバー | DNS サーバーの今の答え。hosts とキャッシュを使わずに、サーバーごとに聞きます |
| OS の結果 | アプリが実際に受け取る IP アドレス。hosts とキャッシュを含みます |

### 引けた元

| 値 | 条件 |
| --- | --- |
| hosts | hosts に書かれている（Windows は DNS より hosts を優先します） |
| DNS | hosts にはなく、DNS サーバーが答えた |
| その他 | hosts にも DNS にもないが、OS は解決できた（NetBIOS、LLMNR など） |
| IP アドレス | 対象に IP アドレスを書いた |
| `-` | どこでも引けない |

### 判定

| 判定 | 条件 |
| --- | --- |
| OK | OS が解決でき、次の「注意」に当てはまらない |
| 注意 | 下の表のどれかに当てはまる |
| 引けない | OS が解決できない |

| 「注意」になるとき | 備考の表示 |
| --- | --- |
| hosts と DNS の答えが違う | hosts と DNS が違う（hosts の 12 行目） |
| hosts に同じ名前が複数の IP アドレスで書かれている | hosts に同じ名前が複数ある（12 行目と 30 行目） |
| hosts になく、OS の結果が DNS の答えと違う | キャッシュが古い可能性（ipconfig /flushdns で確かめてください） |
| DNS サーバーによって答えが違う | DNS サーバーによって答えが違う |
| 応答しない DNS サーバーがある | DNS サーバー 10.0.0.54 が応答しない |
| OS の結果か DNS の答えが、期待する IP アドレスと違う | 期待する IP アドレスと違う（DNS サーバー 10.0.0.53） |
| 逆引きの名前が違う（`-Reverse` のとき） | 逆引きの名前が違う（10.0.1.20 → other.example.local） |

- **IPv4 と IPv6**：A と AAAA の両方を調べます。hosts と DNS を比べるときは、hosts に書かれた種類（IPv4 か IPv6）だけを比べます。IPv4 だけの hosts と、両方を答える DNS は、「違う」としません
- **複数の IP アドレス**：順番は比べません（DNS ラウンドロビンで順番が変わるため）
- **hosts にだけある名前**：意図して書くことが多いので OK とし、備考に「DNS にはない」と書きます
- **短い名前**：`web01` のようにドットのない名前は、OS の DNS サフィックスを順に付けて DNS サーバーに聞きます。実際に引けた名前を「解決した名前」の列に書きます。hosts は、書かれている名前と完全に一致するものだけを見ます
- **hosts の名前の比べ方**：大文字と小文字は区別しません。hosts の行の `#` より後ろはコメントとして読みます
- 応答しない DNS サーバーは、連続して 3 回応答しなければ、その後は聞きません。残りの名前の備考には「応答しないので聞いていない」と書きます

### 期待する IP アドレス

CSV の `期待する IP` の列か、`-Target` の `名前=IP アドレス` の形で書きます。

- OS の結果と、それぞれの DNS サーバーの答えの両方と比べます
- 期待する IP アドレスがすべて含まれていて、期待していない同じ種類（IPv4 か IPv6）の IP アドレスがなければ、一致とします
- hosts が DNS と違っていて、hosts の値が期待どおりのときも、DNS の答えが期待と違うので「注意」です

### 逆引き

`-Reverse` を指定すると、OS の結果の IP アドレスごとに、DNS サーバーへ逆引き（PTR）を聞きます。対象に IP アドレスを書いたときは、指定しなくても調べます。

| 結果 | 意味 | 判定 |
| --- | --- | --- |
| 一致 | 逆引きの名前が、解決した名前と同じ（大文字と小文字は区別しません） | そのまま |
| 違う | 逆引きの名前が、解決した名前と違う | 注意 |
| なし | 逆引きが登録されていない | そのまま（登録しない運用も多いため、備考に書くだけです） |

短い名前で調べたときは、解決した名前と比べます。ロードバランサーなど、正引きと逆引きがもともと一致しない構成では「違う」と出ます。

### -Hosts のとき

hosts に書かれた名前をすべて対象にします。作業のときに書いたまま忘れられた行を探すのに使えます。`localhost` と `127.0.0.1`、`::1` の行は対象にしません。DNS と違うものは「注意」に、DNS にないものは OK で備考に「DNS にはない」と出ます。

## 画面の表示例

```
名前解決確認 (Test-NameResolution 1.0.0)
2026-11-02 22:40:10   PC01（管理者: いいえ）
対象 4 件   DNS サーバー: 10.0.0.53, 10.0.0.54（OS の設定）
hosts: C:\Windows\System32\drivers\etc\hosts（有効な行 2 件）

 判定      名前                 引けた元  OS の結果  DNS の結果  備考
 OK        web01.example.local  DNS       10.0.1.10  10.0.1.10
 注意      db01.example.local   hosts     10.0.9.99  10.0.1.20   hosts と DNS が違う（hosts の 12 行目）
 注意      app01.example.local  DNS       10.0.1.30  10.0.1.31   キャッシュが古い可能性（ipconfig /flushdns で確かめてください）
 引けない  old01.example.local  -         -          -           DNS: 名前が存在しない

結果: OK 1 件  注意 2 件  引けない 1 件  所要 0.4秒
保存先: C:\tools\NameResolution_PC01_20261102_224010
```

表示の決まりは次のとおりです。

- 対象の順に表示します。「注意」は黄色、「引けない」は赤で表示します
- DNS の結果は、すべてのサーバーの答えが同じならその値を、違うときは「サーバーで違う」と表示します。サーバーごとの答えは `results.csv` に書きます
- IP アドレスが複数あるときは、`, ` でつなぎます
- 表は 200 件までです。超えた分は「（ほか 1,234 件は results.csv を参照してください）」と表示します。`-NoSave` のときと、保存できなかったときは、すべて表示します
- 調べている間は、進み具合を表示します
- 条件によって、次の行も表示します
  - `-ConfigFile` を指定したとき：「設定ファイル: C:\tools\monthly.ini」
  - `-Server` を指定したとき：「DNS サーバー: 10.0.2.53（指定）」
  - hosts を読めなかったとき：「※ hosts を読めなかったため、hosts なしとして調べました（理由）」
  - OS に DNS サーバーが設定されていないとき：「※ DNS サーバーが設定されていません」

## 保存されるファイル

実行するたびに、保存先に `NameResolution_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容。200 件を超えても省略しません |
| `results.csv` | すべての名前の結果（対象の順） |

CSV は BOM 付き UTF-8 で保存するため、Excel でダブルクリックすればそのまま開けます。保存先に書き込めないときは警告を表示し、画面表示だけで終了します。

### CSV の列

判定、名前、引けた元、OS の結果、hosts の値、hosts の行番号、DNS の結果、解決した名前、CNAME、TTL、期待する IP、逆引き、メモ、備考

- DNS の結果は、`10.0.0.53: 10.0.1.10 / 10.0.0.54: 10.0.1.20` のように、サーバーごとに書きます。答えがないときは `10.0.0.53: 名前が存在しない`、応答しないときは `10.0.0.54: 応答なし` と書きます
- CNAME は、別名をたどったときの途中の名前を ` → ` でつないで書きます
- TTL は、答えの中で一番短いものの秒数です。3 桁区切りで書きます
- 逆引きは、`10.0.1.10: 一致` のように IP アドレスごとに書きます。`-Reverse` を指定せず、対象も IP アドレスでないときは空欄です
- 名前やメモのうち、Excel で数値・日付・数式に変わるものは、`="..."` の形で書きます

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | すべて OK だった |
| 2 | 「注意」か「引けない」があった |
| 1 | 引数の誤りなどで、調べる前に止まった |

バッチファイルやタスクスケジューラから、「切り替えが終わったかを確かめる」といった判定に使えます。保存の失敗は、終了コードに影響しません。

## 止まるとき

次の場合は、調べ始める前にエラーを表示して止まります（終了コード 1）。

| 場合 | 表示の例 |
| --- | --- |
| 対象を指定していない | 「調べる名前を指定してください（-Target、-List、-Hosts のどれかで指定します）」 |
| `-NewList` のファイルがすでにある | 「同じ名前のファイルがあります: C:\tools\names.csv」 |
| 対象の CSV を読めない、書き間違いがある | 何行目かを表示します（Test-Connectivity と同じ） |
| 期待する IP アドレスや `-Server` が IP アドレスでない | 「-Server は IP アドレスで指定してください: dns01」 |
| 調べる対象が 1 件もない（`-Hosts` で hosts に名前がないときなど） | 「調べる対象がありません」 |
| `Resolve-DnsName` を使えない環境 | 「Resolve-DnsName を使えないため、調べられません（理由）」 |
| 値に `"` が残っている（コマンドプロンプトで `"C:\data\"` のように最後を `\"` にした） | 「-List の値に引用符（"）が残っています: …」と、正しい書き方 |
| 設定ファイルの書き間違い | 何行目かを表示します（Get-DiskUsage と同じ） |

## 使うときの注意

- **結果は、実行した PC から見たものです。**別の PC や、VPN の内と外では、答えが変わることがあります
- **VPN や複数のネットワークにつないでいるとき**は、それぞれの DNS サーバーで答えが違うのが普通のことがあります。「DNS サーバーによって答えが違う」と出たら、`-Server` で確かめたいサーバーだけに聞いてください
- **地域や負荷で答えを変える DNS**（CDN、GSLB など）は、聞くたびに答えが変わり、「注意」と出ることがあります
- **名前解決ポリシー（NRPT）や、DoH などで特定の名前の聞き先を変えている環境**では、OS の結果が DNS サーバーの答えと違うことがあります
- **ブラウザーやアプリのキャッシュ、プロキシ**は調べません。「ブラウザーでだけ違うサーバーにつながる」というときは、このツールでは分かりません
- **DNS のキャッシュは消しません。**「キャッシュが古い可能性」と出たら、確かめたうえで `ipconfig /flushdns` を実行してください
- **hosts を変更しません。**古い行を見つけたら、確かめたうえで手で直してください
- **つながるかどうかは調べません。**ping やポートへの接続は、[Test-Connectivity](../Test-Connectivity/README.md) で確かめてください

## 動作環境

[リポジトリの README の「システム要件」](../../README.md#システム要件)を参照してください。管理者権限は不要です。OS に標準で入っている `Resolve-DnsName` を使います。DNS サーバーへの問い合わせのため、ネットワークに接続します（UDP / TCP の 53 番）。
