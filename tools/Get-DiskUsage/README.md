# Get-DiskUsage（容量検索）

指定したフォルダの中で、容量を多く使っているフォルダ・ファイル・拡張子を洗い出します。結果は画面に表示し、CSV にも保存します。

「サーバーの C ドライブがいっぱいになったが、何が容量を使っているのか分からない」というときの調査用です。調べる場所のファイルを変更・削除することはありません。

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Get-DiskUsage.ps1 -Path C:\
```

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# 4 階層までのフォルダを、上位 50 件まで表示する
powershell -ExecutionPolicy Bypass -File .\Get-DiskUsage.ps1 -Path D:\data -Depth 4 -Top 50

# 最終更新から 90 日以上たったファイルだけで集計する（削除候補を探す）
powershell -ExecutionPolicy Bypass -File .\Get-DiskUsage.ps1 -Path D:\logs -OlderThan 90

# 一部のフォルダを調べない
powershell -ExecutionPolicy Bypass -File .\Get-DiskUsage.ps1 -Path C:\ -Exclude "C:\Windows,*\node_modules"

# 結果を指定したフォルダに保存する
powershell -ExecutionPolicy Bypass -File .\Get-DiskUsage.ps1 -Path C:\ -OutputFolder D:\report

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Get-DiskUsage.ps1 -Path C:\ -NoCsv
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Path` | 調べるフォルダ。ドライブ（`C:\`）や共有フォルダ（`\\server\share`）も指定できます | 現在のフォルダ |
| `-Depth` | フォルダの順位に含める階層の深さ。`-Path` の直下が 1 です。集計そのものは常に全階層が対象です | 3 |
| `-Top` | 画面に表示する件数。フォルダ・ファイル・拡張子それぞれに適用します | 20 |
| `-OlderThan` | 最終更新から指定した日数以上たったファイルだけで集計します。フォルダ・ファイル・拡張子のすべての集計が対象です | 指定なし（すべてのファイル） |
| `-Exclude` | 調べないフォルダ。フォルダのフルパスに対して、ワイルドカード（`*`）で指定します。`*` 以外の文字（`[` `]` など）は、そのままの文字として扱います。大文字と小文字は区別しません。複数指定するときは、`"C:\Windows,*\node_modules"` のようにカンマで区切って1つの文字列にします | 指定なし |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoCsv` | 結果を保存せず、画面表示だけにします | なし |

条件によって、次の行も表示します。

- `-OlderThan` を指定したとき：「条件: 最終更新が 90 日以上前のファイルのみ（2026-07-31 21:30 より前）」
- `-Exclude` を指定したとき：「除外: C:\Windows, *\node_modules」。除外したフォルダがあれば、スキップの行に「除外したフォルダ 3 件」
- 権限なし以外のエラーでも読めなかった場所があったとき：スキップの行が「スキップ 37 件（権限なし 35・その他のエラー 2）」
- 管理者として実行しておらず、読めない場所があったとき：「※ 管理者として実行すると、読める範囲が広がります」

## 保存されるファイル

実行するたびに、保存先に `DiskUsage_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容（実行条件・ドライブの使用量・集計結果） |
| `folders.csv` | `-Depth` までのすべてのフォルダ（合計サイズの大きい順） |
| `files.csv` | 大きいファイルの上位 1,000 件 |
| `extensions.csv` | すべての拡張子ごとの合計 |
| `skipped.csv` | 調べられなかった場所・調べなかった場所と、その理由 |

CSV は BOM 付き UTF-8 で保存するため、Excel でダブルクリックすればそのまま開けます。保存先に書き込めないときは警告を表示し、画面表示だけで終了します。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `folders.csv` | 順位、フォルダ、階層、サイズ(MB)、サイズ(バイト)、ファイル数 |
| `files.csv` | 順位、ファイル、サイズ(MB)、サイズ(バイト)、最終更新日時、拡張子 |
| `extensions.csv` | 順位、拡張子、サイズ(MB)、サイズ(バイト)、ファイル数 |
| `skipped.csv` | 理由、パス、詳細 |

サイズとファイル数は、`156,723,000,000` のように 3 桁区切りで出力します。Excel では桁区切り付きの数値として読み込まれるため、12 桁を超えるサイズも指数表示（`1.56723E+11`）にならず、全桁を表示できます。

`.1` や `.001` のように数字だけの拡張子（ローテートしたログや分割したアーカイブなど）は、Excel で数値に変わらないように `=".1"` の形で出力します。Excel では `.1` と表示されます。

`skipped.csv` の理由は、「権限なし」「リンク」「除外指定」「その他のエラー」のいずれかです。

## 集計のルール

- 隠しファイルとシステムファイルも含めます
- ジャンクションやシンボリックリンクはたどりません。無限ループや二重カウントを防ぐためです
- 権限がなくて読めないフォルダはスキップし、件数を表示します。管理者として実行すると、読める範囲が広がります
- 260 文字を超える長いパスも集計します
- 途中で中断（Ctrl+C）した場合は、結果を保存しません

### 実際のディスク使用量とずれるケース

サイズは「ファイルのサイズ」（エクスプローラーのプロパティに表示される「サイズ」）で数えます。そのため、次のような場合はドライブの使用量と一致しません。

- **圧縮されたファイル・スパースファイル**：実際のディスク使用量より大きく出ます
- **OneDrive などのオンライン専用ファイル**：ディスクを使っていなくても、サイズに含まれます
- **ハードリンク**：同じファイルが複数の場所で数えられます。特に `C:\Windows\WinSxS` は実際より大きく見えます
- **小さなファイルが多い場合**：ディスク上の割り当て単位（クラスター）の余りを含まないため、実際より小さく出ます

## 共有フォルダを調べるとき

- `-Path \\サーバー名\共有名` の形で指定してください
- ネットワークドライブ（`Z:\` など）も指定できます。ただし、管理者として開いた PowerShell からは、通常の権限で割り当てたネットワークドライブが見えません。その場合は `\\サーバー名\共有名` の形で指定してください
- 実行したユーザーの権限で読みます。共有のアクセス許可とフォルダのアクセス許可の両方で読める場所だけを集計し、読めない場所はスキップします
- ネットワーク越しにフォルダを1つずつ読むため、ローカルのフォルダより大幅に時間がかかります。ファイルサーバーにログオンできる場合は、サーバー上でローカルのパス（`D:\share` など）を指定して実行するほうが速く終わります
- 画面の「ドライブ」の行には、共有が置かれているドライブの使用量を表示します。取得できない場合は表示しません
