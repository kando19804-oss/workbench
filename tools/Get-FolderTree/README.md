# Get-FolderTree（フォルダツリー出力）

指定したフォルダの構成を、罫線を使ったツリー形式のテキストで出力します。結果は画面に表示し、ファイルにも保存します。

「設計書や手順書、引き継ぎ資料にフォルダ構成を貼りたい」というときのための道具です。Windows 標準の `tree` コマンドと違い、階層の深さを指定したり、不要なフォルダを除外したり、フォルダの合計サイズを添えたりできます。調べる場所のファイルを変更・削除することはありません。

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Get-FolderTree.ps1 -Path D:\project
```

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# 2 階層までのフォルダを出力する
powershell -ExecutionPolicy Bypass -File .\Get-FolderTree.ps1 -Path D:\project -Depth 2

# ファイルも出力する
powershell -ExecutionPolicy Bypass -File .\Get-FolderTree.ps1 -Path D:\project -Files

# フォルダの合計サイズとファイル数、ファイルのサイズと最終更新日時を添える
powershell -ExecutionPolicy Bypass -File .\Get-FolderTree.ps1 -Path D:\project -Files -Detail

# 一部のフォルダを出力しない
powershell -ExecutionPolicy Bypass -File .\Get-FolderTree.ps1 -Path D:\project -Exclude "*\.git,*\node_modules"

# 罫線の代わりに ASCII 文字で描く（メール本文などで罫線が崩れるとき）
powershell -ExecutionPolicy Bypass -File .\Get-FolderTree.ps1 -Path D:\project -Ascii

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Get-FolderTree.ps1 -Path D:\project -NoSave

# 設定ファイルに書いた条件で出力する
powershell -ExecutionPolicy Bypass -File .\Get-FolderTree.ps1 -ConfigFile .\project.ini
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Path` | 調べるフォルダ。ドライブ（`C:\`）や共有フォルダ（`\\server\share`）も指定できます | 現在のフォルダ |
| `-Depth` | 出力する階層の深さ。`-Path` の直下が 1 です。1～100 で指定します | 3 |
| `-Files` | フォルダに加えて、ファイルも出力します | なし（フォルダのみ） |
| `-Hidden` | 隠し属性またはシステム属性の付いたフォルダ・ファイルも出力します | なし |
| `-Detail` | フォルダに合計サイズとファイル数を、ファイルにサイズと最終更新日時を添えます。合計は `-Depth` より下の階層も含めて数えるため、全階層を読みます | なし |
| `-Exclude` | 出力しないフォルダ。フォルダのフルパスに対して、ワイルドカード（`*`）で指定します。`*` 以外の文字（`[` `]` など）は、そのままの文字として扱います。大文字と小文字は区別しません。複数指定するときは、`"*\.git,*\node_modules"` のようにカンマで区切って1つの文字列にします | 指定なし |
| `-Ascii` | 罫線（`├─` `└─` `│`）の代わりに、ASCII 文字（`+--` `\--` `\|`）で描きます | なし（罫線） |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします | なし |
| `-ConfigFile` | 設定ファイルのパス。ここまでのパラメーターを、ファイルにまとめて書いておけます（[設定ファイル](#設定ファイル)を参照）。コマンドラインで指定した値は、設定ファイルより優先します | 指定なし |

## 設定ファイル

同じ条件で繰り返し出力するときは、パラメーターを設定ファイルにまとめておけます。設定ファイルを使わなくても、パラメーターだけで動きます。

```powershell
powershell -ExecutionPolicy Bypass -File .\Get-FolderTree.ps1 -ConfigFile .\project.ini
```

設定ファイルは、`-ConfigFile` で指定したときだけ読みます。スクリプトと同じフォルダに置いても、自動では読みません。

### 書き方

メモ帳などで次のように書いて保存します。ファイル名と拡張子は自由です。

```ini
# Get-FolderTree の設定ファイル
# 「項目 = 値」の形で、1 行に 1 つずつ書きます。# か ; で始まる行はコメントです
# 書かなかった項目は、既定値で動きます

Path = D:\project
Depth = 4
Files = true
Hidden = false
Detail = false

# Exclude は、複数の行に分けて書けます（すべての行を合わせて使います）
Exclude = *\.git
Exclude = *\node_modules

Ascii = false
OutputFolder = \\fileserver\docs\tree
NoSave = false
```

- 項目の名前は、パラメーターの名前から `-` を除いたものです（`Path`、`Depth`、`Files`、`Hidden`、`Detail`、`Exclude`、`Ascii`、`OutputFolder`、`NoSave`）。大文字と小文字は区別しません。値の意味と範囲は、パラメーターと同じです
- `Files`、`Hidden`、`Detail`、`Ascii`、`NoSave` は `true` か `false` で書きます
- そのほかの書き方（空の値、引用符、コメント、環境変数、相対パス、文字コード）と、書き間違いがあったときの動きは、[Get-DiskUsage の設定ファイル](../Get-DiskUsage/README.md#設定ファイル)と同じです

### コマンドラインと一緒に使うとき

コマンドラインで指定した値が、設定ファイルより優先します。

- コマンドラインで `-Exclude` を指定すると、設定ファイルの `Exclude` は使いません（両方を合わせることはしません）
- 設定ファイルで `true` にした `Files`、`Hidden`、`Detail`、`Ascii`、`NoSave` は、コマンドラインから取り消せません。元に戻したいときは、設定ファイルを直してください（`powershell -File` で起動すると `-Files:$false` の書き方が使えないためです）

## 画面の表示例

```
フォルダツリー出力 (Get-FolderTree 1.0.0)
対象: D:\project   2026-10-31 13:05:12   SERVER01
条件: 3 階層まで・フォルダのみ
除外: *\.git
フォルダ 42 件  所要 0.4秒
スキップ 1 件（権限なし）  たどらなかったリンク 1 件  除外したフォルダ 1 件

D:\project
├─doc
│  ├─手順
│  └─設計
├─secret  [権限なし]
├─src
│  ├─app
│  │  └─…
│  └─lib
└─tools  [リンク]

保存先: C:\tools\FolderTree_SERVER01_20261031_130512
```

`-Files -Detail` を指定したときは、次のように表示します。

```
D:\project  (1.8 GB・1,204 ファイル)
├─doc  (1.2 GB・312 ファイル)
│  ├─手順  (24.5 MB・18 ファイル)
│  │  └─作業手順書.docx  (1.1 MB・2026-10-30 18:22)
│  └─設計  (1.1 GB・290 ファイル)
│      └─…
└─README.md  (4.0 KB・2026-10-29 09:15)
```

`-Ascii` を指定したときは、次のように描きます。

```
D:\project
+-- doc
|   +-- 手順
|   \-- 設計
\-- src
```

表示の決まりは次のとおりです。

- `…` は、`-Depth` より下の階層にもフォルダ（`-Files` のときはファイルも）があることを表します
- `[権限なし]` は、権限がなくて中を読めなかったフォルダです。`[リンク]` は、たどらなかったジャンクションやシンボリックリンクです。`[エラー]` は、そのほかの理由で読めなかったフォルダです
- 画面に表示するツリーは 500 行までです。超えた分は「（ほか 1,234 行は tree.txt を参照してください）」と表示します。保存するファイルには、すべての行を書きます。`-NoSave` を指定したときは、ほかに見る場所がないため、すべての行を画面に表示します
- 条件によって、ヘッダーに次の行も表示します
  - `-ConfigFile` を指定したとき：「対象」の次の行に「設定ファイル: D:\tools\project.ini」
  - `-Files` を指定したとき：「フォルダ 42 件  ファイル 315 件」
  - `-Hidden` を指定したとき：「条件: 3 階層まで・フォルダのみ・隠し項目を含む」
  - 権限なし以外のエラーでも読めなかった場所があったとき：スキップの行が「スキップ 3 件（権限なし 2・その他のエラー 1）」
  - 管理者として実行しておらず、読めない場所があったとき：「※ 管理者として実行すると、読める範囲が広がります」

## 保存されるファイル

実行するたびに、保存先に `FolderTree_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `tree.txt` | ツリーだけ（ヘッダーを含めない）。設計書などにそのまま貼れます |
| `summary.txt` | 画面に表示した内容（実行条件・件数・ツリー）。ツリーは 500 行を超えても省略しません |
| `items.csv` | ツリーに出力したフォルダ・ファイルの一覧（ツリーと同じ順） |
| `skipped.csv` | 調べられなかった場所・調べなかった場所と、その理由 |

テキストと CSV は BOM 付き UTF-8 で保存します。メモ帳や Excel でそのまま開けます。保存先に書き込めないときは警告を表示し、画面表示だけで終了します。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `items.csv` | 種類、パス、名前、階層、サイズ(MB)、サイズ(バイト)、ファイル数、最終更新日時、状態 |
| `skipped.csv` | 理由、パス、詳細 |

- 種類は「フォルダ」か「ファイル」です。状態は空欄か「権限なし」「リンク」「エラー」です
- サイズとファイル数は、フォルダは `-Detail` を指定したとき、ファイルは常に出力します。3 桁区切りで出力します
- フォルダの最終更新日時は出力しません（中のファイルを変更しても更新されず、誤解を招くためです）
- `skipped.csv` の理由は、「権限なし」「リンク」「除外指定」「その他のエラー」のいずれかです

## 出力のルール

- 同じ階層では、フォルダを先に、ファイルを後に並べます。それぞれ名前の順で、エクスプローラーと同じく、名前の中の数字は数値として比べます（`file2` が `file10` より先）。大文字と小文字は区別しません
- 隠し属性またはシステム属性の付いたフォルダ・ファイルは、`-Hidden` を指定したときだけ出力します。指定しないときは、`-Detail` の合計にも含めません（ツリーに見えているものだけで合計するためです）。Git の `.git` フォルダも、Windows では隠し属性が付いています
- ジャンクションやシンボリックリンクはたどりません。無限ループや二重カウントを防ぐためです。`-Hidden` を指定しないと、Windows の互換用リンク（`Application Data` など）は表示しません
- `-Exclude` で除外したフォルダは、ツリーに表示しません。`-Detail` の合計にも含めません
- 権限がなくて読めないフォルダはスキップし、ツリーに `[権限なし]` と表示して件数を数えます
- 260 文字を超える長いパスや、名前に `[` `]` を含むフォルダも出力します
- 途中で中断（Ctrl+C）した場合は、結果を保存しません
- `-Detail` のサイズは「ファイルのサイズ」で数えます。圧縮ファイルやハードリンクなどでドライブの使用量とずれる点は、[Get-DiskUsage](../Get-DiskUsage/README.md#実際のディスク使用量とずれるケース) と同じです

## 罫線が崩れるとき

ツリーの罫線（`├─` `└─` `│`）は、Windows の `tree` コマンドと同じく、罫線を全角の幅で表示する環境で縦にそろうように描きます。

- Word や Excel に貼るとき：フォントを「ＭＳ ゴシック」にしてください。游ゴシックなど文字ごとに幅が違うフォントでは、縦の線がずれます
- Windows Terminal、VS Code、GitHub など、罫線を半角の幅で表示する環境では、縦の線がずれます。`-Ascii` を指定してください
- メール本文や、罫線を表示できない環境に貼るときも、`-Ascii` を指定してください。`-Ascii` は、等幅のフォントならどこでもそろいます

フォルダ名に全角文字と半角文字が混ざっていても、罫線は名前の左側にあるため崩れません。

## 共有フォルダを調べるとき

- `-Path \\サーバー名\共有名` の形で指定してください
- 実行したユーザーの権限で読みます。読めない場所はスキップします
- `-Detail` を指定すると全階層を読むため、ネットワーク越しでは時間がかかります
