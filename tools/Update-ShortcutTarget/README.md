# Update-ShortcutTarget（ショートカットのリンク先置き換え）

ショートカット（`.lnk`）のリンク先にある共有フォルダのサーバーを、まとめて置き換えます。置き換える前に予定を表示して確認を求め、元のファイルは結果のフォルダに控えます。

「ファイルサーバーを移したら、`\\192.168.1.10\営業` を指すデスクトップのショートカットが全部開けなくなった」「サーバーの IP アドレスが変わるので、利用者のショートカットを付け替えたい」というときのための道具です。移す前に、どのショートカットがどのサーバーを指しているかを調べる（棚卸し）こともできます。

- `-To` を指定しないときは、調べるだけで、ファイルを変更しません
- 置き換えるときは、置き換え先（新しいサーバーのフォルダやファイル）があるかを先に確かめます。見つからないものは置き換えません

## 使い方

```powershell
# 棚卸し：共有フォルダを指すショートカットを、サーバーごとに一覧にする（ファイルは変更しない）
powershell -ExecutionPolicy Bypass -File .\Update-ShortcutTarget.ps1 -Path C:\Users\yamada\Desktop

# 192.168.1.10 を指すショートカットを、192.168.2.20 に置き換える（確認してから置き換える）
powershell -ExecutionPolicy Bypass -File .\Update-ShortcutTarget.ps1 -Path C:\Users\yamada\Desktop -From 192.168.1.10 -To 192.168.2.20
```

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# 192.168.1.10 を指すショートカットだけを一覧にする（ファイルは変更しない）
powershell -ExecutionPolicy Bypass -File .\Update-ShortcutTarget.ps1 -Path C:\Users\yamada\Desktop -From 192.168.1.10

# IP アドレスとサーバー名の両方で書かれたショートカットを、新しいサーバーにそろえる
powershell -ExecutionPolicy Bypass -File .\Update-ShortcutTarget.ps1 -Path C:\Users\yamada\Desktop -From "192.168.1.10,oldfs,oldfs.corp.local" -To newfs

# 共有名も変わったとき（\\192.168.1.10\営業 の下を、\\192.168.2.20\sales の下に置き換える）
powershell -ExecutionPolicy Bypass -File .\Update-ShortcutTarget.ps1 -Path C:\Users\yamada\Desktop -From \\192.168.1.10\営業 -To \\192.168.2.20\sales

# デスクトップと「ネットワークの場所」をまとめて置き換える（コマンドプロンプトから）
powershell -ExecutionPolicy Bypass -File .\Update-ShortcutTarget.ps1 -Path "%USERPROFILE%\Desktop,%APPDATA%\Microsoft\Windows\Network Shortcuts" -From 192.168.1.10 -To 192.168.2.20

# この PC のすべてのユーザーのショートカットを置き換える（管理者として実行する）
powershell -ExecutionPolicy Bypass -File .\Update-ShortcutTarget.ps1 -Path C:\Users -Exclude "*\AppData\Local" -From 192.168.1.10 -To 192.168.2.20

# 確認せずに置き換える（ログオンスクリプトなど、画面を見ずに実行するとき）
powershell -ExecutionPolicy Bypass -File \\fs\scripts\Update-ShortcutTarget.ps1 -Path "%USERPROFILE%\Desktop" -From 192.168.1.10 -To 192.168.2.20 -Force -OutputFolder "%TEMP%"
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Path` | 調べるフォルダか、ショートカットのファイル。フォルダを指定すると、サブフォルダも含めて調べます。共有フォルダ（`\\server\share`）も指定できます。複数指定するときは、`"C:\Users\yamada\Desktop,C:\Users\Public\Desktop"` のようにカンマで区切って 1 つの文字列にします。指定した文字列全体が 1 つのフォルダとして存在するときは、カンマを含む名前のフォルダとして扱います | なし（必須） |
| `-From` | 置き換える前のサーバー。IP アドレスかサーバー名（`192.168.1.10`、`oldfs`）、または共有フォルダのパス（`\\192.168.1.10\営業`）で書きます。`"192.168.1.10,oldfs"` のようにカンマで区切って複数書けます（[置き換えのルール](#置き換えのルール)を参照） | 指定なし（棚卸し） |
| `-To` | 置き換えた後のサーバー。`-From` と同じ形で 1 つだけ書きます（`-From` がサーバーなら サーバー、共有フォルダのパスなら 共有フォルダのパス） | 指定なし（置き換えない） |
| `-Exclude` | 調べないフォルダやファイル。ワイルドカード（`*`）で、カンマで区切って書きます。書き方は [Find-DuplicateFile の除外の書き方](../Find-DuplicateFile/README.md#除外の書き方)と同じです | 指定なし |
| `-Force` | 確認せずに置き換えます | なし |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします。置き換えるとき（`-To` を指定したとき）は使えません（元のファイルを控えられないため） | なし |

`-From` と `-To` の組み合わせで、次のように動きます。

| 指定 | 動き |
| --- | --- |
| どちらも指定しない | 棚卸し。共有フォルダを指すショートカットをすべて一覧にし、サーバーごとの件数を表示します |
| `-From` だけ | `-From` のサーバーを指すショートカットを一覧にします |
| `-From` と `-To` | 置き換えの予定を表示して確認を求め、`Y` を入力すると置き換えます |

### ショートカットのよくある場所

| 場所 | パス |
| --- | --- |
| デスクトップ | `C:\Users\<ユーザー名>\Desktop`。OneDrive にデスクトップを移している PC では `C:\Users\<ユーザー名>\OneDrive\デスクトップ` などです（エクスプローラーで、デスクトップのプロパティの「場所」タブで確かめられます） |
| パブリックのデスクトップ（すべてのユーザーに表示される） | `C:\Users\Public\Desktop`。置き換えるには管理者が要ります |
| ネットワークの場所（エクスプローラーの「PC」に表示される） | `C:\Users\<ユーザー名>\AppData\Roaming\Microsoft\Windows\Network Shortcuts` |
| スタートメニュー | `C:\Users\<ユーザー名>\AppData\Roaming\Microsoft\Windows\Start Menu`、すべてのユーザーの分は `C:\ProgramData\Microsoft\Windows\Start Menu`（置き換えるには管理者が要ります） |

表示の決まりは次のとおりです。

- サーバーごとの件数は、件数の多い順に並べます。1 つのショートカットが 2 つのサーバーを指しているときは、両方に数えます
- ショートカットの一覧は、サーバー・ショートカットのパスの順に並べます。置き換えの予定は、予定・ショートカットのパスの順に並べます
- リンク先が共有フォルダでないとき（`explorer.exe` の引数に共有フォルダのパスを書いたショートカットなど）は、見つかった項目の名前を付けて「（引数）\\fileserver01\tools」のように表示します
- `-From` だけを指定したときは、「■ 192.168.1.10 を指すショートカット」として、リンク先とショートカットを表示します
- 画面に表示するショートカットは 200 件までです。超えた分は「（ほか 1,234 件は shortcuts.csv を参照してください）」と表示します。`-NoSave` のときと、保存先のフォルダを作れなかったときは、すべて表示します
- 置き換えるショートカットがないときは「置き換えるショートカットはありません」と表示し、確認せずに終わります
- 確認で `N` を入力したときは「置き換えませんでした」と表示し、予定だけを保存します
- 条件によって、次の行も表示します
  - `-Exclude` を指定したとき：「除外: *\AppData\Local」。除外したものがあれば「除外 3 件」
  - 読めないフォルダやショートカットがあったとき：「スキップ 3 件（権限なし 2・読めないショートカット 1）」
  - リンクがあったとき：「たどらなかったリンク 1 件」
  - 置き換え先の共有フォルダにつながらなかったとき：「※ \\192.168.2.20\営業 に接続できません。新しいサーバーが動いているか、サーバーの名前や IP アドレスが正しいかを確かめてください」
  - `-To` が `-From` の中にあるとき（`\\srv\営業` を `\\srv\営業\新` にするなど）：「※ -To が -From の中にあります。もう一度実行すると、二重に置き換わります（\\srv\営業\新\新）」。確認の前に表示します
  - `-From` がサーバーで、置き換え先が見つからないものがあるとき：「※ 共有名が変わったときは、-From と -To を \\サーバー\共有 の形で指定してください」
  - 管理者として実行しておらず、書き込む権限がなくて置き換えられないものがあったとき：「※ 管理者として実行すると、置き換えられるものがあります（パブリックのデスクトップなど）」

## 保存されるファイル

実行するたびに、保存先に `ShortcutTarget_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容（条件・件数・一覧・置き換えの結果）。一覧は 200 件を超えても省略しません |
| `shortcuts.csv` | 共有フォルダを指すショートカット（`-From` を指定したときは、`-From` のサーバーを指すもの）の一覧と、置き換えの結果 |
| `changes.csv` | 置き換えの予定と結果。置き換える項目ごとに 1 行です。`-To` を指定したときだけ作ります |
| `skipped.csv` | 調べられなかったフォルダ・ショートカットと、その理由 |
| `backup\` | 置き換えたショートカットの、置き換える前のファイル。元のパスと同じ構成で控えます（`C:\Users\yamada\Desktop\営業共有.lnk` なら `backup\C\Users\yamada\Desktop\営業共有.lnk`、`\\fs\portal\営業.lnk` なら `backup\UNC\fs\portal\営業.lnk`）。置き換えたときだけ作ります |

CSV とテキストは BOM 付き UTF-8 で保存します。保存先に書き込めないときは、調べるだけのときは警告を表示して画面表示だけで終わり、置き換えるときは置き換えずに止まります（元のファイルを控えられないため）。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `shortcuts.csv` | ショートカット、サーバー、リンク先、引数、作業フォルダ、アイコンの場所、コメント、最終更新日時、結果、備考、控え |
| `changes.csv` | ショートカット、項目、置き換える前、置き換えた後、結果 |
| `skipped.csv` | 理由、パス、詳細 |

- `shortcuts.csv` のリンク先などの値と最終更新日時は、置き換える前の値です。置き換えた後の値は `changes.csv` で確かめられます
- サーバーは、ショートカットが指しているサーバーです。複数あるときは「192.168.1.10, fileserver01」のようにカンマで区切ります
- 結果は、置き換えないとき（棚卸しと `-From` だけのとき）は空欄です。置き換えるときは「置き換えた」「置き換え先が見つからない」「置き換え先に接続できない」「置き換えられない」「失敗」「置き換えなかった」（確認で `N` を選んだ・中断した）のどれかです
- 備考には、置き換えなかった理由を書きます（「読み取り専用のファイルです」「書き込む権限がありません」「\\192.168.2.20\総務\月報.xlsx が見つかりません」など）
- 控えは、`backup\` に控えたファイルの、結果のフォルダから見たパスです（`backup\C\Users\yamada\Desktop\営業共有.lnk`）
- `changes.csv` の項目は、「リンク先」「引数」「作業フォルダ」「アイコンの場所」「コメント」のどれかです。結果は `shortcuts.csv` と同じです
- `skipped.csv` の理由は、「権限なし」「リンク」「除外指定」「クラウドのみ」「読めないショートカット」「その他のエラー」のいずれかです

## 置き換えのルール

- 置き換えるのは、ショートカットの「リンク先」「引数」「作業フォルダ」「アイコンの場所」「コメント」の 5 つの中にある、共有フォルダのパス（`\\サーバー\…`）だけです。ショートカットのファイル名や、「ネットワークの場所」の名前（`共有 (192.168.1.10)` など）は変えません
- `-From` がサーバーのときは、`\\` の後ろのサーバーの部分が、`-From` と全部同じものだけを置き換えます。`192.168.1.1` は `\\192.168.1.10\` に当たりません。パスの途中にある同じ文字（`\\newfs\backup\192.168.1.10\` の `192.168.1.10` など）も置き換えません
- `-From` が共有フォルダのパスのときは、パスの先頭が `\` の区切りまで同じものだけを置き換えます。`\\192.168.1.10\営業` は `\\192.168.1.10\営業\2025` に当たり、`\\192.168.1.10\営業部` には当たりません。置き換えるのは一致した部分だけで、その後ろ（`\2025`）はそのまま残します
- 引数とコメントでは、文の中の共有フォルダのパスを同じルールで置き換えます。`-From` が共有フォルダのパスのときは、後ろが `\` か `"` か文の終わりのものだけを置き換えます（共有名には空白を使えるため、`\\srv\営業 共有` を `\\srv\営業` と取り違えないように）
- 大文字と小文字は区別しません。置き換えた部分は、`-To` に書いたとおりの文字になります
- `\\?\UNC\192.168.1.10\…` の形のパスも、同じように置き換えます
- `-From` を複数書いたときは、どれに当たっても `-To` に置き換えます
- `-To` が `-From` の中にあるとき（`\\srv\営業` を `\\srv\営業\新` にするなど）も置き換えます。置き換えたショートカットも `-From` に当たるので、もう一度実行すると `\\srv\営業\新\新` に置き換わります。注意を表示するので、同じ指定で 2 回実行しないでください
- 棚卸しで「共有フォルダを指すショートカット」に数えるのは、5 つの項目のどれかに共有フォルダのパスがあるものです。サーバーが IP アドレスで書かれているか、名前で書かれているかは、書かれたとおりに表示します（同じサーバーでも、`fileserver01` と `fileserver01.corp.local` は別に数えます）
- ネットワークドライブ（`Z:\` など）を指すショートカットは、置き換えません。ドライブの割り当てを付け替えてください

### 置き換え先の確かめ方

置き換える前に、置き換え先があるかを、実行したユーザーの権限で確かめます。

- 置き換えた後のリンク先が共有フォルダのパスなら、そのフォルダかファイルがあるかを確かめます。見つからないショートカットは「置き換え先が見つからない」とし、置き換えません。移し忘れや、`-To` の打ち間違いに気付けるようにするためです。移し終えてから、もう一度実行してください
- 先に、置き換え先の共有フォルダ（`\\サーバー\共有`）ごとに、つながるかを 1 回確かめます。つながらない共有の下のショートカットは「置き換え先に接続できない」とし、1 件ずつは確かめません（つながらないサーバーは、1 件に 20～40 秒かかるため）
- リンク先が共有フォルダのパスでないとき（`explorer.exe` の引数にパスを書いたものなど）は、置き換えた共有フォルダにつながるかだけを確かめます
- 権限がなくて確かめられないとき（フォルダはあるが、実行したユーザーには開けないなど）は、置き換えます。備考に「権限がないため、置き換え先を確かめられませんでした」と書きます
- 置き換える前のサーバーには接続しません。すでに止めたサーバーを指すショートカットも、待たずに調べられます

### 置き換え方

- ショートカットの読み書きには、Windows に入っている WScript.Shell を使います。リンク先を設定し直すと、Windows がショートカットの中の情報（エクスプローラーが使う、サーバーと共有の情報）を新しいリンク先から作り直します
- 「管理者として実行」の設定、ショートカットキー、実行時の大きさ（最大化など）は、そのまま残ります
- 元のファイルは、置き換える前に `backup\` に控えます。控えられなかったショートカットは、置き換えません
- 置き換えた後に読み直し、5 つの項目が予定どおりになっているかを確かめます。違っていたときは、控えたファイルで元に戻し、「失敗」とします
- 予定を立てた後に（確認を待っている間などに）変わったショートカットは、置き換えずに「失敗」とします
- ファイルのアクセス権と属性（隠しなど）は変えません。読み取り専用のショートカットは、置き換えずに「置き換えられない」とします
- 最終更新日時は、置き換えた日時になります

### 元に戻すとき

`backup\` のファイルを、元の場所にコピーしてください。置き換えたショートカットをまとめて戻すときは、結果のフォルダで次のように実行します。

```powershell
cd C:\tools\ShortcutTarget_PC01_20261114_100005
Import-Csv .\shortcuts.csv | Where-Object { $_.結果 -eq '置き換えた' } | ForEach-Object { Copy-Item -LiteralPath $_.控え -Destination $_.ショートカット -Force }
```

## そのほかのルール

- 調べるのは、拡張子が `.lnk` のファイルです。隠しファイルとシステムファイルも調べます
- ジャンクションやシンボリックリンクはたどりません。`-Path` にリンクそのものを指定したときは、リンク先を調べます
- 権限がなくて読めないフォルダは飛ばして、件数を表示し、`skipped.csv` に残します
- 壊れていて読めないショートカットは、`skipped.csv` に「読めないショートカット」として残します
- OneDrive などのクラウドのみのファイルは、読むとダウンロードが始まるため、調べずに `skipped.csv` に「クラウドのみ」として残します
- このツールの結果のフォルダ（`ShortcutTarget_*`）の中は調べません（控えたショートカットを、次に置き換えてしまわないように）
- 260 文字を超える長いパスや、名前に `[` `]` を含むフォルダ・ファイルも扱えます
- 途中で中断（Ctrl+C）した場合は、調べている途中や、置き換え先を確かめている途中なら、結果を保存しません（ファイルは変えていません）。置き換えの途中なら、それまでに置き換えたショートカットはそのまま残り、控えと結果も残します。残りのショートカットは「置き換えなかった」とし、備考に「中断したため、置き換えていません」と書きます
- 置き換えるときは、Ctrl+C をキーの入力として受け取り、ショートカットの区切りごとに確かめて止めます（Windows PowerShell 5.1 は、処理の途中の Ctrl+C を取りこぼすことがあるためです）。確認（`[Y] はい  [N] いいえ`）を待っている間は、通常の Ctrl+C です

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 調べられた。置き換えたときは、予定したものをすべて置き換えた（確認で `N` を選んだときも 0） |
| 1 | 引数の誤りなどで止まった。置き換えられなかったショートカット（置き換え先が見つからない・接続できない・置き換えられない・失敗）がある。または、置き換えの途中で Ctrl+C で中断した |

読めなかったフォルダやショートカットがあっても、それだけでは 1 にしません（件数は画面に表示します）。

## 止まるとき

次の場合は、調べ始める前にエラーを表示して止まります（終了コード 1）。

| 場合 | 表示の例 |
| --- | --- |
| `-Path` を指定していない | 「調べるフォルダかショートカットを -Path で指定してください」 |
| 値に `"` が残っている（コマンドプロンプトで `"C:\data\" -From …` のように、最後が `\"` の値の後ろに引数が続いた） | 「-Path の値に引用符（"）が残っています: …」と、正しい書き方 |
| フォルダもファイルも見つからない | 「フォルダかファイルが見つかりません: C:\Users\yamada\Desktop」 |
| 同じフォルダを 2 回指定した、片方がもう片方の中にある | 「指定したフォルダの片方が、もう片方の中にあります: C:\Users と C:\Users\yamada\Desktop」 |
| `-From` か `-To` の書き方が正しくない | 「-From は IP アドレスかサーバー名、または \\サーバー\共有 の形で指定してください: \\192.168.1.10\」 |
| `-To` だけを指定した | 「-To を使うときは、置き換える前のサーバーを -From で指定してください」 |
| `-To` に複数書いた | 「-To は 1 つだけ指定してください」 |
| `-From` と `-To` の形がそろっていない | 「-From と -To は、どちらもサーバー、またはどちらも \\サーバー\共有 の形で指定してください」 |
| `-From` と `-To` が同じ | 「-From と -To が同じです: 192.168.1.10」 |
| `-To` と `-NoSave` を一緒に指定した | 「置き換えるときは -NoSave を使えません（元のファイルを控えられないため）」 |
| 置き換えるときに、保存先に書き込めない | 「保存先に書き込めないため、置き換えずに止めました: …」 |
| `-Force` なしで、確認できない環境（`-NonInteractive` で起動したなど）で置き換えようとした | 「確認できないため、置き換えずに止めました。確認せずに置き換えるときは -Force を付けてください」 |

## ログオンスクリプトやタスクスケジューラで使うとき

- `-Force` を付けてください。付けないと、確認できないため置き換えずに止まります
- `-Path` と `-OutputFolder` は、フルパスで指定してください
- スクリプトを置いた共有フォルダに、利用者は書き込めないことが多いので、`-OutputFolder` に利用者が書き込める場所（`%TEMP%` など）を指定してください。保存先に書き込めないと、置き換えずに止まります
- 新しいサーバーにつながらない時間に動くと、置き換えずに終わります（終了コード 1）。サーバーを移し終えてから動かしてください

## 使うときの注意

- **先に棚卸しをしてください。** 同じサーバーが、IP アドレスで書かれたショートカットと、名前（`fileserver01`、`fileserver01.corp.local`）で書かれたショートカットに分かれていることがあります。`-From` には、棚卸しで見つかった書き方をすべて書いてください
- **置き換える前に、`changes.csv` で予定を確かめてください。** 確認で `N` を選べば、予定だけを保存して終わります
- **ショートカットのほかにも、サーバーを指しているものがあります。** ネットワークドライブの割り当て、エクスプローラーのクイックアクセスのピン留め、Office の最近使ったファイル、タスクバーのピン留め、インターネットショートカット（`.url`）は、このツールでは置き換えません
- **パブリックのデスクトップ、すべてのユーザーのスタートメニュー、ほかのユーザーのフォルダ**は、管理者でないと置き換えられません
- 置き換えたショートカットのアイコンが、すぐには新しくならないことがあります（エクスプローラーが前のアイコンを覚えているため）。開けば新しいリンク先が開きます
