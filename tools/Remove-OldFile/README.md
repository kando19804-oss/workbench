# Remove-OldFile（古いファイルの整理）

指定したフォルダの中から、指定した日数より古いファイルを探して一覧にします。指定すれば、確認したうえで、まとめて削除するか、別の場所へ移します。何を削除したか（移したか）は、結果のフォルダに記録として残します。

「ログのフォルダがいっぱいになるので、90 日より古いログを消したい」「スキャンの置き場や受け渡し用のフォルダに、古いファイルが溜まっている」「古いファイルを、別のドライブのアーカイブへ移したい」というときのための道具です。タスクスケジューラで、定期的に整理することもできます。

- 既定では一覧にするだけで、ファイルを変更しません
- 削除するとき（`-Delete`）と移すとき（`-MoveTo`）は、件数と容量を表示して確認を求めます
- 削除したファイルは、ごみ箱に入りません。元に戻せないので、先に一覧だけで実行して確かめてください

## 使い方

```powershell
# 一覧だけ：D:\logs の中で、90 日より古いファイルを一覧にする（ファイルは変更しない）
powershell -ExecutionPolicy Bypass -File .\Remove-OldFile.ps1 -Path D:\logs -OlderThan 90

# 削除する（確認してから削除する）
powershell -ExecutionPolicy Bypass -File .\Remove-OldFile.ps1 -Path D:\logs -OlderThan 90 -Delete
```

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# .log と .txt だけを対象にする
powershell -ExecutionPolicy Bypass -File .\Remove-OldFile.ps1 -Path D:\logs -OlderThan 90 -Include "*.log,*.txt" -Delete

# 一部のフォルダを対象にしない
powershell -ExecutionPolicy Bypass -File .\Remove-OldFile.ps1 -Path D:\share\scan -OlderThan 30 -Exclude "keep,*.pdf" -Delete

# 削除して空になったフォルダも削除する（日付ごとのフォルダが溜まっていく置き場など）
powershell -ExecutionPolicy Bypass -File .\Remove-OldFile.ps1 -Path D:\backup\daily -OlderThan 14 -Delete -RemoveEmptyFolder

# 削除せずに、別のドライブのアーカイブへ移す（フォルダの構成はそのまま）
powershell -ExecutionPolicy Bypass -File .\Remove-OldFile.ps1 -Path D:\logs -OlderThan 365 -MoveTo E:\archive\logs

# 確認せずに削除する（タスクスケジューラなど、画面を見ずに実行するとき）
powershell -ExecutionPolicy Bypass -File C:\tools\Remove-OldFile.ps1 -Path D:\logs -OlderThan 90 -Delete -Force -OutputFolder C:\tools\log
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Path` | 調べるフォルダ。サブフォルダも含めて調べます。共有フォルダ（`\\server\share`）も指定できます。複数指定するときは、`"D:\logs\app1,D:\logs\app2"` のようにカンマで区切って 1 つの文字列にします。指定した文字列全体が 1 つのフォルダとして存在するときは、カンマを含む名前のフォルダとして扱います。ドライブのルートや Windows のフォルダなど、[指定できない場所](#指定できない場所)があります | なし（必須） |
| `-OlderThan` | 何日より古いファイルを対象にするか。1～36500 で指定します（[古いファイルの決め方](#古いファイルの決め方)を参照） | なし（必須） |
| `-Include` | 対象にするファイルの名前。ワイルドカード（`*`）で、`"*.log,*.txt"` のようにカンマで区切って書きます。`*` 以外の文字（`[` `]` `?` など）は、そのままの文字として扱います。大文字と小文字は区別しません | 指定なし（すべてのファイル） |
| `-Exclude` | 対象にしないフォルダやファイル。ワイルドカード（`*`）で、カンマで区切って書きます。書き方は [Find-DuplicateFile の除外の書き方](../Find-DuplicateFile/README.md#除外の書き方)と同じです | 指定なし |
| `-Delete` | 対象のファイルを、確認してから削除します | なし（一覧だけ） |
| `-MoveTo` | 対象のファイルを、確認してから指定したフォルダへ移します（[移すときのルール](#移すときのルール)を参照）。`-Delete` とは一緒に使えません | 指定なし（移さない） |
| `-RemoveEmptyFolder` | 対象のファイルを削除した（移した）ことで空になったフォルダも削除します（[空になったフォルダ](#空になったフォルダ)を参照）。一覧だけのときは、空になる予定のフォルダを数えて表示します | なし（フォルダは削除しない） |
| `-Force` | 確認せずに削除します（移します）。`-Delete` か `-MoveTo` と一緒に使います | なし |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします。削除するとき・移すときは使えません（何を削除したかの記録を残すため） | なし |

`-Path`、`-MoveTo`、`-OutputFolder` には、`%TEMP%` のような環境変数を書けます。タスクスケジューラなど、コマンドプロンプトを通らずに起動されて、環境変数が展開されないまま届くときも、ツールの中で展開します。

`-Delete` と `-MoveTo` の指定で、次のように動きます。

| 指定 | 動き |
| --- | --- |
| どちらも指定しない | 一覧だけ。古いファイルを、フォルダごとの件数と容量と一緒に表示し、記録を保存します |
| `-Delete` | 削除の予定を表示して確認を求め、`Y` を入力すると削除します |
| `-MoveTo` | 移す予定を表示して確認を求め、`Y` を入力すると移します |

## 画面の表示例

一覧だけのとき：

```

対象: D:\logs
2026-11-18 10:00:00   SERVER01（管理者: はい）
条件: 作成・最終更新とも 90 日以上前（2026-08-20 10:00 より前）のファイル  名前: *.log
ファイル 12,345 件  古いファイル 1,503 件（9.3 GB）  所要 1.2秒

■ 古いファイルのあるフォルダ（サイズの大きい順）
      サイズ      件数  いちばん古い  フォルダ
      8.2 GB     1,200  2024-01-05    D:\logs\app
      1.1 GB       300  2025-03-01    D:\logs\iis\W3SVC1
     12.4 MB         3  2025-08-11    D:\logs

対象 1,500 件（9.3 GB）  対象外 3 件（読み取り専用 2・システムファイル 1）
削除するときは -Delete を、移すときは -MoveTo を付けて、もう一度実行してください
保存先: C:\tools\OldFile_SERVER01_20261118_100000
```

削除するとき（`-Delete`）は、一覧の後に次のように表示し、確認を求めます。

```
削除するファイル 1,500 件（9.3 GB）
削除しないファイル 3 件（読み取り専用 2・システムファイル 1）
※ 削除したファイルは元に戻せません（ごみ箱には入りません）
削除しますか？ [Y] はい  [N] いいえ: Y

結果: 削除しました  1,498 件（9.2 GB）  失敗 2 件  所要 3.4秒

■ 削除できなかったファイル
 理由            ファイル
 使用中          D:\logs\app\app_20240105.log
 予定の後に変更  D:\logs\app\app_20240106.log

保存先: C:\tools\OldFile_SERVER01_20261118_100000
```

移すとき（`-MoveTo E:\archive\logs`）は、「対象」の次の行に「移す先: E:\archive\logs」を表示し、確認を次のように求めます。

```
移すファイル 1,500 件（9.3 GB）
移さないファイル 4 件（移す先に同じ名前がある 1・読み取り専用 2・システムファイル 1）
移しますか？ [Y] はい  [N] いいえ: Y

結果: 移しました  1,500 件（9.3 GB）  失敗 0 件  所要 2分10秒
```

表示の決まりは次のとおりです。

- 「ファイル」は調べたファイルの数（`-Include` に当てはまり、`-Exclude` に当てはまらないもの）、「古いファイル」はそのうち [古いファイルの決め方](#古いファイルの決め方)に当てはまったものの数です
- フォルダの一覧は、そのフォルダの直下にある古いファイルの合計で、サイズの大きい順に並べます。画面に表示するのは 20 フォルダまでです。超えた分は「（ほか 35 フォルダは folders.csv を参照してください）」と表示します。`-NoSave` のときと、保存先のフォルダを作れなかったときは、すべて表示します
- 「いちばん古い」は、そのフォルダの古いファイルのうち、[判定に使う日時](#古いファイルの決め方)がいちばん古いものの日付です
- 削除できなかった（移せなかった）ファイルは、20 件まで表示します。超えた分は「（ほか 12 件は files.csv を参照してください）」と表示します
- 対象のファイルがないときは「対象のファイルはありません」と表示し、確認せずに終わります
- 確認で `N` を入力したときは「削除しませんでした」（「移しませんでした」）と表示し、予定だけを保存します
- 条件によって、次の行も表示します
  - `-Exclude` を指定したとき：「除外: keep, *.pdf」。除外したものがあれば「除外 3 件」
  - 読めないフォルダがあったとき：「スキップ 3 件（権限なし 2・その他のエラー 1）」
  - リンクがあったとき：「たどらなかったリンク 1 件」
  - `-RemoveEmptyFolder` を指定したとき：確認の前に「空になるフォルダ 12 件も削除します」（一覧だけのときは「空になる予定のフォルダ 12 件」）、結果の後に「空になったフォルダ 12 件を削除しました」
  - 管理者として実行しておらず、読めないフォルダや、権限がなくて削除できないファイルがあったとき：「※ 管理者として実行すると、対象にできる範囲が広がります」

## 保存されるファイル

実行するたびに、保存先に `OldFile_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容（条件・件数・フォルダの一覧・結果）。一覧は 20 件を超えても省略しません |
| `files.csv` | 古いファイルの一覧と、削除した（移した）結果。古くないファイルは載せません |
| `folders.csv` | 古いファイルのあるフォルダごとの件数と容量 |
| `emptyfolders.csv` | 空になった（なる予定の）フォルダと、削除した結果。`-RemoveEmptyFolder` を指定したときだけ作ります |
| `skipped.csv` | 調べられなかったフォルダ・ファイルと、その理由 |

CSV とテキストは BOM 付き UTF-8 で保存します。保存先に書き込めないときは、一覧だけのときは警告を表示して画面表示だけで終わり、削除するとき・移すときは何もせずに止まります（記録を残せないため）。

削除するとき・移すときは、**削除する前に予定を `files.csv` に書いておき**、終わったら結果で書き直します。途中で PowerShell のウィンドウを閉じるなどして止まっても、何を削除しようとしていたかが残ります（結果が「削除する予定」のまま残っている行は、ファイルがあるかどうかで、削除したかが分かります）。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `files.csv` | ファイル、サイズ(バイト)、作成日時、最終更新日時、経過日数、結果、備考、移した先 |
| `folders.csv` | フォルダ、件数、サイズ(バイト)、いちばん古い日時、いちばん新しい日時 |
| `emptyfolders.csv` | フォルダ、結果、備考 |
| `skipped.csv` | 理由、パス、詳細 |

- 経過日数は、作成日時と最終更新日時の新しいほうから、実行した日時までの日数です（1 日に満たない分は切り捨てます）
- 結果は次のどれかです
  - 一覧だけのとき：空欄（対象）か「対象外」
  - 削除するとき：「削除した」「対象外」「失敗」「削除しなかった」（確認で `N` を選んだ・中断した・予定を立てた後になくなっていた）。途中で止まったときは「削除する予定」が残ります
  - 移すとき：「移した」「移せない」（移す先に同じ名前のファイルがある）「対象外」「失敗」「移さなかった」。途中で止まったときは「移す予定」が残ります
- 備考には、対象外の理由（「読み取り専用のファイルです」「システムファイルです」「クラウドのみのファイルです」）や、失敗の理由（「ほかのプロセスが使用中です」「アクセスが拒否されました」「予定を立てた後に更新されました」など）を書きます
- 移した先は、移したファイルの移した先のパスです。移さなかったものは空欄です
- 日時は `2026/11/18 10:00:00` の形、サイズと件数は 3 桁区切りで出力します
- `emptyfolders.csv` の結果は、一覧だけのときは空欄、削除するときは「削除した」「削除しなかった」（中に削除できなかったファイルが残った・確認で `N` を選んだなど）「失敗」のどれかです
- `skipped.csv` の理由は、「権限なし」「リンク」「除外指定」「その他のエラー」のいずれかです

## 古いファイルの決め方

**作成日時と最終更新日時が、どちらも「実行した日時の N 日前」より前のファイル**を、古いファイルとします（N は `-OlderThan` の日数）。どちらか新しいほうで判定する、ということです。

- 基準の日時は、実行を始めた日時から N×24 時間前です。画面の「条件」の行に「（2026-08-20 10:00 より前）」のように表示します
- 書き込みが続いているログは、作成日時が古くても最終更新日時が新しいので、対象になりません
- **古いファイルをコピーして置いた場合**：エクスプローラーや `Copy-Item` でコピーしたファイルは、最終更新日時は元のまま、作成日時がコピーした日時になります。そのため、置いてから N 日たつまでは対象になりません（最終更新日時だけで判定すると、2020 年のファイルを置いた次の実行で消えてしまいます）
  - robocopy でコピーしたファイルは、作成日時も元のまま写るため、元の日時で判定されます
- 最終アクセス日時は使いません（Windows は、ファイルを読んでも最終アクセス日時を更新しないことがあるためです）
- 日時が未来のファイル（時計のずれた PC から書かれたものなど）は、対象になりません
- 日時が壊れていて読めないファイルは、`skipped.csv` に「その他のエラー」として残します

### 対象外にするファイル

古いファイルでも、次のものは削除せず（移さず）、`files.csv` に「対象外」として残します。

| ファイル | 理由 |
| --- | --- |
| 読み取り専用のファイル | 消さないように印を付けてあるファイルのため |
| システムファイル（システム属性の付いたファイル） | `desktop.ini` など、Windows が使うファイルのため |
| クラウドのみのファイル（OneDrive など） | PC の容量を使っていないため（削除しても容量は空かず、クラウドとほかの PC からも消えます）。移すときは、ダウンロードが始まるため |

隠しファイルは、対象にします。

## 削除するときのルール

- 削除したファイルは、ごみ箱に入りません（`del` コマンドと同じです）
- 確認を待っている間などに、予定を立てた後で変わったファイル（更新された、サイズが変わった、読み取り専用になった）は、削除せずに「失敗」とします。予定を立てた後になくなっていたファイルは、「削除しなかった」とします
- ほかのプロセスが使っていて削除できないファイルは「失敗」とし、ほかのファイルの削除を続けます。どのプロセスが使っているかは、[Find-FileLock](../Find-FileLock/) で調べられます
- 削除するのはファイルだけです。フォルダは、`-RemoveEmptyFolder` を指定したときだけ削除します

## 移すときのルール

- `-MoveTo` に指定したフォルダの下に、`-Path` の中と同じフォルダの構成で移します。`-Path D:\logs -MoveTo E:\archive\logs` なら、`D:\logs\app\a.log` は `E:\archive\logs\app\a.log` に移ります。足りないフォルダは作ります
- `-MoveTo` のフォルダは、先に作っておいてください。見つからないときは止まります（打ち間違いで、別の場所にフォルダを作ってしまわないように）
- `-MoveTo` を使うときは、`-Path` を 1 つだけ指定してください（複数のフォルダから同じ構成で移すと、名前がぶつかるため）
- 移す先に同じ名前のファイルがあるときは、上書きせずに「移せない」とします
- 作成日時・最終更新日時・属性（隠しなど）は、元のまま移します。移した先でも、このツールで同じように古さを判定できます
- アクセス権は、同じドライブの中で移すときは元のまま、別のドライブへ移すときは、移した先のフォルダのアクセス権を引き継ぎます
- 別のドライブへ移すときは、コピーしてから元のファイルを削除します。コピーした後にサイズを確かめ、元のファイルを削除できなかったときは、移した先のコピーを削除して「失敗」とします（同じファイルが 2 か所に残らないように）
- 別のドライブへ移すときは、確認の前に、移す先の空き容量が足りるかを確かめます。足りないときは止まります

## 空になったフォルダ

`-RemoveEmptyFolder` を指定すると、ファイルを削除した（移した）後に、空になったフォルダも削除します。

- 削除するのは、**このツールで中のファイルを削除した（移した）ことで空になったフォルダ**だけです。実行する前から空だったフォルダは削除しません（アプリが使うために置いてある空のフォルダもあるため）
- 中のフォルダがすべて空になって削除された結果、空になった親のフォルダも削除します
- 中に何か 1 つでも残っているフォルダ（隠しファイル、対象外のファイル、新しいファイル、リンクなど）は削除しません
- `-Path` に指定したフォルダそのものは、空になっても削除しません
- フォルダを削除する直前に、空であることをもう一度確かめます

## 指定できない場所

誤って指定すると、OS やアプリが動かなくなる場所は、`-Path` に指定できません。次の場所そのものか、それを含むフォルダを指定すると、調べる前に止まります（一覧だけのときも止まります）。

- ドライブのルート（`C:\`、`D:\`、管理共有の `\\server\C$` など）
- ドライブの直下の `Windows`・`Program Files`・`Program Files (x86)`・`ProgramData`・`Users`
- `Windows` の中の `System32`・`SysWOW64`・`WinSxS`
- `Users` の直下の各ユーザーのフォルダ（`C:\Users\yamada`、`C:\Users\Public` など）
- この PC の Windows のフォルダ（`%SystemRoot%`）と、各ユーザーのプロファイルのフォルダ（ほかのドライブに置いている場合）

これらの中のフォルダ（`C:\Windows\Temp`、`C:\ProgramData\<アプリ>\logs`、`C:\Users\yamada\Downloads` など）は指定できます。管理共有を通したパス（`\\server\C$\Windows` など）も、同じように扱います。共有フォルダのルート（`\\server\scan`）は指定できます。

## そのほかのルール

- 隠しフォルダの中も調べます
- ジャンクションやシンボリックリンクはたどらず、リンクそのものも削除しません。`skipped.csv` に「リンク」として残します
- 権限がなくて読めないフォルダは飛ばして、件数を表示し、`skipped.csv` に残します
- このツールの結果のフォルダ（`OldFile_<ホスト名>_<日時>` の形の名前のフォルダ）、ごみ箱（`$RECYCLE.BIN`）、`System Volume Information` の中は調べず、`skipped.csv` に「除外指定」として残します。実行しているスクリプトのファイルも対象にしません
- 260 文字を超える長いパスや、名前に `[` `]` を含むフォルダ・ファイルも扱えます
- 途中で中断（Ctrl+C）した場合は、調べている途中なら、結果を保存しません（ファイルは変えていません）。削除（移動）の途中なら、それまでに削除した（移した）ファイルはそのままで、記録も残します。残りのファイルは「削除しなかった」（「移さなかった」）とし、備考に「中断したため、削除していません」と書きます
- 削除するとき・移すときは、Ctrl+C をキーの入力として受け取り、ファイルの区切りごとに確かめて止めます（Windows PowerShell 5.1 は、処理の途中の Ctrl+C を取りこぼすことがあるためです）。大きなファイルを別のドライブへ移しているときは、そのファイルを移し終えてから止まります。確認（`[Y] はい  [N] いいえ`）を待っている間は、通常の Ctrl+C です

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 調べられた。削除するとき・移すときは、予定したものをすべて削除した（移した）。確認で `N` を選んだときも 0 |
| 1 | 引数の誤りなどで止まった。削除できなかった（移せなかった）ファイルがある（失敗・移せない）。空になったフォルダを削除できなかった。または、削除（移動）の途中で Ctrl+C で中断した |

読めなかったフォルダや、対象外のファイル（読み取り専用など）があっても、それだけでは 1 にしません（件数は画面に表示します）。

## 止まるとき

次の場合は、調べ始める前にエラーを表示して止まります（終了コード 1）。

| 場合 | 表示の例 |
| --- | --- |
| `-Path` を指定していない | 「調べるフォルダを -Path で指定してください」 |
| `-OlderThan` を指定していない | 「何日より古いファイルを対象にするかを、-OlderThan で指定してください（例: -OlderThan 90）」 |
| `-OlderThan` が範囲外 | 「-OlderThan は 1～36500 の数値で指定してください: 0」 |
| 値に `"` が残っている（コマンドプロンプトで `"D:\logs\" -OlderThan 90` のように、最後が `\"` の値の後ろに引数が続いた） | 「-Path の値に引用符（"）が残っています: …」と、正しい書き方 |
| フォルダが見つからない・開けない | 「フォルダが見つかりません: D:\logs」「フォルダを開けません: \\fs\scan（アクセスが拒否されました。）」。管理者として開いた PowerShell でネットワークドライブを指定したときは、`\\サーバー名\共有名` の形で指定するよう案内します |
| `-Path` にファイルを指定した | 「フォルダを指定してください（ファイルは指定できません）: D:\logs\app.log」 |
| 指定できない場所を指定した | 「この場所は指定できません（OS やアプリが動くのに必要なファイルがあるため）: C:\Windows」と、もっと下のフォルダを指定するよう案内します |
| 同じフォルダを 2 回指定した、片方がもう片方の中にある | 「指定したフォルダの片方が、もう片方の中にあります: D:\logs と D:\logs\app」 |
| `-Delete` と `-MoveTo` を一緒に指定した | 「-Delete と -MoveTo は一緒に使えません」 |
| `-MoveTo` で、`-Path` を 2 つ以上指定した | 「-MoveTo を使うときは、-Path を 1 つだけ指定してください」 |
| `-MoveTo` のフォルダが見つからない | 「移す先のフォルダが見つかりません: E:\archive\logs。先に作ってから実行してください」 |
| `-MoveTo` が `-Path` と同じ、または片方がもう片方の中にある | 「移す先が、調べるフォルダと重なっています: D:\logs と D:\logs\old」 |
| `-Force` を、`-Delete` も `-MoveTo` もなしで指定した | 「-Force は -Delete か -MoveTo と一緒に指定してください」 |
| `-NoSave` を、`-Delete` か `-MoveTo` と一緒に指定した | 「削除するとき・移すときは -NoSave を使えません（記録を残すため）」 |
| 削除するとき・移すときに、保存先に書き込めない | 「保存先に書き込めないため、削除せずに止めました: …」 |
| 別のドライブへ移すときに、移す先の空き容量が足りない | 「移す先の空き容量が足りないため、移さずに止めました（必要 9.3 GB・空き 5.0 GB）: E:\」。調べた後、確認の前に止まります |
| `-Force` なしで、確認できない環境（`-NonInteractive` で起動したなど）で削除しようとした | 「確認できないため、削除せずに止めました。確認せずに削除するときは -Force を付けてください」。調べた後、確認の前に止まります |
| どのパラメーターにも当たらない引数がある（パラメーターの名前の書き間違いなど） | 「どのパラメーターにも当たらない引数があります: …」 |

## タスクスケジューラで使うとき

- `-Delete`（か `-MoveTo`）と `-Force` を付けてください。`-Force` を付けないと、確認できないため削除せずに止まります
- `-Path`、`-MoveTo`、`-OutputFolder` は、フルパスで指定してください。タスクスケジューラから実行すると、現在のフォルダが `C:\Windows\System32` になるためです
- 結果のフォルダは、実行するたびに 1 つずつ増えます。`-OutputFolder` に記録用のフォルダを指定し、ときどき整理してください（このツールは、自分の結果のフォルダの中は調べないため、このツールでは整理できません）
- 共有フォルダを整理するときは、タスクを「SYSTEM」ではなく、共有フォルダに書き込めるドメインのユーザーで実行してください（SYSTEM は、ネットワークの先ではコンピューターのアカウントとして扱われます）

「操作」の設定は、次のようにします。

| 項目 | 値 |
| --- | --- |
| プログラム/スクリプト | `powershell.exe` |
| 引数の追加 | `-ExecutionPolicy Bypass -File C:\tools\Remove-OldFile.ps1 -Path D:\logs -OlderThan 90 -Delete -Force -OutputFolder C:\tools\log` |

## 共有フォルダを整理するとき

- `-Path \\サーバー名\共有名` の形で指定してください。管理者として開いた PowerShell からは、通常の権限で割り当てたネットワークドライブ（`Z:` など）が見えないことがあります
- 実行したユーザーの権限で読み、削除します。読めない場所は飛ばし、削除する権限のないファイルは「失敗」とします
- ネットワーク越しにフォルダを 1 つずつ読むため、ローカルのフォルダより時間がかかります。ファイルサーバーにログオンできる場合は、サーバー上でローカルのパス（`D:\share` など）を指定して実行するほうが速く終わります
- ファイルサーバーで「以前のバージョン」（シャドウコピー）が有効なら、削除したファイルをそこから戻せることがあります

## 使うときの注意

- **先に、一覧だけで実行してください。** `folders.csv` と `files.csv` で、消してはいけないファイルが入っていないかを確かめてから、`-Delete` を付けて実行してください
- **削除したファイルは、元に戻せません。** ごみ箱には入りません。心配なときは、`-MoveTo` で別の場所へ移し、しばらく様子を見てから削除してください
- **アプリが読み続けるファイルに注意してください。** 設定ファイルやデータベースのように、作ってから更新されないまま使われ続けるファイルは、古いファイルとして対象になります。アプリのフォルダを指定するときは、ログのフォルダだけに絞ってください
- **OneDrive などの同期しているフォルダ**では、削除するとクラウドとほかの PC からも消えます（クラウドのみのファイルは対象外にしますが、PC に保存されているファイルは削除します）
- ハードリンクの別名を削除しても、ほかの名前が残っている間は、容量は空きません
