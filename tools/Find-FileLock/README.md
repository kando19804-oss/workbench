# Find-FileLock（ファイルロック特定）

指定したファイルやフォルダを使っているプロセスを突き止めます。ファイルサーバーの上で実行すると、共有フォルダ経由で開いているクライアントとユーザーも表示します。結果は画面に表示し、CSV にも保存します。

「ファイルが使用中で、削除も上書きもできない」「フォルダを消そうとしたら、どこかで開かれていると言われた」「共有フォルダの Excel を誰が開いているのか知りたい」というときのための道具です。読み取りだけを行い、プロセスを止めたり、共有の接続を切ったりすることはありません。

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Find-FileLock.ps1 -Path D:\共有\経理\売上.xlsx
```

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# フォルダの中身も含めて調べる（フォルダを消せない、名前を変えられないとき）
powershell -ExecutionPolicy Bypass -File .\Find-FileLock.ps1 -Path D:\app\logs

# 結果を指定したフォルダに保存する
powershell -ExecutionPolicy Bypass -File .\Find-FileLock.ps1 -Path D:\app\logs -OutputFolder D:\report

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Find-FileLock.ps1 -Path D:\共有\経理\売上.xlsx -NoSave
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Path` | 調べるファイルかフォルダ。フォルダを指定すると、中のファイルとフォルダもすべて調べます。ワイルドカードは使えません | なし（必須） |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします | なし |

- `-Path` は、名前を省略して書くこともできます（`.\Find-FileLock.ps1 D:\app\logs`）
- 設定ファイル（`-ConfigFile`）はありません。調べる場所が毎回違うためです

## 画面の表示例

```
ファイルロック特定 (Find-FileLock 1.0.0)
対象: D:\共有\経理\売上.xlsx
SERVER01   2026-11-03 10:00:00   管理者: はい

■ このコンピューターのプロセス
  PID  プロセス   実行ユーザー         起動日時          サービス  ファイル
    4  System     NT AUTHORITY\SYSTEM  2026-10-28 08:01  （カーネル：共有フォルダ経由の接続など）  D:\共有\経理\売上.xlsx

■ 共有フォルダから開いているクライアント
 クライアント  ユーザー        権限      ファイル
 10.0.0.25     CONTOSO\suzuki  読み書き  D:\共有\経理\売上.xlsx

■ 開けるかの確認
 読み取り  書き込み                        ファイル
 可        不可（ほかのプログラムが使用中）  D:\共有\経理\売上.xlsx

結果: 使用中   プロセス 1 個  クライアント 1 件   所要 0.4秒
保存先: C:\tools\FileLock_SERVER01_20261103_100000
```

表示の決まりは次のとおりです。

- 結果の行は「使用中」か「使用中のものは見つかりません」のどちらかです。プロセスかクライアントが 1 つでも見つかれば「使用中」です。どちらも見つからなくても、ほかのプログラムが使っていて開けないファイルがあれば、「使用中（使っているものは特定できません）」とします
- フォルダを指定したときは、対象の行の次に「調べた数: ファイル 1,234 件  フォルダ 56 件」と表示します。ファイルの列は、すべてフルパスです
- 見つからなかった欄は、見出しの下に「（なし）」と表示します
- 画面に表示する行は、欄ごとに 200 行までです。超えた分は「（ほか 34 行は locks.csv を参照してください）」と表示します。`-NoSave` のときと、保存できなかったときは、すべて表示します
- 調べている間は、進み具合を表示します
- コマンドラインは、パスワードなどが含まれることがあるため、画面には表示せず、CSV にだけ書きます
- PID 4（System）は、Windows のカーネルです。共有フォルダ経由で開かれているファイルは、ファイルサーバーの上では PID 4 が使っているように見えます。サービスの列に注記を表示します
- 調べている間に終わったプロセスは、プロセスの列に「（終了したプロセス）」と表示します
- 条件によって、次の行も表示します
  - 読めない場所があったとき：「スキップ 3 件（権限なし 2・その他のエラー 1）」
  - リンクがあったとき：「たどらなかったリンク 1 件」
  - 見つからなかったのに、ほかのプログラムが使っていて開けないファイルがあったとき：「※ 使っているものは見つかりませんが、書き込みで開けないファイルがあります。別の PC から共有フォルダ経由で使われているかもしれません。ファイルサーバーの上で実行してください」
  - 管理者でないため、共有フォルダの接続元を調べられなかったとき：「※ 共有フォルダの接続元は、管理者として実行すると調べられます」。管理者でも調べられなかったとき（Server サービスが止まっているなど）は、「※ 共有フォルダの接続元を調べられませんでした（理由）」
  - `\\server\share` の形か、ネットワークドライブで指定したとき：「※ 別の PC からは、この PC のプロセスしか分かりません。誰が開いているかは、ファイルサーバーの上で、そのサーバーでのパス（D:\共有\... など）を指定して実行してください」
  - 調べるフォルダの中が、このツール自身の現在のフォルダになっているとき：「※ このツールを、調べるフォルダの中で実行しています。別のフォルダから実行してください」
  - 管理者として実行しておらず、取れなかった情報があったとき：「※ 管理者として実行すると、ほかのユーザーのプロセスの実行ユーザー・実行ファイル・コマンドラインも取れます（コマンドラインは CSV にだけ書きます）」

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 使用中のものは見つからなかった（すべて調べられた） |
| 2 | 使用中のものが見つかった。または、ほかのプログラムが使っていて開けないファイルがあった。読めない場所があっても 2 です |
| 1 | 引数の誤りなどで、調べる前に止まった。または、見つからなかったが、読めない場所がある |

バッチファイルやタスクスケジューラから、「使われていなければ次の処理に進む」といった判定に使えます。共有フォルダの接続元を調べられなかったときも、これだけでは 1 にはしません（ファイルサーバーでない PC では、いつも調べられないためです）。

## 保存されるファイル

実行するたびに、保存先に `FileLock_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容。一覧は 200 行を超えても省略しません |
| `locks.csv` | 使っているプロセスとクライアントの一覧 |
| `skipped.csv` | 調べられなかった場所・調べなかった場所と、その理由 |

CSV は BOM 付き UTF-8 で保存するため、Excel でダブルクリックすればそのまま開けます。保存先に書き込めないときは警告を表示し、画面表示だけで終了します。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `locks.csv` | 種類、ファイル、PID、プロセス、サービス、実行ユーザー、起動日時、実行ファイル、コマンドライン、クライアント、クライアントのユーザー、権限、読み取り、書き込み |
| `skipped.csv` | 理由、パス、詳細 |

- 種類は「プロセス」か「クライアント」です。プロセスの行はプロセスの列を、クライアントの行はクライアントの列を埋め、残りは空欄にします
- 1 つのファイルを複数のプロセスが使っているときは、プロセスごとに 1 行ずつ書きます
- サービスは、複数あるときは `, ` で区切って、すべて書きます
- 権限は「読み取り」「読み書き」「その他」のどれかです
- 読み取り・書き込みは、[開けるかの確認](#開けるかの確認)の結果です。フォルダの行は空欄です
- 起動日時は `2026/10/30 22:14:05` の形で書きます
- 管理者でないために取れなかった値は、空欄にします
- ファイル名のうち、Excel で数値・日付・数式に変わる値は、`="..."` の形で書きます
- `skipped.csv` の理由は、「権限なし」「たどらなかったリンク」「その他のエラー」のいずれかです

## 調べ方

### プロセス

- Windows の API（`NtQueryInformationFile`）に、そのファイルやフォルダを開いているプロセスを問い合わせます。`Add-Type` で呼ぶため、実行のたびに C# のコンパイルが少し走ります
- ファイルを開いているプロセスのほか、実行中の EXE、読み込み中の DLL、現在のフォルダとしてフォルダを使っているプロセス（そのフォルダで開いたコマンドプロンプトなど）も出します
- このツール自身は出しません
- プロセスとサービスの情報は、CIM（`Win32_Process`、`Win32_Service`）で取ります

### 共有フォルダのクライアント

- `Get-SmbOpenFile` で、共有フォルダ経由で開かれているファイルの一覧を取り、調べるパスに当たるものを出します。管理者として実行したときだけ調べられます
- ファイルサーバーの上で、そのサーバーでのパス（`D:\共有\経理\売上.xlsx`）を指定してください。共有の名前（`\\server\share\...`）では突き合わせません
- 表示するのは、今開いている接続です。接続が切れた後も少しのあいだ残ることがあります

### 開けるかの確認

使っているプロセスがあっても、そのプロセスが共有を許していれば、ほかのプログラムからも読み書きできます。そこで、次のファイルについて、読み取りと書き込みのモードで実際に開いて、すぐに閉じます。

- `-Path` にファイルを指定したときは、そのファイル
- フォルダを指定したときは、中のファイルのうち、使っているものが見つかったファイル

**書き込みのモードで開くだけで、何も書きません。** ファイルの内容も更新日時も変わりません。ほかのプログラムの邪魔をしないよう、読み書きと削除をすべて許した状態で開きます。

| 表示 | 意味 |
| --- | --- |
| 可 | そのモードで開けた |
| 不可（ほかのプログラムが使用中） | 共有違反。本当のロックです |
| 不可（権限なし） | ファイルのアクセス権で開けない |
| 不可（読み取り専用） | 読み取り専用の属性が付いている |
| 不可（その他のエラー） | そのほかの理由で開けない |
| 確かめていない | オンライン専用ファイルなど、開くとダウンロードが始まるもの |

### 飛ばすもの

- **リンク**：ジャンクションやシンボリックリンクはたどらず、`skipped.csv` に残します。無限ループを防ぐためです。OneDrive のフォルダは、普通のフォルダとして調べます
- **読めないフォルダ**：権限がなくて中を読めないフォルダは飛ばして、件数を表示します
- 260 文字を超える長いパスや、名前に `[` `]` を含むフォルダ・ファイルも調べます
- 途中で中断（Ctrl+C）した場合は、結果を保存しません

## 止まるとき

次の場合は、調べ始める前にエラーを表示して止まります（終了コード 1）。

| 場合 | 表示の例 |
| --- | --- |
| `-Path` を指定していない | 「調べるファイルかフォルダを -Path で指定してください」 |
| 値に `"` が残っている（コマンドプロンプトで `"C:\data\"` のように最後を `\"` にした） | 「-Path の値に引用符（"）が残っています: …」と、正しい書き方 |
| ファイルもフォルダも見つからない | 「ファイルもフォルダも見つかりません: D:\memo.txt」 |
| Windows の API を呼ぶ準備ができない（`Add-Type` が使えない） | 「Windows の API を呼ぶ準備ができません。制約付き言語モードか、コンパイラーの実行が禁止されている環境では使えません」と、元のエラー |

## 使うときの注意

- **ファイルサーバーの上で、管理者として実行してください。** 共有フォルダのファイルを誰が開いているかは、ファイルサーバーの上でしか分かりません。別の PC から `\\server\share\...` を調べても、分かるのはその PC のプロセスだけです
- **管理者でなくても、使っているプロセスの PID と名前は取れます。** 実行ユーザー・実行ファイル・コマンドラインは、ほかのユーザーのプロセスでは取れないことがあります
- **出るのは、調べた瞬間の状態です。** 一瞬だけファイルを開くプログラム（ウイルス対策ソフト、バックアップなど）は、タイミングによって出たり出なかったりします
- **カーネルのドライバーが使っているファイル**は、PID 4（System）と表示されるか、まったく出ないことがあります
- **AppLocker や WDAC で制限された環境**では、`Add-Type` を使えないため動きません
- フォルダの中を調べるときは、ファイルごとに問い合わせます。ファイルが多いと時間がかかります

## 動作環境

[リポジトリの README の「システム要件」](../../README.md#システム要件)を参照してください。管理者権限は不要ですが、管理者として実行することをおすすめします。共有フォルダの接続元を調べるときは、管理者権限が必要です。
