# Compare-SystemState（作業前後スナップショット比較）

サーバーの状態（サービス・ポート・タスク・更新プログラム・ネットワーク設定など）を保存しておき、後で比べて、何が変わったかを一覧にします。結果は画面に表示し、CSV にも保存します。

「パッチの適用や設定変更の前後で、意図しないものが変わっていないか確かめたい」「作業のエビデンスを残したい」「作業の後で動かなくなったので、作業前と何が違うかを見たい」というときのための道具です。読み取りだけを行い、サーバーの設定を変更することはありません。

## 使い方

作業の前に状態を保存します。

```powershell
powershell -ExecutionPolicy Bypass -File .\Compare-SystemState.ps1 -Snapshot
```

保存先に `SystemSnapshot_<ホスト名>_<日時>` というフォルダができます。作業の後に、そのフォルダと今の状態を比べます。画面の最後に、このコマンドを表示します。

```powershell
powershell -ExecutionPolicy Bypass -File .\Compare-SystemState.ps1 -Reference .\SystemSnapshot_SERVER01_20261103_220000
```

調べたいサーバーの上で、管理者として実行してください。実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# サービスとポートだけを保存する
powershell -ExecutionPolicy Bypass -File .\Compare-SystemState.ps1 -Snapshot -Item "Service,Port"

# Windows 標準のタスク（\Microsoft\ の下）も含めて保存する
powershell -ExecutionPolicy Bypass -File .\Compare-SystemState.ps1 -Snapshot -AllTasks

# 保存した 2 つのスナップショットを比べる（別のサーバーとの比較にも使えます）
powershell -ExecutionPolicy Bypass -File .\Compare-SystemState.ps1 -Reference .\SystemSnapshot_AP01_20261103_220000 -Difference .\SystemSnapshot_AP02_20261103_220500

# 比べるときに、更新プログラムとソフトだけを見る
powershell -ExecutionPolicy Bypass -File .\Compare-SystemState.ps1 -Reference .\SystemSnapshot_SERVER01_20261103_220000 -Item "HotFix,Software"

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Compare-SystemState.ps1 -Reference .\SystemSnapshot_SERVER01_20261103_220000 -NoSave
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Snapshot` | 今の状態を保存するだけで、比べません | なし |
| `-Reference` | 基準のスナップショットのフォルダ | なし（`-Snapshot` のとき以外は必須） |
| `-Difference` | 比較のスナップショットのフォルダ | 今の状態 |
| `-Item` | 調べる項目。`"Service,Port"` のようにカンマで区切って書きます（[調べる項目](#調べる項目)を参照） | すべて |
| `-AllTasks` | Windows 標準のタスク（`\Microsoft\` の下）も保存します。`-Snapshot` のときだけ指定できます | なし |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします。`-Snapshot` と一緒には使えません | なし |

- 比べるときの `-Item` を省略すると、基準のスナップショットにある項目をすべて比べます。今の状態も、その項目だけを取ります
- 今の状態と比べるときのタスクの範囲は、基準のスナップショットに合わせます（`-AllTasks` で保存したものと比べるときは、今の状態も `\Microsoft\` の下まで取ります）
- 保存したもの同士を比べるとき、タスクの範囲が違うと、タスクは比べず `skipped.csv` に残します（すべて「追加」に見えてしまうためです）
- 設定ファイル（`-ConfigFile`）はありません。ほとんどの場合、既定のままで実行できるためです

## 調べる項目

突き合わせる値が同じものを同じ対象とみなし、比べる値が違えば「変更」とします。ここに書いていない値（PID、前回の実行日時、表示名など）は、スナップショットには残しても比べません。

| `-Item` の値 | 項目 | 突き合わせる値 | 比べる値 |
| --- | --- | --- | --- |
| `Service` | サービス | サービス名 | 状態、スタートアップ、実行ユーザー、実行ファイル |
| `Port` | 待ち受けポート | プロトコル、ローカルアドレス、ポート | プロセス名、サービス |
| `Task` | タスク | タスクのパス | 有効・無効、実行ユーザー、トリガー、操作 |
| `Software` | インストール済みソフト | 名前、32/64 ビット | バージョン |
| `HotFix` | 更新プログラム | KB 番号 | （あるかないかだけ） |
| `Network` | ネットワーク設定 | 接続の名前 | IP アドレス、サブネット、ゲートウェイ、DNS サーバー、DHCP、MAC アドレス |
| `Route` | ルーティング | 宛先、ゲートウェイ、接続の名前 | メトリック |
| `Share` | 共有フォルダ | 共有名 | パス |
| `LocalUser` | ローカルユーザー | ユーザー名 | 有効・無効、パスワードの期限 |
| `LocalGroup` | ローカルグループのメンバー | グループ名、メンバー名 | （あるかないかだけ） |
| `Hosts` | hosts ファイル | アドレス、ホスト名 | （あるかないかだけ） |
| `Environment` | システムの環境変数 | 変数名 | 値 |
| `Firewall` | ファイアウォール | 規則の ID（プロファイルは名前） | 規則：有効・無効、方向、許可・拒否、プロファイル、プロトコル、ポート、プログラム、リモートアドレス。プロファイル：有効・無効 |

### 取るものの範囲

- **サービス**：ログオンごとに名前の末尾が変わるユーザーごとのサービス（`CDPUserSvc_1a2b3` など）は、末尾を除いた名前で 1 つにまとめ、スタートアップと実行ファイルだけを比べます
- **待ち受けポート**：TCP の待ち受けと UDP です。接続中の通信は取りません
- **タスク**：`\Microsoft\` の下は、`-AllTasks` を指定したときだけ取ります。トリガーと操作の書き方は [Export-TaskList](../Export-TaskList/README.md#トリガーの書き方) と同じです
- **インストール済みソフト**：Windows の「プログラムと機能」に出るものです（コンピューター全体にインストールしたものだけ。実行したユーザーの分は、ユーザーによって変わるので取りません）。同じ名前で複数のバージョンがあるときは、バージョンをまとめて 1 行にします
- **更新プログラム**：`Win32_QuickFixEngineering` の一覧です。新しい累積更新を入れると、古いものが一覧から消えて「削除」に出ることがあります
- **ルーティング**：マルチキャスト、リンクローカル、ループバックは取りません
- **hosts ファイル**：コメントと空行を除いて、アドレスとホスト名の組ごとに 1 行にします
- **環境変数**：システムの環境変数だけです。ユーザーの環境変数は取りません
- **ファイアウォール**：グループポリシーの分も含めて、実際に効いている規則（`ActiveStore`）を取ります。規則が多いと、取るのに数十秒かかることがあります
- **ローカルユーザー・グループ**：ドメインコントローラーにはローカルユーザーがないので取らず、`skipped.csv` に「対象外」と残します。名前を解決できないメンバーは、SID のまま書きます
- **共有フォルダ**：管理共有（`ADMIN$`、`C$` など）も取ります。アクセス権は比べません

## 比べ方

| 結果 | 意味 |
| --- | --- |
| 追加 | 比較にだけある |
| 削除 | 基準にだけある |
| 変更 | 両方にあって、比べる値が違う |
| 参考 | 違いはあるが、通常の動きでも起きるもの（下記）。結果の件数と終了コードでは、違いに数えません |
| 比べられない | 片方でも取れなかった項目。中身は比べません（すべて「追加」や「削除」に見えるのを防ぐためです） |

次のものを「参考」にします。

- スタートアップが基準と比較のどちらも「手動」のサービスで、状態だけが変わったもの（必要なときだけ起動して止まるサービスが多いためです）
- 49152 番以上のポートの追加・削除・変更（Windows が動的に割り当てる範囲で、再起動のたびに変わります）

比べ方のそのほかの決まりは次のとおりです。

- 突き合わせでは、大文字と小文字を区別しません。値の比較では区別します
- 順序に意味のない値（IP アドレス、サービスの一覧、バージョンの一覧など）は、並べ替えてから比べます。DNS サーバーは順序に意味があるので、そのまま比べます
- スナップショットには、OS の言語に左右されない形（`実行中` `停止` など、このツールが決めた言葉）で書きます。表示の言語が違うサーバーどうしでも比べられます

`-Snapshot` で保存したときは、次のように表示します。

```
作業前後スナップショット比較 (Compare-SystemState 1.0.0)
スナップショットを保存します
SERVER01   2026-11-03 22:00:00   管理者: はい

 サービス               248
 待ち受けポート          31
 タスク                  12
 （中略）
 ファイアウォール       512

所要 18.2秒
保存先: C:\tools\SystemSnapshot_SERVER01_20261103_220000

作業の後で、次のコマンドで比べられます:
powershell -ExecutionPolicy Bypass -File C:\tools\Compare-SystemState.ps1 -Reference C:\tools\SystemSnapshot_SERVER01_20261103_220000
```

比べたときは、次のように表示します。

```
作業前後スナップショット比較 (Compare-SystemState 1.0.0)
基準: SERVER01 2026-11-03 22:00:00（管理者: はい）  C:\tools\SystemSnapshot_SERVER01_20261103_220000
比較: 今の状態 SERVER01 2026-11-03 23:30:00（管理者: はい）
再起動: あり（基準 2026-10-28 08:01:00 → 比較 2026-11-03 23:05:00）
OS: 10.0.20348.2700 → 10.0.20348.2849

■ 項目ごとの件数
 項目              基準  比較  追加  削除  変更  参考
 サービス           248   249     1     0     1     3
 待ち受けポート      31    32     1     0     0     6
 タスク              12    12     0     0     0     0
 更新プログラム      18    19     1     0     0     0
 （中略）

■ 違い（項目の順）
 結果  項目            対象              変わった内容
 追加  サービス        Tomcat9           自動・実行中・LocalService
 変更  サービス        W3SVC             状態: 実行中 → 停止
 追加  待ち受けポート  TCP 0.0.0.0:8080  java.exe・Tomcat9
 追加  更新プログラム  KB5044281

結果: 違いあり   追加 3 件  削除 0 件  変更 1 件  参考 9 件   所要 16.4秒
保存先: C:\tools\SystemDiff_SERVER01_20261103_233000
```

表示の決まりは次のとおりです。

- 結果の行は「違いあり」「違いなし」のどちらかです。違いがなくても、比べられない項目があるときは「違いなし（ただし、比べられなかった項目が 2 件あります。skipped.csv を確認してください）」と表示します
- 「追加」と「削除」は対象ごとに 1 件、「変更」は変わった値ごとに 1 件と数えます
- 「参考」は、件数だけを画面に表示します。中身は `differences.csv` に書きます
- 画面に表示する違いは 200 件までです。超えた分は「（ほか 1,234 件は differences.csv を参照してください）」と表示します。`-NoSave` のときと、保存できなかったときは、すべて表示します
- **パスワードが含まれることのある値は、画面に表示しません。** タスクの操作、サービスの実行ファイル、環境変数の値は「操作が変わりました」とだけ表示し、値は CSV にだけ書きます
- 再起動の行は、基準と比較の最終起動日時を比べて「あり」か「なし」を表示します。OS の行は、ビルド番号が変わったときだけ表示します。どちらも、終了コードでは違いに数えません
- 取っている間は、進み具合を表示します
- 条件によって、次の行も表示します
  - 基準と比較のホスト名が違うとき：「※ 違うコンピューターの状態を比べています。名前や IP アドレスの違いも出ます」
  - 基準と比較で、管理者かどうかが違うとき：「※ 基準と比較で、管理者かどうかが違います。取れる情報の違いが、違いとして出ることがあります」
  - 管理者として実行していないとき：「※ 管理者として実行すると、取れる情報が増えます」
  - 比べられない項目があるとき：「比べられない項目 2 件（skipped.csv を確認してください）」

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 違いがなかった（すべて比べられた）。`-Snapshot` で保存できたときも 0 |
| 2 | 違いがあった（追加・削除・変更）。「参考」は違いに含めません |
| 1 | 引数の誤りなどで、比べる前に止まった。または、違いはなかったが、比べられない項目がある |

違いがあって、比べられない項目もあるときは 2 です。

## 保存されるファイル

### スナップショット

`-Snapshot` で実行すると、保存先に `SystemSnapshot_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `info.txt` | 保存したときの情報（ツールのバージョン、ホスト名、日時、管理者かどうか、OS、最終起動日時、タスクの範囲、項目ごとの取得の結果）。`項目 = 値` の形です |
| `services.csv` | サービス |
| `ports.csv` | 待ち受けポート |
| `tasks.csv` | タスク |
| `software.csv` | インストール済みソフト |
| `hotfixes.csv` | 更新プログラム |
| `network.csv` | ネットワーク設定 |
| `routes.csv` | ルーティング |
| `shares.csv` | 共有フォルダ |
| `localusers.csv` | ローカルユーザー |
| `localgroups.csv` | ローカルグループのメンバー |
| `hosts.csv` | hosts ファイル |
| `environment.csv` | システムの環境変数 |
| `firewall.csv` | ファイアウォール |
| `skipped.csv` | 取れなかった項目と、その理由 |

### 比べた結果

比べると、保存先に `SystemDiff_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容。違いは 200 件を超えても省略しません |
| `differences.csv` | 違いの一覧（参考を含む） |
| `skipped.csv` | 比べられなかった項目と、その理由 |
| `snapshot\` | 比べたときの今の状態のスナップショット（上と同じ形）。`-Difference` を指定したときは作りません。次の作業の `-Reference` にも使えます |

CSV は BOM 付き UTF-8 で保存するため、Excel でダブルクリックすればそのまま開けます。比べるときに保存先に書き込めないときは警告を表示し、画面表示だけで終了します。`-Snapshot` のときは、エラーで止まります。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `differences.csv` | 結果、項目、対象、属性、基準の値、比較の値、備考 |
| `skipped.csv` | 理由、項目、詳細 |
| `services.csv` | サービス名、表示名、状態、スタートアップ、実行ユーザー、実行ファイル |
| `ports.csv` | プロトコル、ローカルアドレス、ポート、プロセス名、サービス |
| `tasks.csv` | パス、有効、実行ユーザー、トリガー、操作 |
| `software.csv` | 名前、ビット、バージョン、発行元 |
| `hotfixes.csv` | KB 番号、種類、インストール日 |
| `network.csv` | 接続の名前、アダプター、MAC アドレス、DHCP、IP アドレス、サブネット、ゲートウェイ、DNS サーバー |
| `routes.csv` | 宛先、ゲートウェイ、接続の名前、メトリック |
| `shares.csv` | 共有名、パス、説明 |
| `localusers.csv` | ユーザー名、有効、パスワードの期限、説明 |
| `localgroups.csv` | グループ名、メンバー名 |
| `hosts.csv` | アドレス、ホスト名 |
| `environment.csv` | 変数名、値 |
| `firewall.csv` | 種類、ID、表示名、有効、方向、操作、プロファイル、プロトコル、ローカルポート、リモートポート、プログラム、リモートアドレス |

- `differences.csv` では、変更のあった値を 1 つにつき 1 行ずつ書きます。属性はその値の名前です（`状態` など）。追加と削除は、対象ごとに 1 行にまとめ、属性を空欄にして、値を `状態=実行中 / スタートアップ=自動` の形で書きます
- 備考には、参考にした理由などを書きます
- `skipped.csv` の理由は、「権限なし」「対象外」「スナップショットにない」「読めない」「その他のエラー」のいずれかです
- 名前や値のうち、Excel で数値・日付・数式に変わるものは、`="..."` の形で書きます。比べるときは、元の値に戻して読みます
- スナップショットの CSV は Excel で開けますが、Excel で上書き保存すると、比べるときに読めなくなることがあります。手で直さないでください

## 止まるとき

次の場合は、エラーを表示して止まります（終了コード 1）。項目が取れないだけでは止まりません。

| 場合 | 表示の例 |
| --- | --- |
| `-Snapshot` も `-Reference` も指定していない | 「作業の前は -Snapshot を、作業の後は -Reference を指定してください」 |
| `-Snapshot` と一緒に `-Reference`・`-Difference`・`-NoSave` を指定した | 「-Snapshot のときは、-Reference は指定できません」 |
| `-Snapshot` のとき以外に `-AllTasks` を指定した | 「-AllTasks は、-Snapshot のときだけ指定できます」 |
| `-Difference` だけを指定した | 「-Difference を使うときは、-Reference も指定してください」 |
| 値に `"` が残っている（コマンドプロンプトで `"C:\data\"` のように最後を `\"` にした） | 「-Reference の値に引用符（"）が残っています: …」と、正しい書き方 |
| フォルダが見つからない | 「基準のフォルダを開けません: C:\tools\SystemSnapshot_…」 |
| スナップショットとして読めない | 「スナップショットのフォルダとして読めません: D:\memo（Compare-SystemState の -Snapshot で保存したフォルダを指定してください）」 |
| 基準と比較が同じフォルダ | 「基準と比較が同じフォルダです: …」 |
| `-Item` の値が誤っている | 「-Item の値が正しくありません: Servce（使える値: Service, Port, …）」 |
| `-Item` の項目が基準のスナップショットにない | 「基準のスナップショットに、次の項目がありません: Firewall」 |
| 制約付き言語モード（AppLocker や WDAC の環境） | 「制約付き言語モードでは使えません（AppLocker や WDAC でスクリプトの実行が制限されている環境です）」 |

スナップショットの中の 1 つの CSV だけが読めないときは、止まらずに、その項目を「比べられない」にして `skipped.csv` に残します。

## 情報の取り方

| 項目 | 取り方 |
| --- | --- |
| サービス、ネットワーク設定、更新プログラム、共有フォルダ、ローカルユーザー、ローカルグループ | CIM（`Win32_Service`、`Win32_NetworkAdapterConfiguration`、`Win32_QuickFixEngineering`、`Win32_Share`、`Win32_UserAccount`、`Win32_Group`）。ユーザーごとのサービスの判定はレジストリ、グループのメンバーは WinNT プロバイダー（`Get-LocalGroupMember` は名前を解決できないメンバーがあると失敗するため） |
| 待ち受けポート | `Get-NetTCPConnection`、`Get-NetUDPEndpoint` |
| タスク | COM の `Schedule.Service` |
| インストール済みソフト、環境変数 | レジストリ（`HKLM` の `Uninstall`、`Session Manager\Environment`） |
| ルーティング | `Get-NetRoute` |
| ファイアウォール | `Get-NetFirewallRule`、`Get-NetFirewallProfile` と各フィルターの一括取得 |
| hosts ファイル | `%SystemRoot%\System32\drivers\etc\hosts` を読む |

すべて Windows に最初から入っている機能です。ネットワークには出ません（ドメインのメンバー名を解決するときに、ドメインコントローラーに問い合わせることはあります）。

## 使うときの注意

- **管理者として実行してください。** 管理者でないと、ほかのユーザーのタスク、プロセスの情報、ファイアウォールの一部などが取れません。作業の前と後は、同じ権限で実行してください
- **スナップショットの扱いに注意してください。** タスクの引数、サービスのコマンドライン、環境変数には、パスワードなどが含まれることがあります。また、サーバーの構成がそのまま分かる情報です。社外に持ち出すときは中身を確かめてください
- **作業と関係のない変化も出ます。** Windows Update や、ウイルス対策ソフトの更新、再起動によって、作業と関係のないものが変わることがあります。作業の直前と直後に実行すると、紛れにくくなります
- **ファイルの中身は比べません。** フォルダの中身が変わったかどうかは、[Compare-Folder](../Compare-Folder/README.md) を使ってください
- 設定を読むだけなので、レジストリ全体やアプリの設定ファイルの変更は検知しません
- 実行した PC の状態だけを取ります。別のサーバーの状態は、そのサーバーの上で実行してください
- 途中で中断（Ctrl+C）した場合は、結果を保存しません
