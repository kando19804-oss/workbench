# Test-Connectivity（疎通一括確認）

複数のサーバーについて、名前解決・ping・TCP ポートへの接続を一度に確かめます。結果は画面に表示し、CSV にも保存します。

「作業の前後で、関係するサーバーとポートにつながるかを確かめて記録したい」「障害のときに、どこまで届いているかを切り分けたい」というときのための道具です。調べる相手に変更を加えることはありません。

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Test-Connectivity.ps1 -List .\targets.csv
```

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# 対象のひな形（targets.csv）を作る
powershell -ExecutionPolicy Bypass -File .\Test-Connectivity.ps1 -NewList .\targets.csv

# CSV に書いた対象を確かめる
powershell -ExecutionPolicy Bypass -File .\Test-Connectivity.ps1 -List .\targets.csv

# その場で数件だけ確かめる（ポートを書かなければ ping だけ）
powershell -ExecutionPolicy Bypass -File .\Test-Connectivity.ps1 -Target "web01:443,db01:1433,192.168.1.1"

# 5 秒ごとに確かめ続け、つながる・つながらないが変わったときだけ表示する（Ctrl+C で終わる）
powershell -ExecutionPolicy Bypass -File .\Test-Connectivity.ps1 -List .\targets.csv -Repeat 5

# 待ち時間を 5 秒にする（遠い拠点や遅い回線のとき）
powershell -ExecutionPolicy Bypass -File .\Test-Connectivity.ps1 -List .\targets.csv -Timeout 5

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Test-Connectivity.ps1 -Target "web01:443" -NoSave
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-List` | 対象を書いた CSV ファイル（[対象の書き方](#対象の書き方)を参照） | 指定なし |
| `-Target` | 対象をコマンドラインで指定します。`ホスト` か `ホスト:ポート` を、`"web01:443,db01:1433"` のようにカンマで区切って1つの文字列にします。`-List` と一緒に指定すると、両方を確かめます | 指定なし |
| `-Timeout` | 1 件あたりの待ち時間（秒）。名前解決・ping・TCP の接続それぞれに適用します。1～60 で指定します | 2 |
| `-Repeat` | 指定した秒数ごとに、Ctrl+C で止めるまで確かめ続けます（[繰り返し確かめるとき](#繰り返し確かめるとき)を参照）。1～3600 で指定します | 指定なし（1 回だけ） |
| `-NewList` | 対象のひな形の CSV を作って終わります。同じ名前のファイルがあるときは、上書きせずに止まります | 指定なし |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします | なし |
| `-ConfigFile` | 設定ファイルのパス（[設定ファイル](#設定ファイル)を参照）。コマンドラインで指定した値は、設定ファイルより優先します | 指定なし |

`-List` と `-Target` のどちらかは必ず指定してください（設定ファイルに書いてもかまいません）。

## 対象の書き方

### CSV ファイル（-List）

Excel やメモ帳で、次のような CSV を作ります。`-NewList` で作ったひな形を書き換えると簡単です。

```csv
ホスト,ポート,メモ
# 先頭が # の行は確かめません,,
web01,443,Web サーバー（HTTPS）
db01,1433,SQL Server
192.168.1.1,,ゲートウェイ（ping だけ）
fileserver.example.local,445,ファイル共有
```

- 1 行目は見出しです。`ホスト` の列は必須、`ポート` と `メモ` の列は省略できます。英語の見出し（`Host`、`Port`、`Memo`）でもかまいません
- ホストには、コンピューター名・FQDN・IPv4 アドレス・IPv6 アドレスを書けます
- ポートは 1～65535 の数値です。空欄にすると ping だけを確かめます。1 つのホストで複数のポートを確かめるときは、行を分けて書きます
- ホストが空の行と、ホストが `#` で始まる行は飛ばします
- メモに Excel のセル内改行（Alt+Enter）があるときは、空白に置き換えます
- 値の途中の `"`（`19" ラック` など）は、そのままの文字として読みます。`"` で始めた値は、`"` で閉じてください
- 文字コードは、UTF-8（BOM の有無は問いません）、Shift_JIS、UTF-16 のどれでも読めます。Excel の「CSV（コンマ区切り）」で保存したもの（Shift_JIS）もそのまま読めます

書き間違いがあると、確かめ始める前にエラーを表示して止まります。

```
対象の CSV の 4 行目: ポートは 1～65535 の数値で指定してください: 14333
ファイル: C:\tools\targets.csv
```

| 場合 | 表示の例 |
| --- | --- |
| ファイルが見つからない | 「対象の CSV が見つかりません: C:\tools\targets.csv」 |
| `ホスト`（`Host`）の列がない | 「対象の CSV に「ホスト」の列がありません。1 行目を見出し（ホスト,ポート,メモ）にしてください」 |
| ポートが数値でない、または範囲外 | 上の例のとおり |
| `"` で始めた値が閉じていない | 「対象の CSV の 3 行目: 引用符（"）が閉じていません」 |
| 確かめる対象が 1 件もない | 「確かめる対象がありません」 |

### コマンドライン（-Target）

- `web01`（ping だけ）、`web01:443`、`192.168.1.1:3389` のように書きます
- IPv6 アドレスにポートを付けるときは、`[fe80::1]:443` のように `[ ]` で囲みます
- 書き間違いがあると、確かめ始める前に止まります（「-Target の 2 つ目: ポートは 1～65535 の数値で指定してください: db01:abc」）

`-List` と `-Target` を両方指定したときは、CSV の対象、`-Target` の対象の順に番号を付けます。

## 確かめる内容と判定

1 つの対象について、次の順に確かめます。

1. **名前解決**：ホストを IP アドレスに変えます。IPv4 のアドレスがあれば、それを使います。名前解決できなかったときは、ping と TCP は確かめずに NG にします。ホストに `192.168.1.1` のような 4 つの数字の IPv4 アドレスか、`:` を含む IPv6 アドレスを書いたときは、名前解決をせずにそのまま使います。`192.168.001.010` のように 0 を付けて桁をそろえた書き方も、10 進数として読みます（192.168.1.10）
2. **ping**：1 回だけ送り、応答があれば応答時間を表示します
3. **TCP**：ポートを指定した対象だけ、そのポートに接続できるかを確かめます。接続できたら、すぐに切断します（データは送りません）

判定は次のとおりです。

| 対象 | OK の条件 |
| --- | --- |
| ポートを指定した対象 | TCP で接続できた（ping の結果は問いません） |
| ポートを指定しない対象 | ping に応答があった |

ping を止めているサーバー（Windows の既定のファイアウォールなど）でも、ポートにつながれば OK にするためです。

TCP の結果は、次の 3 つに分けて表示します。切り分けの手がかりにしてください。

| TCP の結果 | 考えられること |
| --- | --- |
| 接続できた | ポートで待ち受けているサービスに届いています |
| 拒否された | 相手のコンピューターには届いていますが、そのポートで待ち受けているサービスがありません（サービスが止まっている、ポート番号の誤りなど） |
| タイムアウト | 途中のファイアウォールなどで止められているか、相手が応答していません |

すべての対象を同時に確かめます（最大 50 件ずつ）。そのため、対象が多くても、50 件ごとに長くて `-Timeout` の 2 倍ほど（名前解決と、ping・TCP のそれぞれで待つため）で終わります。

## 画面の表示例

```
疎通一括確認 (Test-Connectivity 1.0.0)
実行元: PC01（192.168.1.10）   2026-10-31 14:05:12
DNS サーバー: 192.168.1.1   デフォルトゲートウェイ: 192.168.1.1
対象: C:\tools\targets.csv（4 件）、-Target（1 件）   タイムアウト 2 秒
結果: OK 3 件  NG 2 件   所要 2.1秒

 No  判定  ホスト    IP アドレス   ping      ポート  TCP           メモ
  1  OK    web01     192.168.1.21  1 ms         443  接続できた    Web サーバー（HTTPS）
  2  NG    db01      192.168.1.31  応答なし    1433  タイムアウト  SQL Server
  3  OK    fs01      192.168.1.41  2 ms         445  接続できた    ファイル共有
  4  NG    old-srv   名前解決失敗  -                 -
  5  OK    10.0.0.1  10.0.0.1      3 ms              -

保存先: C:\tools\Connectivity_PC01_20261031_140512
```

- NG の行は赤で表示します
- 全角文字は 2 文字分の幅として数え、列をそろえます
- 実行元の IP アドレス、DNS サーバー、デフォルトゲートウェイは、有効なネットワークアダプターのものを表示します。複数あるときは `, ` で区切ります。DNS サーバーとデフォルトゲートウェイがどちらも取れないときは、その行を表示しません
- `-ConfigFile` を指定したときは、「対象」の前の行に「設定ファイル: C:\tools\check.ini」を表示します

## 繰り返し確かめるとき

`-Repeat` を指定すると、指定した秒数ごとに、Ctrl+C で止めるまで確かめ続けます。サーバーを再起動したあとに戻ってきたかを見るときや、断続的に切れる回線を見張るときに使います。

```
（1 回目は、上の表示例と同じ表を表示します）

5 秒ごとに確かめています。止めるときは Ctrl+C を押してください。
14:06:12  NG → OK  2  db01:1433  タイムアウト → 接続できた
14:09:47  OK → NG  5  10.0.0.1   応答あり → 応答なし
（確認 48 回目  OK 5 件  NG 0 件）
```

- 2 回目からは、判定が変わった対象だけを 1 行ずつ表示します。最後の行には、何回目かと、いまの OK・NG の件数を表示します
- 1 回の確認にかかった時間が `-Repeat` より長いときは、終わってすぐに次の確認を始めます
- Ctrl+C で止めたときも、それまでの結果を保存します（1 回だけ確かめるときと違い、途中で止めるのが通常の終わり方のため）。終了コードは、最後の確認の結果で決まります。ただし、入力をリダイレクトして起動したとき（コンソールがないとき）は、Ctrl+C で PowerShell ごと止まるため、結果は保存しますが、終了コードは最後の確認の結果になりません
- Ctrl+C は、次の確認を待っている間に受け付けます。確認の途中で押したときは、その確認が終わってから止まります

## 保存されるファイル

実行するたびに、保存先に `Connectivity_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容（実行元・条件・結果の表）。`-Repeat` のときは、最後の確認の表と、変化の一覧 |
| `results.csv` | 対象ごとの結果。`-Repeat` のときは、最後の確認の結果 |
| `changes.csv` | `-Repeat` のときだけ。判定が変わった記録。変わるたびに書き足すので、途中で PC が止まっても、それまでの記録は残ります |

CSV は BOM 付き UTF-8 で保存するため、Excel でダブルクリックすればそのまま開けます。保存先に書き込めないときは警告を表示し、画面表示だけで続けます。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `results.csv` | No、判定、ホスト、IP アドレス、ping、応答時間(ms)、ポート、TCP、接続時間(ms)、メモ、確認日時、詳細 |
| `changes.csv` | 日時、No、ホスト、ポート、変化前、変化後、詳細 |

- ping の列は「応答あり」「応答なし」「-」（名前解決できなかったとき）のどれかです
- 接続時間は、数十ミリ秒ほどの誤差を含む、おおよその値です（多くの対象を同時に確かめるため）。応答時間は ping の結果の値です
- TCP の列は「接続できた」「拒否された」「タイムアウト」「エラー」「-」（ポートを指定しないとき、または名前解決できなかったとき）のどれかです
- 詳細の列には、名前解決できなかったとき、ping を送れなかったとき、TCP が「エラー」のときの理由を書きます
- ホストとメモは、`="..."` の形で出力します。Excel で `001` や `2026-10-31` のような値が、数値や日付に変わらないようにするためです。ただし、255 文字を超える値は Excel の式に書けないため、そのまま出力します

## 設定ファイル

同じ条件で繰り返し確かめるときは、パラメーターを設定ファイルにまとめておけます。設定ファイルを使わなくても、パラメーターだけで動きます。

```ini
# Test-Connectivity の設定ファイル
List = targets.csv
Timeout = 3
OutputFolder = \\fileserver\evidence\%COMPUTERNAME%
```

- 書ける項目は、`List`、`Target`、`Timeout`、`Repeat`、`OutputFolder`、`NoSave` です（`NewList` は書けません）
- `List` と `OutputFolder` に相対パスを書くと、設定ファイルのあるフォルダを基準にします
- そのほかの書き方と、書き間違いがあったときの動きは、[Get-DiskUsage の設定ファイル](../Get-DiskUsage/README.md#設定ファイル)と同じです

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | すべての対象が OK |
| 2 | NG の対象がある（`-Repeat` のときは、最後の確認で NG があった） |
| 1 | 引数や対象の CSV の誤りなどで、確かめられなかった |

タスクスケジューラやバッチファイルから、結果を判定するのに使えます。

## 注意

- 確かめるのは、このツールを実行したコンピューターからの到達性です。プロキシを経由する接続は確かめられません
- UDP のポートは確かめられません（応答がないのが正常なサービスがあるためです）
- 多数の対象に短い間隔で `-Repeat` を使うと、相手のセキュリティ製品にポートスキャンとみなされることがあります。必要な対象と間隔にしぼってください
- 名前解決は、OS の設定（hosts ファイルと DNS）に従います
