# Find-DuplicateFile（重複ファイル検出）

指定したフォルダの中から、内容が同じファイルと、「報告書 - コピー.xlsx」のようにコピーらしい名前のファイルを洗い出します。結果は画面に表示し、CSV にも保存します。

「ファイルサーバーの容量を整理したいが、同じファイルがどこに何件あり、どれだけ減らせるのか分からない」「現場に残っているコピーのファイルを片づけたい」というときのための道具です。調べる場所のファイルを変更・削除することはありません。どのファイルを残すかは、結果を見て判断してください。

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Find-DuplicateFile.ps1 -Path D:\share
```

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# 2 つのフォルダをまたいで探す
powershell -ExecutionPolicy Bypass -File .\Find-DuplicateFile.ps1 -Path "D:\share,E:\archive"

# 小さなファイルも含めて、すべてのファイルを比べる
powershell -ExecutionPolicy Bypass -File .\Find-DuplicateFile.ps1 -Path D:\share -MinSize 1

# Excel と PDF だけを調べる
powershell -ExecutionPolicy Bypass -File .\Find-DuplicateFile.ps1 -Path D:\share -Include "*.xlsx,*.pdf"

# 最終更新から 1 年以上たったファイルだけを調べる
powershell -ExecutionPolicy Bypass -File .\Find-DuplicateFile.ps1 -Path D:\share -OlderThan 365

# ログと一部のフォルダを調べない
powershell -ExecutionPolicy Bypass -File .\Find-DuplicateFile.ps1 -Path D:\share -Exclude "*.log,logs,D:\share\system"

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Find-DuplicateFile.ps1 -Path D:\share -NoSave
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Path` | 調べるフォルダ。ドライブ（`D:\`）や共有フォルダ（`\\server\share`）も指定できます。複数指定するときは、`"D:\share,E:\archive"` のようにカンマで区切って 1 つの文字列にします。指定した文字列全体が 1 つのフォルダとして存在するときは、カンマを含む名前のフォルダとして扱います | 現在のフォルダ |
| `-MinSize` | 内容を比べるファイルの最小サイズ。`500KB`、`10MB`、`1.5GB` のように書きます。単位（`KB` `MB` `GB` `TB`）を書かないとバイトです。1 以上を指定します。[コピーらしい名前](#コピーらしい名前)の判定には使いません | `1MB` |
| `-Include` | 調べるファイルの名前。ワイルドカード（`*`）で、`"*.xlsx,*.pdf"` のようにカンマで区切って書きます。`*` 以外の文字（`[` `]` `?` など）は、そのままの文字として扱います。大文字と小文字は区別しません | 指定なし（すべてのファイル） |
| `-Exclude` | 調べないフォルダやファイル。ワイルドカード（`*`）で、カンマで区切って書きます（[除外の書き方](#除外の書き方)を参照） | 指定なし |
| `-OlderThan` | 最終更新から指定した日数以上たったファイルだけを調べます。1～36500 で指定します | 指定なし（すべてのファイル） |
| `-Top` | 画面に表示する件数。重複のグループと、コピーらしい名前のファイルのそれぞれに適用します。1～1000 で指定します | 20 |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします | なし |
| `-ConfigFile` | 設定ファイルのパス（[設定ファイル](#設定ファイル)を参照）。コマンドラインで指定した値は、設定ファイルより優先します | 指定なし |

### 除外の書き方

- `\` を含まない書き方は、フォルダ名・ファイル名に対して、どの階層でも当てはめます。`*.log` はすべての階層の `.log` ファイル、`logs` はすべての階層の `logs` フォルダ（と `logs` という名前のファイル）です
- `D:\` や `\\` で始まる書き方は、フルパスに当てはめます。`D:\share\system` はそのフォルダです
- それ以外の `\` を含む書き方は、`-Path` に指定した各フォルダから見た相対パスに当てはめます。`logs\*` は直下の `logs` フォルダの中身、`*\cache` は 2 階層目より下の `cache` です。`\logs` や `.\logs` のように先頭に付けると、直下の `logs` だけに当てはめます
- 末尾の `\` は無視します（`logs\` は `logs` と同じです）
- フォルダが除外に当てはまると、その中はすべて調べません
- `-Include` にも当てはまるときは、`-Exclude` を優先します
- `*` 以外の文字（`[` `]` `?` など）は、そのままの文字として扱います。大文字と小文字は区別しません

## 設定ファイル

同じ条件で繰り返し調べるときは、パラメーターを設定ファイルにまとめておけます。設定ファイルを使わなくても、パラメーターだけで動きます。

```ini
# Find-DuplicateFile の設定ファイル
# 「項目 = 値」の形で、1 行に 1 つずつ書きます。# か ; で始まる行はコメントです

# Path は、複数の行に分けて書けます（1 行に 1 つのフォルダを書きます）
Path = D:\share
Path = E:\archive

MinSize = 10MB
OlderThan = 365
Top = 50

# Include と Exclude は、カンマで区切っても、複数の行に分けて書いてもかまいません
Include = *.xlsx,*.pdf
Exclude = *.log
Exclude = D:\share\system

OutputFolder = .\記録
NoSave = false
```

- 書ける項目は、`Path`、`MinSize`、`Include`、`Exclude`、`OlderThan`、`Top`、`OutputFolder`、`NoSave` です
- `Path` の 1 行はカンマで区切りません。カンマを含む名前のフォルダは、設定ファイルならそのまま書けます
- `NoSave` は `true` か `false` で書きます
- コマンドラインで `-Path`、`-Include`、`-Exclude` を指定すると、設定ファイルの同じ項目は使いません（両方を合わせることはしません）
- 設定ファイルで指定した `NoSave = true` と `OlderThan` は、コマンドラインから取り消せません。元に戻したいときは、設定ファイルを直してください
- そのほかの書き方（空の値、引用符、コメント、環境変数、相対パス、文字コード）と、書き間違いがあったときの動きは、[Get-DiskUsage の設定ファイル](../Get-DiskUsage/README.md#設定ファイル)と同じです

## 保存されるファイル

実行するたびに、保存先に `DuplicateFile_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容（実行条件・件数）。重複のグループとコピーらしい名前のファイルは、`-Top` を超えても省略しません |
| `groups.csv` | 重複のグループの一覧（減らせる容量の大きい順） |
| `duplicates.csv` | 重複のファイルの一覧（グループの順、グループの中は最終更新の古い順） |
| `copynames.csv` | コピーらしい名前のファイルの一覧 |
| `skipped.csv` | 調べられなかった場所・調べなかった場所と、その理由 |

CSV は BOM 付き UTF-8 で保存するため、Excel でダブルクリックすればそのまま開けます。保存先に書き込めないときは警告を表示し、画面表示だけで終了します。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `groups.csv` | グループ、件数、実体の数、1 件のサイズ(MB)、1 件のサイズ(バイト)、減らせる容量(MB)、減らせる容量(バイト)、ハッシュ |
| `duplicates.csv` | グループ、実体、ファイル、ファイル名、サイズ(MB)、サイズ(バイト)、最終更新日時、ハッシュ |
| `copynames.csv` | 名前の形、元との比較、ファイル、元と思われるファイル、サイズ(MB)、サイズ(バイト)、元のサイズ(バイト)、最終更新日時、元の最終更新日時、備考 |
| `skipped.csv` | 理由、パス、詳細 |

- サイズは `156,723,000` のように 3 桁区切りで出力します（Excel で 12 桁を超える値が指数表示にならないように）
- ハッシュは、SHA-256 の値を大文字の 16 進数で書きます（PowerShell の `Get-FileHash` と同じ形です）
- `duplicates.csv` の実体は、グループの中で振った番号です。同じ番号のファイルは、ハードリンクで実体を共有しています
- `copynames.csv` の名前の形は「コピー」「番号付き」「古い版」「日付付き」のどれかです。元との比較は「同じ」「違う」「元が見つからない」「比べられなかった」のどれかで、「比べられなかった」ときは理由を備考に書きます
- ファイル名のうち、Excel で数値・日付・数式に変わるもの（`2026-10-31`、`001`、`-old` など）は、`="..."` の形で書きます。Excel ではそのまま表示されます
- `skipped.csv` の理由は、「権限なし」（アクセスを拒否されたフォルダとファイル）「読めない」（ほかのプログラムが使っているなどで、ファイルを開けなかった）「オンライン専用」「調査中に変更」「リンク」「除外指定」「その他のエラー」のいずれかです

## 調べ方

### 内容が同じファイル

1. フォルダをたどって、すべてのファイルの一覧を作ります
2. `-MinSize` 以上で、サイズが同じファイルが 2 件以上あるものだけを残します
3. 残ったファイルの先頭 64 KB のハッシュを比べて、さらに絞ります
4. 残ったファイルの全体を読み、SHA-256 のハッシュが同じものを、同じ内容とします

- ファイル名と更新日時は判定に使いません。名前を変えたコピーも見つかります
- サイズが同じ相手がいないファイルは読みません。ファイルの内容を読むのは、絞り込みで残ったものだけです
- 減らせる容量は、`1 件のサイズ ×（実体の数 - 1）` です。同じ内容のファイルを 1 つだけ残した場合に空く容量の目安です

### コピーらしい名前

ファイル名の形から、コピーらしいファイルを探します。同じフォルダに「元と思われるファイル」があれば、内容も比べます。

| 名前の形 | 当てはまる名前（元は `報告書.xlsx`） | 元が見つからないとき |
| --- | --- | --- |
| コピー | `報告書 - コピー.xlsx`、`報告書 - コピー (2).xlsx`、`報告書のコピー.xlsx`、`コピー ～ 報告書.xlsx`、`コピー (2) ～ 報告書.xlsx`、`報告書 - Copy.xlsx`、`報告書 - Copy (2).xlsx`、`Copy of 報告書.xlsx`、`Copy (2) of 報告書.xlsx` | 一覧に出す |
| 番号付き | `報告書 (1).xlsx`、`報告書(1).xlsx`、`報告書（1）.xlsx` | 一覧に出さない |
| 古い版 | `報告書_old.xlsx`、`報告書-old.xlsx`、`報告書 old.xlsx`（`old` のほか `bak` `backup` `旧` `古` `バックアップ` `控え`）、`報告書.xlsx.bak`、`報告書.xlsx.old`、`報告書.bak`、`報告書.old` | 一覧に出す |
| 日付付き | `報告書_20261102.xlsx`、`報告書-2026-11-02.xlsx`、`報告書 261102.xlsx`、`報告書_1102.xlsx`（区切りは `_` `-` スペース。日付として正しい数字だけ） | 一覧に出さない |

- 元は、当てはまった部分を取り除いた名前のファイルを、同じフォルダの中だけで探します。別のフォルダへ移したコピーは、「元が見つからない」になります
- `報告書.bak` と `報告書.old` は、拡張子だけが違う `報告書.*` のファイルが同じフォルダに 1 つだけあれば、それを元とします
- `報告書 - コピー - コピー.xlsx` のようにコピーの形が重なっているときは、すべて取り除いて元を探します。そのほかの形は 1 回だけ取り除きます
- 元との比較は、サイズが違えば「違う」とします（ファイルを読みません）。サイズが同じならハッシュで比べます。元が見つからないコピーは、調べている間になくなったものでも一覧に残ります
- 番号付きと日付付きは、連番の資料や定期的な帳票でも普通に使う名前のため、元があるものだけを出します
- 名前の判定に `-MinSize` は使いません。小さな Office 文書のコピーも見つけるためです。`-Include`、`-Exclude`、`-OlderThan` は使います。ただし、元は `-Include` と `-OlderThan` に当てはまらなくても探します（`-Exclude` で除外したファイルは、元になりません）
- 名前の形は目安です。**一覧に載っていても、不要なファイルとは限りません。**特に「違う」ものは、元より新しい内容を含んでいることがあります
- コピーらしい名前の一覧は、減らせる容量と終了コードには数えません（元と比べるときに読めなかったファイルは、[終了コード](#終了コード)の「読めなかった場所」に数えます）。`-MinSize` 以上で、元も調べる対象のときは、重複のグループにも載ります

名前の一部だけが違うファイル（`報告書_最新.xlsx`、`報告書_修正版.xlsx` など）を、名前の似ている度合いで探すことはしません。時間がかかるうえ、`第1回.docx` と `第2回.docx` のような別のファイルが大量に出るためです。

### ハードリンク

ハードリンクは、1 つの実体に複数の名前を付けたものです。消しても容量は空かないため、同じ実体のファイルは減らせる容量に 1 つとして数えます。すべてが同じ実体のグループ（消しても容量が空かない）は、重複には出さず、件数だけを表示します。

判定できるのは、重複のグループに残ったファイルだけです。判定には Windows の機能を PowerShell の中から呼び出します。セキュリティの設定などで呼び出せないときや、ファイルシステムが判定に対応していないときは、ハードリンクとして数えずに続け、画面にそのことを表示します。

### 飛ばすもの

- **リンク**：ジャンクションやシンボリックリンクはたどりません。無限ループや、同じファイルを二重に数えることを防ぐためです。OneDrive のフォルダは、リンクではなく普通のフォルダとして調べます
- **0 バイトのファイル**：内容の比較には使いません（コピーらしい名前の判定には使います）
- **オンライン専用ファイル**：OneDrive などのオンライン専用ファイルは、読むとダウンロードが始まるため、内容を比べません。比べる必要があったものを `skipped.csv` に残します
- **読めないフォルダ**：権限がなくて読めないフォルダは飛ばして、件数を表示します
- **開けないファイル**：権限がないファイルや、ほかのプログラムが使っていて開けないファイルは、飛ばして `skipped.csv` に残します
- **ごみ箱とシステムの管理用のフォルダ**：`$RECYCLE.BIN` と `System Volume Information` は調べず、`skipped.csv` に「除外指定」として残します
- **日時が壊れたファイル**：更新日時が範囲外のファイルは、日時を読む必要があったときに、飛ばして `skipped.csv` に「その他のエラー」として残します
- **調査中に変わったファイル**：内容を読んでいる間にサイズか更新日時が変わったファイルと、読む前になくなったファイルは、比べずに `skipped.csv` に残します。一覧を作った後、読む前に変わっただけのファイルは、その時点の内容で比べます
- **このツールの結果**：調べるフォルダの中に、このツールの結果のフォルダ（`DuplicateFile_<ホスト名>_<日時>` の形の名前）があっても、その中は調べず、`skipped.csv` に「除外指定」として残します。`DuplicateFile_backup` のようなほかの名前のフォルダは調べます
- 隠しファイルとシステムファイルも調べます。260 文字を超える長いパスや、名前に `[` `]` を含むフォルダ・ファイルも調べます
- 途中で中断（Ctrl+C）した場合は、結果を保存しません

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 内容が同じファイルがなかった（すべて調べられた） |
| 2 | 内容が同じファイルがあった |
| 1 | 引数の誤りなどで、調べる前に止まった。または、重複はなかったが、読めなかった場所がある |

重複があって、読めなかった場所もあるときは 2 です。リンクと除外指定は、読めなかった場所に数えません。

## 止まるとき

次の場合は、調べ始める前にエラーを表示して止まります（終了コード 1）。

| 場合 | 表示の例 |
| --- | --- |
| 値に `"` が残っている（コマンドプロンプトで `"C:\data\"` のように最後を `\"` にした） | 「-Path の値に引用符（"）が残っています: …」と、正しい書き方 |
| フォルダが見つからない・開けない | 「フォルダを開けません: D:\share」 |
| 同じフォルダを 2 回指定した | 「同じフォルダが 2 回指定されています: D:\share」 |
| 片方がもう片方の中にある（`D:\share` と `D:\share\経理` など） | 「指定したフォルダの片方が、もう片方の中にあります。同じファイルを二重に数えてしまいます。」 |
| `-MinSize` の書き方が正しくない | 「-MinSize は 500KB、10MB のように指定してください: 10M」 |
| 設定ファイルの書き間違い | 何行目かを表示します（Get-DiskUsage と同じ） |

## 共有フォルダを調べるとき

- `\\サーバー名\共有名` の形で指定してください。管理者として開いた PowerShell からは、通常の権限で割り当てたネットワークドライブ（`Z:` など）が見えないことがあります
- 実行したユーザーの権限で読みます。読めない場所は飛ばします
- ファイルの内容をネットワーク越しに読むため、時間がかかります。ファイルサーバーにログオンできる場合は、サーバー上でローカルのパス（`D:\share` など）を指定して実行するほうが速く終わります

## 使うときの注意

- **消す前に、必ず中身と使われ方を確かめてください。**内容が同じでも、それぞれの場所で必要なファイルがあります。特に `C:\Windows` や `Program Files` の中の重複は、必要があって置かれているものです。消さないでください
- **同じ場所を別の名前で指定しないでください。**ネットワークドライブ（`Z:`）とその共有フォルダ（`\\server\share`）のような指定は、同じ場所だと判定できません。すべてのファイルが重複に見えますが、片方を消すともう片方も消えます
- **ログのローテーション**：`app.log` と `app_20261101.log` のようなファイルは、日付付きとして大量に出ることがあります。`-Exclude` で除いてください
- **減らせる容量は目安です。**NTFS の圧縮やデータ重複除去が有効なドライブ、オンライン専用ファイルでは、実際に空く容量と一致しません
- **書き込み中のファイルやハードリンクの別名**：フォルダの一覧のサイズが古いことがあり、同じ内容でも重複として見つからないことがあります
- **アクセス権・所有者・属性**は比べません。内容が同じでも、アクセス権が違うことがあります
- **フォルダの一覧をメモリに読み込む**ため、ファイルが多いとメモリを多く使います。ドライブ全体など数百万件を超えるときは、フォルダを分けて実行してください。ただし、分けるとフォルダをまたぐ重複は見つかりません
