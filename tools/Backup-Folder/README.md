# Backup-Folder（フォルダのバックアップ）

フォルダの中身を、USB メモリや別のドライブ、別の共有フォルダへ差分でコピーします。2 回目からは、変わったファイルだけをコピーします。コピーする前に、件数と容量を表示して確認を求めます。

「共有フォルダの資料を、定期的に USB メモリへ控えておきたい」というときのためのツールです。中身のコピーには、Windows に最初から入っている `robocopy` を使います。

- コピー元のファイルを変更・削除することはありません
- コピー先のファイルを削除することはありません。コピー元で削除したファイルも、コピー先には残ります

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Backup-Folder.ps1 -Source \\server01\共有\経理 -Destination E:\backup\経理
```

コピーするファイルの件数と容量が表示され、「コピーしますか？」と聞かれます。`Y` を入力するとコピーを始めます。

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# コピーする予定のファイルを確かめるだけで、コピーはしない
powershell -ExecutionPolicy Bypass -File .\Backup-Folder.ps1 -Source D:\data -Destination E:\backup\data -ListOnly

# 設定ファイルに書いたコピー元・コピー先で実行する
powershell -ExecutionPolicy Bypass -File .\Backup-Folder.ps1 -ConfigFile .\usb.ini

# 確認せずにコピーする（タスクスケジューラで定期的に実行するとき）
powershell -ExecutionPolicy Bypass -File C:\tools\Backup-Folder.ps1 -ConfigFile C:\tools\nightly.ini -Force

# ダブルクリック用の起動ファイルと、設定ファイルのひな形を作る
powershell -ExecutionPolicy Bypass -File .\Backup-Folder.ps1 -CreateLauncher
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Source` | コピー元のフォルダ。ドライブ（`D:\`）や共有フォルダ（`\\server\share`）も指定できます | なし（必須） |
| `-Destination` | コピー先のフォルダ。なければ作ります | なし（必須） |
| `-ListOnly` | コピーする予定のファイルの件数と容量を表示し、一覧を `files.csv` に保存するだけで、コピーしません。コピー先のフォルダも作りません | なし |
| `-Force` | 確認せずにコピーします。タスクスケジューラなど、画面を見ずに実行するときに使います | なし |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-ConfigFile` | 設定ファイルのパス（[設定ファイル](#設定ファイル)を参照）。コマンドラインで指定した値は、設定ファイルより優先します | 指定なし |
| `-CreateLauncher` | ダブルクリック用の起動ファイルと、設定ファイルのひな形を作ります（[担当者がダブルクリックで使えるようにする](#担当者がダブルクリックで使えるようにする)を参照）。コピーはしません | なし |

`-Source` と `-Destination` は、名前を省略して順に書くこともできます（`.\Backup-Folder.ps1 D:\data E:\backup\data`）。

## 設定ファイル

コピー元とコピー先を、設定ファイルにまとめておけます。設定ファイルは、`-ConfigFile` で指定したときだけ読みます。

```ini
# Backup-Folder の設定ファイル
# 「項目 = 値」の形で、1 行に 1 つずつ書きます。# か ; で始まる行はコメントです

Source = \\server01\共有\経理
Destination = E:\backup\経理
OutputFolder = .\記録
```

書ける項目は `Source`、`Destination`、`OutputFolder` の 3 つです。`-ListOnly` と `-Force` は、設定ファイルには書けません（確認なしでコピーする設定が、知らないうちに効いてしまうのを防ぐため）。

書き方の決まりは、[Get-DiskUsage の設定ファイル](../Get-DiskUsage/README.md#設定ファイル)と同じです。

- 大文字と小文字は区別しません。値は `"` で囲んでも囲まなくてもかまいません
- 相対パスは、設定ファイルのあるフォルダを基準にします
- `%USERPROFILE%` などの環境変数を使えます
- 文字コードは UTF-8（BOM の有無は問いません）、Shift_JIS、UTF-16 のどれでも読めます。メモ帳で保存するときに、文字コードを気にする必要はありません
- 書き間違い（知らない項目、2 回書いた項目、定義されていない環境変数など）があると、何行目かを表示して、コピーする前に止まります

## 担当者がダブルクリックで使えるようにする

PC に慣れていない人でも、ダブルクリックだけでバックアップできるようにします。準備は SE が一度だけ行います。

1. `Backup-Folder.ps1` を置いたフォルダ（共有フォルダや USB メモリの中でもかまいません）で、次のコマンドを実行します

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Backup-Folder.ps1 -CreateLauncher
   ```

2. 同じフォルダに、次の 2 つのファイルができます。同じ名前のファイルがすでにあるときは、上書きせずにそのまま残します

   | ファイル | 内容 |
   | --- | --- |
   | `Backup-Folder.cmd` | ダブルクリック用の起動ファイル |
   | `Backup-Folder.ini` | 設定ファイルのひな形（コピー元とコピー先が空欄） |

3. `Backup-Folder.ini` をメモ帳で開き、`Source` と `Destination` を書いて保存します
4. 担当者は `Backup-Folder.cmd` をダブルクリックします。件数と容量を確かめて `Y` を入力するとコピーが始まり、終わると「続行するには何かキーを押してください」と表示されます

- 3 つのファイルは、同じフォルダに置いたまま使ってください。フォルダごと別の場所へ移しても動きます（USB メモリのドライブ文字が変わっても動きます）
- 起動ファイルは、自分と同じ名前の `.ps1` と `.ini` を探します。名前を変えるときは、3 つとも同じ名前にそろえてください
- 起動ファイルの中身は次の 3 行です。実行ポリシーの設定にかかわらず起動できます（`%~dpn0` は「起動ファイルのフォルダと、拡張子を除いた名前」です）

  ```bat
  @echo off
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File "%~dpn0.ps1" -ConfigFile "%~dpn0.ini"
  pause
  ```

- エクスプローラーの右クリックメニューの「PowerShell で実行」は使わないでください。Windows の初期状態（実行ポリシーが `Restricted`）では、スクリプトの実行が禁止されているため動きません

## 画面の表示例

```
フォルダのバックアップ (Backup-Folder 1.0.0)
コピー元: \\server01\共有\経理
コピー先: E:\backup\経理（exFAT・空き 28.4 GB）
2026-10-31 09:30:00   PC01（管理者: いいえ）

コピーするファイル 1,204 件（3.2 GB）  新規 1,189 件・上書き 15 件
コピーしますか？ [Y] はい  [N] いいえ: Y

（ここに robocopy がコピー中のファイルを表示します）

結果: 正常に終わりました  コピー 1,204 件  失敗 0 件  所要 2分14秒
保存先: C:\tools\Backup_PC01_20261031_093000
```

条件によって、表示が次のように変わります。

- `-ConfigFile` を指定したとき：日時の行の次に「設定ファイル: C:\tools\usb.ini」
- コピーするファイルがないとき：「コピーするファイルはありません（すべてコピー済みです）」と表示し、確認せずに終わります。空のフォルダだけが新しいときは「コピーするファイルはありません。新しく作るフォルダ 3 個」と表示し、確認のうえでフォルダを作ります
- `-ListOnly` を指定したとき：確認の行を出さず、「一覧だけを保存しました。コピーはしていません」と表示します
- 確認で `N` を入力したとき：「コピーしませんでした」と表示して終わります。結果は保存しません
- 権限がないなどで、コピー元に読めないフォルダがあるとき：「※ 読めなかったフォルダが 2 件あります。そのフォルダの中はコピーされません（skipped.csv を確認してください）」
- 結果の保存先がコピー元の中にあるとき：「※ 結果の保存先がコピー元の中にあるため、結果のフォルダもコピーされます（-OutputFolder で、コピー元の外を指定してください）」
- コピー先が FAT32 で、4 GB 以上のファイルがあるとき：「※ コピー先は FAT32 のため、4 GB 以上のファイル 2 件はコピーできません」と、確認の前に表示します
- `-ListOnly` を指定していて、コピー先の空きが足りないとき：止まらずに「※ コピー先の空きが足りません（必要 3.2 GB・空き 1.1 GB）」と表示します

コピーした後の「結果」の行は、次のどれかです。

| 結果の行 | 終了コード |
| --- | --- |
| 「結果: 正常に終わりました  コピー 1,204 件  失敗 0 件  所要 2分14秒」 | 0 |
| 「結果: コピーできなかったファイルが 2 件あります。files.csv と robocopy.log を確認してください（コピー 1,202 件  所要 2分14秒）」 | 1 |
| 「結果: 読めなかったフォルダが 2 件あります。そのフォルダの中はコピーしていません。skipped.csv を確認してください（コピー 1,204 件  所要 2分14秒）」 | 1 |
| 「結果: コピーできなかったフォルダかファイルがあります。robocopy.log を確認してください（コピー 1,204 件  所要 2分14秒）」 | 1 |
| 「結果: robocopy が途中で止まりました（終了コード 16）。robocopy.log を確認してください」 | 1 |

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 正常に終わった。コピーするファイルがなかったとき、`-ListOnly` で一覧だけを保存したとき、確認で `N` を選んだときも 0 |
| 1 | コピーする前に止まった、またはコピーできなかったファイル・読めなかったフォルダがある。読めなかったフォルダがあれば、コピーするファイルがなかったときも 1（`-ListOnly` のときは 0） |

タスクスケジューラなどで実行するときは、終了コードで結果を判別できます。

## 保存されるファイル

実行するたびに、保存先に `Backup_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容（コピー元・コピー先・件数・結果） |
| `files.csv` | コピーした（`-ListOnly` のときはコピーする予定の）ファイルの一覧と、1 件ずつの結果 |
| `skipped.csv` | 読めなかったため、中をコピーしなかったフォルダと、その理由 |
| `robocopy.log` | robocopy の記録。コピーしなかったとき（`-ListOnly` のときや、コピーするファイルがないとき）は、コピーするファイルを調べたときの記録です |

CSV とログは BOM 付き UTF-8 で保存するため、Excel やメモ帳でそのまま開けます。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `files.csv` | 種類、結果、ファイル、サイズ(MB)、サイズ(バイト)、最終更新日時 |
| `skipped.csv` | 理由、パス、詳細 |

- 種類は「新規」（コピー先にないファイル）か「上書き」（コピー先にあるが、サイズか更新日時が違うファイル）です
- 結果は「コピーした」「失敗」「一覧のみ」（`-ListOnly` のとき）のどれかです。コピーした後に、コピー先のファイルのサイズと更新日時を確かめて判定します。バックアップの途中でコピー元のファイルが更新された場合は、その時点のコピー元と比べます
- ファイルは、コピー元のフルパスです
- サイズは `156,723,000` のように 3 桁区切りで出力します（Excel で 12 桁を超える値が指数表示にならないように）
- `skipped.csv` の理由は「権限なし」か「その他のエラー」です

## コピーのルール

- サイズと更新日時が同じファイルは、コピーしません。更新日時は 2 秒までの違いを同じとみなします（FAT32 や exFAT の USB メモリは、更新日時を 2 秒単位で記録するため）
- サイズか更新日時が違うファイルは、コピー元の内容で上書きします。**コピー先のほうが新しい場合も上書きします**。コピー先で直接ファイルを編集しないでください
- コピー先にだけあるファイルとフォルダは、削除しません
- 空のフォルダもコピーします。隠しファイルとシステムファイルもコピーします
- ファイルの属性と更新日時をコピーします。アクセス権と所有者はコピーしません
- ジャンクションとシンボリックリンクはたどりません。無限ループや二重のコピーを防ぐためです
- 次のファイルはコピーしません：`Thumbs.db`、`desktop.ini`、`~$` で始まるファイル（Office が編集中に作る一時ファイル）
- コピー元の直下にあるごみ箱（`$RECYCLE.BIN`）と `System Volume Information` はコピーしません。ドライブのルート（`D:\` など）や、ドライブのルートを共有したフォルダ（`\\server\D$` など）からコピーするときのためです
- コピー元のフォルダに付いている隠し・システム属性は、コピー先のフォルダに付けません。ドライブのルートには隠し・システム属性が付いているため、そのままだとエクスプローラーでコピー先のフォルダが見えなくなります。コピーを途中で中断したときも外します。ウィンドウを閉じたなどで外れずに残ったときは、次に実行したときに外します（コピーするファイルがなくても外します）
- 権限がなくて読めないフォルダは、飛ばして続けます。件数を表示し、場所を `skipped.csv` に残します
- 260 文字を超える長いパスもコピーします
- 読めないファイルやコピー中にエラーになったファイルは、5 秒待って 3 回まで試し直します。それでもだめなら飛ばして続け、最後に「失敗」として件数を表示します

## 止まるとき

次の場合は、コピーを始める前にエラーを表示して止まります（終了コード 1）。

| 場合 | 表示の例 |
| --- | --- |
| コピー元かコピー先を指定していない | 「コピー元を指定してください（-Source で指定するか、設定ファイルの Source に書きます）」 |
| 値に `"` が残っている（コマンドプロンプトで `"C:\data\"` のように最後を `\"` にした） | 「-Source の値に引用符（"）が残っています: …」と、正しい書き方 |
| コピー元のフォルダが見つからない・開けない | 「コピー元のフォルダを開けません: \\server01\共有\経理」。共有フォルダのときは、[共有フォルダからコピーするとき](#共有フォルダからコピーするとき)の確認方法も表示します |
| コピー先のドライブがない | 「コピー先のドライブ E: が見つかりません。USB メモリなどがつながっているか確かめてください」 |
| コピー元とコピー先が同じ | 「コピー元とコピー先が同じです: D:\data」 |
| コピー先がコピー元の中にある | 「コピー先がコピー元の中にあります。コピーを繰り返すたびに、コピー先の中身もコピーされてしまいます」 |
| コピー先のフォルダを作れない（同じ名前のファイルがある場合も） | 「コピー先のフォルダを作れません: E:\backup\経理（理由）」 |
| コピー先の空きが足りない | 「コピー先の空きが足りません（必要 3.2 GB・空き 1.1 GB）」。`-Force` を付けていても止まります（`-ListOnly` のときは止まらず、知らせるだけです）。必要な容量は、コピー先のクラスタ（割り当ての単位）の大きさに切り上げて計算します |
| 画面がなく確認できない | 「確認できないため、コピーしません。確認せずにコピーするときは -Force を付けてください」 |
| 設定ファイルの書き間違い | 何行目かを表示します（Get-DiskUsage と同じ） |

ネットワークドライブ（`Z:`）とその共有フォルダ（`\\server\share`）のように、同じ場所を別の名前で指定した場合は、「コピー元とコピー先が同じ」「コピー先がコピー元の中」を判定できません。

コピーを始めた後に途中で中断（Ctrl+C）すると、それまでにコピーしたファイルはコピー先に残ります。結果は保存しません。もう一度実行すると、残りのファイルだけをコピーします。

## 共有フォルダからコピーするとき

- このツールは、共有フォルダへの接続（ユーザー名とパスワードの入力）を行いません。実行する前に、エクスプローラーでコピー元の共有フォルダを開けることを確かめてください。ユーザー名とパスワードを聞かれたら入力し、「資格情報を記憶する」にチェックを入れておくと、次からは聞かれません
- **管理者として実行しないでください。** 通常のユーザーで接続した共有フォルダやネットワークドライブは、管理者として開いた PowerShell からは見えないことがあります。管理者として実行していてコピー元を開けないときは、そのことも表示します
- コピー元を開けないときは、次の順に確かめるよう表示します
  1. エクスプローラーのアドレス欄にコピー元のパスを貼り付けて、開けるか試す
  2. ユーザー名とパスワードを聞かれたら入力する
  3. 開けたら、もう一度実行する

## タスクスケジューラで使うとき

- `-Force` を付けてください。付けないと、確認できずに止まります
- `-ConfigFile` は、フルパスで指定してください
- 「ユーザーがログオンしているかどうかにかかわらず実行する」にした場合は、タスクを実行するユーザーでコピー元の共有フォルダを開けるようにしておいてください。記憶した資格情報は、ユーザーごとに別々です

## 使うときの注意

- **FAT32** の USB メモリには、4 GB 以上のファイルをコピーできません。大きいファイルがあるときは、exFAT か NTFS でフォーマットした USB メモリを使ってください
- **OneDrive などのオンライン専用ファイル**をコピー元に含めると、コピーするときにダウンロードが始まります
- アクセス権はコピーしないため、サーバーの移行など、アクセス権まで同じにしたいコピーには使えません
- コピー先を「コピー元と同じ状態」にそろえる（コピー元で消したファイルをコピー先からも消す）ことはしません

## 動作環境

[リポジトリの README の「システム要件」](../../README.md#システム要件)を参照してください。`robocopy` は、対象のすべての Windows に最初から入っています。管理者権限は不要です。
