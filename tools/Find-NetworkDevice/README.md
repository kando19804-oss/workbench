# Find-NetworkDevice（ネットワークの機器一覧）

同じネットワーク（セグメント）にある機器を探して、IP アドレス・名前・MAC アドレスを一覧にします。結果は画面に表示し、CSV にも保存します。

「初めて行く現場や引き継いだ拠点に、どんな機器がつながっているかを把握したい」「新しく機器を置く前に、空いている IP アドレスを確かめたい」というときのための道具です。機器の設定を変えることはありません。

**自分が管理するネットワークで使ってください。** このツールは、範囲内のすべての IP アドレスに ping を送ります。管理していないネットワークで使うと、利用規程や契約に反したり、監視装置に攻撃と判断されたりすることがあります。

## 使い方

```powershell
# この PC がつながっているネットワークの機器を探す
powershell -ExecutionPolicy Bypass -File .\Find-NetworkDevice.ps1
```

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# 範囲を指定する（CIDR の書き方）
powershell -ExecutionPolicy Bypass -File .\Find-NetworkDevice.ps1 -Range "192.168.10.0/24"

# 範囲を指定する（始まりと終わり）
powershell -ExecutionPolicy Bypass -File .\Find-NetworkDevice.ps1 -Range "192.168.1.100-192.168.1.150"

# 応答の遅い機器があるネットワークで、待ち時間を 2 秒にする
powershell -ExecutionPolicy Bypass -File .\Find-NetworkDevice.ps1 -Timeout 2000

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Find-NetworkDevice.ps1 -NoSave
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Range` | 探す IP アドレスの範囲。`"192.168.1.0/24"`（CIDR）か、`"192.168.1.10-192.168.1.50"`（始まりと終わり）、`"192.168.1.1"`（1 つだけ）で書きます。カンマで区切って複数書けます。合わせて 4,096 件までです | 指定なし（[自動で決める](#範囲の決め方)） |
| `-Timeout` | ping の待ち時間（ミリ秒）。100～10000 で指定します | 500 |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします | なし |

設定ファイル（`-ConfigFile`）はありません。指定する項目が少ないためです。

### 範囲の決め方

`-Range` を指定しないときは、この PC のネットワークの設定から範囲を決めます。

- 有効なネットワーク アダプターのうち、IPv4 の既定のゲートウェイが設定されているものを使います。該当するネットワークが複数あるとき（VPN がつながっているとき、有線と Wi-Fi で別のネットワークにつながっているときなど）は、ping を送らずに止まり、候補を表示します。`-Range` で探す範囲を指定してください。VPN の先の会社のネットワークなどに、確認なしで ping を送らないためです
- 範囲は、IP アドレスとサブネット マスクから決めます（`192.168.1.23` と `255.255.255.0` なら `192.168.1.1` ～ `192.168.1.254`）。ネットワーク アドレスとブロードキャスト アドレスは除きます
- 範囲が 1,024 件（/22）を超えるネットワークは、探しません。大量の ping でネットワークに負荷をかけないためです。画面に「※ 10.0.0.0/16（VPN）は大きすぎるため、探していません」と表示し、ほかのネットワーク（手元の LAN など）が 1 つなら、それを探します。すべてのネットワークが大きすぎるときは、止まります。探したいときは、`-Range` で範囲を狭めて指定してください
- 該当するアダプターがないときは、止まって `-Range` を指定するよう案内します

## 画面の表示例

```
ネットワークの機器一覧 (Find-NetworkDevice 1.0.0)
対象: 192.168.1.0/24（192.168.1.1 ～ 192.168.1.254・254 件）   イーサネット
2026-11-01 16:00:00   PC01（192.168.1.23）

 IP アドレス      名前          MAC アドレス       ping      種類
 192.168.1.1      router.local  00-1A-2B-3C-4D-5E     1 ms   ゲートウェイ
 192.168.1.10     FILESERVER01  00-15-5D-01-02-03     1 ms
 192.168.1.23     PC01          3C-52-82-AA-BB-CC     -      この PC
 192.168.1.40                   B8-27-EB-11-22-33  応答なし
 192.168.1.101    PRN-3F        00-80-92-44-55-66     3 ms

機器 5 台（ping に応答 3・応答なし 1・この PC 1）  所要 6.2秒
保存先: C:\tools\NetworkDevice_PC01_20261101_160000
```

表示の決まりは次のとおりです。

- 「対象」の行は、ping を送る前に表示します。思っていた範囲と違うときは、Ctrl+C で止めてください
- 機器は、IP アドレスの小さい順に並べます
- ping が「応答なし」でも、ARP に応答した機器（MAC アドレスが分かった機器）は載せます。ping に応答しない設定の Windows PC やネットワーク機器も、たいていこれで見つかります
- 名前が分からない機器は、名前の欄を空欄にします
- この PC と、既定のゲートウェイには、種類の欄に「この PC」「ゲートウェイ」と表示します
- 機器が 1 台も見つからないときは「機器は見つかりませんでした」と表示します
- 条件によって、次の行も表示します
  - `-Range` に複数の範囲を書いたとき：「対象」の行を、範囲ごとに表示します
  - `-Range` に、この PC のネットワークの外の範囲を指定したとき：「※ 192.168.20.0/24 は、この PC のネットワークの外です。MAC アドレスは分かりません（ping に応答した機器だけを載せます）」。範囲の一部だけが外のときは「※ 192.168.0.0/23 の一部は、この PC のネットワークの外です。…」と表示し、中の部分は MAC アドレスも調べます

## 保存されるファイル

実行するたびに、保存先に `NetworkDevice_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容 |
| `devices.csv` | 見つかった機器の一覧（IP アドレスの小さい順） |

CSV とテキストは BOM 付き UTF-8 で保存します。保存先に書き込めないときは警告を表示し、画面表示だけで終了します。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `devices.csv` | IP アドレス、名前、名前の調べ方、MAC アドレス、ping、応答時間(ms)、種類、ネットワーク |

- 名前の調べ方は「DNS」「NetBIOS」のどちらかです。名前が分からないときと、この PC の行（コンピューター名を書きます）は空欄です。「DNS」は Windows の名前解決で引けたもので、DNS に登録がなくても、Windows が NetBIOS や LLMNR で見つけた名前を含むことがあります
- MAC アドレスは `00-1A-2B-3C-4D-5E` の形（Windows の `arp -a` や `ipconfig /all` と同じ形）で書きます。分からないときは空欄です
- ping は「応答」「応答なし」のどちらかです。この PC は空欄です
- 応答時間は、ping に応答したときのミリ秒です
- 種類は「この PC」「ゲートウェイ」のどちらか、または空欄です
- ネットワークは、その機器を探した範囲（`192.168.1.0/24` など）です
- 名前のうち、Excel で数式・数値・日付に変わる形のものは、`="..."` の形で書きます

## 探し方

1. 範囲内のすべての IP アドレスに、同時に 64 件ずつ ping を送ります（1 件につき 1 回）
2. ping を送ると、Windows は相手の MAC アドレスを ARP で問い合わせます。ping を送り終えたら、Windows が覚えている ARP の表（`arp -a` で表示されるもの）から、範囲内の機器の MAC アドレスを読みます
3. ping に応答がなく、ARP の表にもない IP アドレスに、もう 1 回だけ ping を送り、ARP の表を読み直します。省電力で眠っている機器（画面の消えたスマートフォンなど）は、最初の 1 回に間に合わないことがあるためです
4. 見つかった機器（ping に応答したか、MAC アドレスが分かった機器）の名前を、DNS の逆引きで調べます。DNS で分からなければ、NetBIOS で問い合わせます（Windows の PC や、ファイル共有に対応した機器が答えます）。機器が多いときは 64 台ずつ問い合わせ、名前が 1 つも取れず、答えの返らない問い合わせが残っているときは、残りの機器の DNS の問い合わせをやめます（待ち時間が長くなるのを避けるためです）
5. この PC の IP アドレスと MAC アドレスは、ネットワーク アダプターの設定から書きます

ARP の表に以前から残っていた機器も載せることがあります（Windows は、しばらく通信した相手の MAC アドレスを覚えているためです）。そのときも、ping の欄で今応答したかが分かります。

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 探し終わった（機器が 1 台も見つからなかったときも 0） |
| 1 | 範囲を決められない、範囲が大きすぎる（自動のときは、すべてのネットワークが大きすぎる）、自動で決めるネットワークが複数ある、引数の誤りなどで、止まった |

## 使うときの注意

- **ルーターの向こうのネットワーク**（`-Range` に別のセグメントを指定したとき）は、ping に応答した機器しか見つからず、MAC アドレスも分かりません。ARP は、ルーターを越えないためです。MAC アドレスまで調べたいときは、そのネットワークにつながった PC で実行してください
- **ping にも ARP にも応答しない機器**（電源の切れた機器、ほかのネットワークの機器など）は見つかりません
- **省電力で眠っている機器**（画面の消えたスマートフォンなど）は、見つからないことがあります。一覧にない IP アドレスも、使われている場合があります。新しい機器に割り当てる前に、ルーターの DHCP の割り当ても確かめてください
- **Wi-Fi で、端末どうしの通信を止める設定**（プライバシー セパレーター、AP アイソレーション）があると、ほかの端末は見つかりません
- **仮想マシンや VPN** のアダプターに既定のゲートウェイがあるときは、[範囲の決め方](#範囲の決め方)のとおり、止まって `-Range` の指定を求めます。ただし、既定のゲートウェイのあるネットワークがそれだけのときは、そのネットワークを探します。「対象」の行はアダプターの名前と一緒に ping の前に出るので、違っていたら Ctrl+C で止めてください
- Windows ファイアウォールの設定によっては、Windows の PC が ping に応答しません。その場合も、同じネットワークなら MAC アドレスで見つかります
- 一度に多くの ping を送るため、侵入検知の装置やセキュリティ ソフトが警告を出すことがあります。ネットワークの管理者に知らせてから使ってください
