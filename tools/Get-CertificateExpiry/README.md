# Get-CertificateExpiry（証明書期限一覧）

証明書の有効期限を調べて、期限切れや期限の近いものを洗い出します。調べられるのは、Windows の証明書ストア、接続先のサーバーが使っている証明書、フォルダの中の証明書ファイルです。結果は画面に表示し、CSV にも保存します。

「証明書の期限切れで Web サイトやシステムが止まる前に気づきたい」「サーバーを引き継ぐので、どの証明書がいつ切れるのかを資料にしたい」というときのための道具です。証明書を追加・更新・削除することはありません。

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Get-CertificateExpiry.ps1
```

調べたいサーバーの上で実行してください。IIS のサイトとの紐付けも調べるため、管理者として実行することをおすすめします。

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# 残り 90 日以内を「期限間近」にする
powershell -ExecutionPolicy Bypass -File .\Get-CertificateExpiry.ps1 -Days 90

# すべてのストアを調べる（Windows 標準のルート証明書なども含む）
powershell -ExecutionPolicy Bypass -File .\Get-CertificateExpiry.ps1 -AllStores

# 指定したストアだけを調べる
powershell -ExecutionPolicy Bypass -File .\Get-CertificateExpiry.ps1 -Store "LocalMachine\My,LocalMachine\Root"

# 接続先のサーバーが使っている証明書を調べる（ポートを省くと 443）
powershell -ExecutionPolicy Bypass -File .\Get-CertificateExpiry.ps1 -Target "web01,lb01.example.co.jp:8443"

# フォルダの中の証明書ファイルを調べる
powershell -ExecutionPolicy Bypass -File .\Get-CertificateExpiry.ps1 -Path D:\certs

# 特定の証明書を除く
powershell -ExecutionPolicy Bypass -File .\Get-CertificateExpiry.ps1 -Exclude "CN=localhost,*テスト*"

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Get-CertificateExpiry.ps1 -NoSave
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Days` | 「期限間近」とする残り日数。1～3650 で指定します | 60 |
| `-Store` | 調べるストア。`LocalMachine\My` の形で、カンマで区切って書きます（[調べるストア](#調べるストア)を参照） | 下の説明を参照 |
| `-AllStores` | この PC と実行したユーザーの、すべてのストアを調べます。`-Store` と一緒には使えません | なし |
| `-Target` | 接続して証明書を調べるサーバー。`ホスト` か `ホスト:ポート` を、カンマで区切って書きます。ポートを省くと 443 です（[接続先を調べるとき](#接続先を調べるとき)を参照） | 指定なし |
| `-Timeout` | `-Target` の 1 件あたりの待ち時間（秒）。1～60 で指定します | 5 |
| `-Path` | 調べる証明書ファイル、またはフォルダ。カンマで区切って複数指定できます。フォルダは下の階層まで調べます（[ファイルを調べるとき](#ファイルを調べるとき)を参照） | 指定なし |
| `-Exclude` | 調べない証明書。サブジェクトに対して、ワイルドカード（`*`）で書きます。カンマで区切って複数指定できます。サブジェクトの `CN=a, O=b` のように、スペースが続くカンマでは区切りません。サブジェクトに引用符が入っているとき（`O="Example, Inc."`）は、`*Example, Inc.*` のように引用符を除いて書きます。`*` 以外の文字はそのままの文字として扱い、大文字と小文字は区別しません | 指定なし |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします | なし |
| `-ConfigFile` | 設定ファイルのパス（[設定ファイル](#設定ファイル)を参照）。コマンドラインで指定した値は、設定ファイルより優先します | 指定なし |

何も指定しないと、[運用で使うストア](#調べるストア)を調べます。`-Target` か `-Path` だけを指定すると、この PC のストアは調べません。接続先やファイルと一緒にストアも調べたいときは、`-Store` か `-AllStores` も指定してください。

### 調べるストア

指定しないときは、自分たちで入れることの多い次のストアを調べます。この PC にないストア（`WebHosting` など）は、何も言わずに飛ばします。

| ストア | 内容 |
| --- | --- |
| `LocalMachine\My` | コンピューターの「個人」。サーバー証明書の多くはここにあります |
| `LocalMachine\WebHosting` | IIS の「Web ホスティング」 |
| `LocalMachine\Remote Desktop` | リモートデスクトップの証明書 |
| `CurrentUser\My` | 実行したユーザーの「個人」 |

- `-Store` には `My` `Root` `CA` などのストアの名前を、`LocalMachine\` か `CurrentUser\` を付けて書きます。大文字と小文字は区別しません
- `-Store` で指定したストアがこの PC にないときは、調べる前に止まります。打ち間違いに気づかないまま「問題なし」と出るのを防ぐためです
- `-AllStores` を指定すると、Windows 標準のルート証明書なども並びます。その中には、期限の切れたものも普通に含まれます。Active Directory に問い合わせる `UserDS` のストアは調べません
- `CurrentUser` の `Root` や `CA` などには、Windows が `LocalMachine` の証明書も見せます。同じ名前の `LocalMachine` のストアも調べたときは、同じ証明書が 2 行並ばないよう、`CurrentUser` の行を省いて `skipped.csv` に「除外指定」として残します。`CurrentUser\Root` だけを指定したときは、見えているものをすべて調べます
- アーカイブされた証明書（更新の後に Windows が残している古い証明書）は調べません

## 設定ファイル

同じ条件で繰り返し調べるときは、パラメーターを設定ファイルにまとめておけます。タスクスケジューラで毎月調べるときなどに便利です。設定ファイルを使わなくても、パラメーターだけで動きます。

```ini
# Get-CertificateExpiry の設定ファイル
# 「項目 = 値」の形で、1 行に 1 つずつ書きます。# か ; で始まる行はコメントです

Days = 90

# Store・Target・Path・Exclude は、複数の行に分けて書けます
Store = LocalMachine\My
Store = LocalMachine\WebHosting
Target = web01
Target = lb01.example.co.jp:8443
Path = D:\certs
Exclude = CN=localhost

Timeout = 10
OutputFolder = \\fileserver\report\%COMPUTERNAME%
NoSave = false
```

- 書ける項目は、`Days`、`Store`、`AllStores`、`Target`、`Timeout`、`Path`、`Exclude`、`OutputFolder`、`NoSave` です
- `AllStores`、`NoSave` は `true` か `false` で書きます
- `Path` の 1 行はカンマで区切りません。カンマを含む名前のフォルダは、設定ファイルならそのまま書けます
- コマンドラインで `-Store`、`-Target`、`-Path`、`-Exclude` を指定すると、設定ファイルの同じ項目は使いません（両方を合わせることはしません）
- コマンドラインで `-AllStores` を指定すると設定ファイルの `Store` を、`-Store` を指定すると設定ファイルの `AllStores` を使いません
- 環境変数は、`Target`、`Path`、`Exclude`、`OutputFolder` に書けます
- 設定ファイルで `true` にした `AllStores`、`NoSave` は、コマンドラインから取り消せません。元に戻したいときは、設定ファイルを直してください
- そのほかの書き方（空の値、引用符、コメント、環境変数、相対パス、文字コード）と、書き間違いがあったときの動きは、[Get-DiskUsage の設定ファイル](../Get-DiskUsage/README.md#設定ファイル)と同じです

```

対象: LocalMachine\My, LocalMachine\WebHosting, LocalMachine\Remote Desktop, CurrentUser\My
期限間近の基準: 残り 60 日以内

証明書 12 件  期限切れ 1 件  期限間近 2 件  更新済み 3 件  有効 6 件  所要 0.3秒

■ 対応が必要な証明書（期限の近い順）
 状態      残り日数  有効期限          場所                     サブジェクト
 期限切れ       -13  2026-10-21 08:59  LocalMachine\My          CN=old-api.example.co.jp
 期限間近        17  2026-11-20 08:59  LocalMachine\My          CN=www.example.co.jp（IIS: Default Web Site）
 期限間近        45  2026-12-17 23:59  LocalMachine\WebHosting  CN=portal.example.co.jp（IIS: Portal, Portal2）

```

表示の決まりは次のとおりです。

- 表に出すのは、期限切れと期限間近の証明書だけです。ほかの証明書は件数だけを表示し、`certificates.csv` に残します
- 表は 200 件までです。超えた分は「（ほか 1,234 件は certificates.csv を参照してください）」と表示します。`-NoSave` のときと、保存できなかったときは、すべて表示します
- 対応が必要な証明書がないときは、「（対応が必要な証明書はありません）」と表示します
- 備考があるときは、サブジェクトの後ろに「（名前が一致しない）」のように添えます
- 条件によって、次の行も表示します
  - `-ConfigFile` を指定したとき：「設定ファイル: C:\tools\monthly.ini」
  - `-Exclude` を指定したとき：「除外: CN=localhost」。除外した証明書があれば、件数の行に「除外 1 件」
  - 有効期間前の証明書があったとき：件数の行に「有効期間前 1 件」
  - 調べられなかったものがあったとき：「スキップ 2 件（権限なし 1・接続できない 1）」
  - 開かなかったファイルや、たどらなかったリンクがあったとき：スキップの行に「読まない形式 1 件」「たどらなかったリンク 1 件」
  - `LocalMachine` と重なる証明書を省いたとき：「LocalMachine と重なる証明書 137 件は省きました」
  - IIS の設定を読めなかったとき：「※ IIS の設定を読めなかった部分があるため、サイトとの紐付けが足りないことがあります。ストアの証明書は更新済みにしていません」。管理者として実行していないときは「（管理者として実行すると読めることがあります）」を添えます
  - 管理者として実行しておらず、権限がなくて読めないストア、フォルダ、ファイルがあったとき：「※ 管理者として実行すると、読める範囲が広がります」

## 保存されるファイル

実行するたびに、保存先に `CertificateExpiry_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容（実行条件・件数・対応が必要な証明書）。200 件を超えても省略しません |
| `certificates.csv` | 調べたすべての証明書（有効期限の早い順） |
| `skipped.csv` | 調べられなかったもの・調べなかったものと、その理由 |

CSV は BOM 付き UTF-8 で保存するため、Excel でダブルクリックすればそのまま開けます。保存先に書き込めないときは警告を表示し、画面表示だけで終了します。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `certificates.csv` | 状態、残り日数、有効期限、有効開始日、種類、場所、サブジェクト、別名(SAN)、発行者、用途、秘密鍵、IIS のサイト、フレンドリ名、拇印、備考 |
| `skipped.csv` | 理由、対象、詳細 |

- 状態は「期限切れ」「期限間近」「更新済み」「有効」「有効期間前」のどれかです（[状態の決め方](#状態の決め方)を参照）
- 残り日数は、有効期限まで何日あるかです。24 時間未満なら 0、期限を過ぎると負の数です。3 桁区切りで出力します
- 日時は、実行した PC の時間帯で `2026/11/20 08:59:59` の形で書きます
- 種類は「ストア」「接続先」「ファイル」のどれかです。場所は、ストアの名前、`ホスト:ポート`、ファイルのパスです
- 別名(SAN) は、DNS 名と IP アドレスを `, ` でつないで書きます。用途は「サーバー認証」「クライアント認証」などの拡張キー使用法です
- 秘密鍵は「あり」か「なし」です。接続先とファイルの証明書は空欄です
- IIS のサイトは、この PC の IIS で使っているサイトの名前とバインドを `Default Web Site (*:443:www.example.co.jp)` の形で書きます。複数のときは `, ` でつなぎます。ストアの証明書だけに書きます
- 拇印は、Windows の証明書の画面に表示される値（SHA-1、大文字の 16 進数）です。数字だけの値など、Excel で変わるものは `="..."` の形で書きます
- 備考は、接続先の証明書を Windows が信頼できないとき（「信頼できない発行者」「名前が一致しない」など）や、更新済みとした根拠（新しい証明書の拇印）を書きます
- `skipped.csv` の理由は、「権限なし」「接続できない」「読めない」「読まない形式」「除外指定」「リンク」「その他のエラー」のいずれかです

## 状態の決め方

| 状態 | 条件 |
| --- | --- |
| 期限切れ | 有効期限を過ぎている |
| 期限間近 | 残りが `-Days` 以内 |
| 更新済み | 期限切れか期限間近だが、新しい証明書に置き換わっていると判断できる（下の条件） |
| 有効 | 残りが `-Days` より多い |
| 有効期間前 | 有効開始日より前 |

次の条件をすべて満たすと、「更新済み」とします。更新の後に残った古い証明書が毎回「期限切れ」に並ぶと、本当に対応が必要な証明書が埋もれてしまうためです。

- 同じ場所（同じストア、または同じフォルダ）に、新しい証明書がある。接続先の証明書は、更新済みになりません
- サブジェクトと別名(SAN)が、どちらも同じ
- 新しい証明書の有効期限のほうが遅く、新しい証明書は今有効で、残りが `-Days` より多い
- 古い証明書に秘密鍵があるときは、新しい証明書にも秘密鍵がある
- 古い証明書を IIS のサイトで使っていない。**古い証明書をまだサイトで使っているときは、新しい証明書があっても「期限切れ」「期限間近」のままです**。IIS の設定を読めなかったときは、使っているかどうかが分からないので、ストアの証明書を更新済みにしません

更新済みかどうかは、画面の表に出すかどうかと終了コードだけに影響します。`certificates.csv` には、すべての証明書を書きます。

## 接続先を調べるとき

指定したサーバーに TLS で接続し、サーバーが示した証明書（サーバー証明書 1 枚）の期限を調べます。ロードバランサーや Linux のサーバーなど、ストアを見られない相手にも使えます。

- `-Target` を指定したときだけ、ネットワークに接続します。接続した後は証明書を受け取るだけで、データは送りません。ただし、発行者を確かめるときに、Windows が証明書に書かれた CA の URL に問い合わせることがあります（閉じたネットワークでは、その分だけ時間がかかることがあります）
- `-Timeout` は接続と TLS のやり取りのそれぞれに効くので、1 件あたりの待ち時間は指定した秒数より長くなることがあります
- 期限切れや、信頼できない証明書でも、受け取って調べます。信頼できないときは、備考に書きます
- プロキシは使いません。この PC からそのサーバーのポートに直接届く必要があります
- Windows PowerShell 5.1 では TLS 1.2 までで接続します。TLS 1.3 だけに対応したサーバーには接続できません（PowerShell 7 では OS の設定に従います）
- 接続は最初から TLS で始まるポートだけに対応します。接続の途中で TLS に切り替える方式（SMTP の STARTTLS など）は調べられません
- 1 台の IP アドレスで複数の証明書を使っているサーバーは、指定したホスト名に応じた証明書を返します。IP アドレスで指定すると、別の証明書が返ることがあります
- 接続できないときや、TLS で通信できないときは、飛ばして `skipped.csv` に「接続できない」として残します。ほかの対象は続けて調べます

## ファイルを調べるとき

- 拡張子が `.cer` `.crt` `.pem` `.der` のファイルを調べます。バイナリ（DER）と Base64（PEM）のどちらの形式でも読めます
- 1 つの PEM ファイルに複数の証明書が入っているときは、すべて調べます。そのため、中間 CA の証明書も行に出ます。秘密鍵の部分は読みません
- `.pfx` と `.p12` は、パスワードが必要なので開かず、`skipped.csv` に「読まない形式」として残します。証明書の入っていない PEM ファイル（Let's Encrypt の `privkey.pem`、`dhparam.pem`、証明書要求など）と、拡張子が `.crt` などでも中身が証明書 1 枚の形式ではないファイル（PFX、PKCS#7 など）も同じです
- 途中で切れた PEM ファイルは、読めた分の証明書を調べて、`skipped.csv` に「読めない」として残します
- `-Path` の指定が重なっていても（`D:\certs` と `D:\certs\sub` など）、同じファイルは 1 回だけ調べます
- `-Path` に直接指定したファイルは、拡張子にかかわらず証明書として読みます（`.pfx` と `.p12` を除く）。読めないときは、`skipped.csv` に「読めない」として残します
- 10 MB を超えるファイルは、証明書ではないものとして読まず、`skipped.csv` に「読めない」として残します
- フォルダは下の階層まで調べます。ジャンクションやシンボリックリンクはたどりません
- 260 文字を超える長いパスや、名前に `[` `]` を含むフォルダ・ファイルも調べます
- 権限がなくて読めないフォルダやファイルは飛ばして、件数を表示します

## IIS のサイトとの紐付け

この PC に IIS があると、自動で調べます。指定は要りません。

- `%windir%\System32\inetsrv\config\applicationHost.config` を読みます。IIS の設定を変更することはありません
- バインドに証明書の情報がないサイトは、HTTP.sys の設定（レジストリ）を読んで補います。FTP サイトの証明書も調べます
- どちらも読むには管理者の権限が必要です。読めないときや、IIS の共有構成で設定が別の場所にあるとき、どの証明書を使っているか分からないバインドがあるときは、そのことを画面に表示して、分かる範囲の紐付けで続けます
- 紐付けが分かるのは IIS だけです。Apache や Tomcat、独自のサービスなどで使っている証明書は分かりません

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 対応が必要な証明書がなかった（すべて調べられた） |
| 2 | 期限切れか期限間近の証明書があった |
| 1 | 引数の誤りなどで、調べる前に止まった。または、対応が必要な証明書はなかったが、調べられなかったものがある |

対応が必要な証明書があって、調べられなかったものもあるときは 2 です。「更新済み」「有効期間前」は、対応が必要な証明書に数えません。「除外指定」「リンク」「読まない形式」は、調べられなかったものに数えません。保存の失敗は、終了コードに影響しません。バッチファイルやタスクスケジューラから、「期限が近づいたら通知する」といった判定に使えます。

### タスクスケジューラで使うとき

`CurrentUser` のストアは、タスクを実行するユーザーのものを調べます。SYSTEM で実行すると、ログオンしているユーザーの証明書は見えません。

| 項目 | 値 |
| --- | --- |
| プログラム/スクリプト | `powershell.exe` |
| 引数の追加 | `-ExecutionPolicy Bypass -File C:\tools\Get-CertificateExpiry.ps1 -ConfigFile C:\tools\monthly.ini` |

## 止まるとき

次の場合は、調べ始める前にエラーを表示して止まります（終了コード 1）。

| 場合 | 表示の例 |
| --- | --- |
| `-Store` の書き方が正しくない | 「-Store は LocalMachine\My の形で指定してください: My」 |
| `-Store` のストアがこの PC にない | 「ストアが見つかりません: LocalMachine\Mi」 |
| `-Store` と `-AllStores` を一緒に指定した | 「-Store と -AllStores は一緒に指定できません」 |
| `-Target` の書き方が正しくない | 「-Target は ホスト か ホスト:ポート（ポートは 1～65535）の形で指定してください: web01:99999」 |
| `-Path` のファイルやフォルダが見つからない | 「ファイルかフォルダが見つかりません: D:\certs」 |
| 値に `"` が残っている（コマンドプロンプトで `"C:\data\"` のように最後を `\"` にした） | 「-Path の値に引用符（"）が残っています: …」と、正しい書き方 |
| 設定ファイルの書き間違い | 何行目かを表示します（Get-DiskUsage と同じ） |

## 使うときの注意

- **調べるのは、実行した PC のストアだけです。**別のサーバーのストアは、そのサーバーの上で実行するか、`-Target` で接続して調べてください
- **`CurrentUser` は、実行したユーザーの分だけです。**サービスアカウントなど、ほかのユーザーの証明書は見えません
- **「有効」は、期限が切れていないという意味です。**失効しているかや、発行者までのつながり（証明書チェーン）は調べません
- **中間 CA の期限は、接続先では調べません。**サーバー証明書が有効でも、中間 CA の期限切れで接続に失敗することがあります
- **一覧に出ていても、使われているとは限りません。**使っていない証明書は期限が切れても問題ないことがあるので、IIS の紐付けや、使っているシステムを確かめて判断してください
- **更新済みの判断は目安です。**サービスによっては、拇印を指定して古い証明書を使い続けていることがあります。更新の後は、サービスの設定も確かめてください
- **自動更新の証明書**（Active Directory 証明書サービスの自動登録など）は、期限間近と出ても自動で更新されることがあります

## 動作環境

[リポジトリの README の「システム要件」](../../README.md#システム要件)を参照してください。管理者権限は不要ですが、`LocalMachine` のストアの一部と IIS の紐付けのために、管理者として実行することをおすすめします。`-Target` を使うときは、相手のサーバーのポートに届くネットワークが必要です。
