# Export-TaskList（タスクスケジューラ出力）

タスクスケジューラに登録されているタスクを一覧にして、いつ・誰の権限で・何を動かすか・前回の結果を CSV に保存します。あわせて、各タスクを取り込み直せる XML も保存します。

「サーバーの引き継ぎで、どんな定期処理が動いているかを資料にしたい」「サーバーを移行するので、タスクを控えておいて新しいサーバーに登録し直したい」というときのための道具です。タスクを変更・削除・実行することはありません。

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Export-TaskList.ps1
```

調べたいサーバーの上で実行してください。ほかのユーザーや SYSTEM で動くタスクも出力するため、管理者として実行することをおすすめします。

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# Windows 標準のタスク（\Microsoft\ の下）も含めて、すべて出力する
powershell -ExecutionPolicy Bypass -File .\Export-TaskList.ps1 -All

# \集計 フォルダの下のタスクだけを出力する
powershell -ExecutionPolicy Bypass -File .\Export-TaskList.ps1 -Path \集計

# 一覧の CSV だけを保存し、XML は保存しない
powershell -ExecutionPolicy Bypass -File .\Export-TaskList.ps1 -NoXml

# 結果を指定したフォルダに保存する
powershell -ExecutionPolicy Bypass -File .\Export-TaskList.ps1 -OutputFolder D:\引き継ぎ

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Export-TaskList.ps1 -NoSave
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Path` | 出力するタスクのフォルダ（タスクスケジューラの左側に表示されるフォルダ）。`\集計` のように `\` で始めて書きます。下のフォルダもすべて出力します | `\`（すべて） |
| `-All` | Windows 標準のタスク（`\Microsoft\` の下）も出力します | なし（`\Microsoft\` の下は出力しない） |
| `-NoXml` | 各タスクの XML を保存しません | なし（保存する） |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします | なし |

- `-Path` に `\Microsoft\` の下のフォルダ（`\Microsoft\Windows\Defrag` など）を指定したときは、`-All` を付けなくても出力します
- 設定ファイル（`-ConfigFile`）はありません。指定する項目が少なく、毎回同じ条件で実行することがほとんどのためです

## 画面の表示例

```
タスクスケジューラ出力 (Export-TaskList 1.0.0)
対象: SERVER01（管理者: はい）   2026-11-01 14:00:00
範囲: \ の下（\Microsoft\ の下を除く）

 状態      前回の結果             次回の実行        実行ユーザー  タスク
 準備完了  成功 (0x0)             2026-11-02 03:00  SYSTEM        \夜間バックアップ
 無効      -                      -                 admin         \旧\ログ削除
 準備完了  まだ実行していない     2026-11-05 09:00  admin         \集計\月次レポート
 準備完了  失敗 (0x1)             2026-11-01 15:00  svc_batch     \集計\毎時集計

タスク 4 件（有効 3・無効 1）  前回失敗 1 件  所要 0.8秒
保存先: C:\tools\TaskList_SERVER01_20261101_140000
```

表示の決まりは次のとおりです。

- タスクは、フォルダとタスク名のパスの順に並べます。並びは文字コードの順で、日本語は読みの順にはなりません。フォルダの中のタスクは、そのフォルダのすぐ後に続きます
- 前回失敗したタスクの行は、黄色で表示します。無効のタスクの行は、灰色で表示し、前回の結果と次回の実行は `-` にします
- 「前回失敗」の件数は、有効なタスクだけで数えます（無効にしたタスクの、昔の失敗は数えません。tasks.csv には前回の結果をそのまま書きます）
- 画面に表示するタスクは 200 件までです。超えた分は「（ほか 34 件は tasks.csv を参照してください）」と表示します。`-NoSave` のときと、保存できなかったときは、すべて表示します
- タスクが 1 件もないときは「（タスクはありません）」と表示します
- 条件によって、次の行も表示します
  - `-All` を指定したとき（`-Path` を省略したとき）：「範囲: \ の下（Windows 標準のタスクを含む）」
  - XML を保存できなかったタスクがあったとき：「※ XML を保存できなかったタスクが 1 件あります（skipped.csv を確認してください）」
  - `-NoXml` を指定したとき：「XML: 保存しない」
  - 読めないフォルダやタスクがあったとき：「スキップ 3 件（権限なし 2・その他のエラー 1）」
  - 管理者として実行していないとき：「※ 管理者として実行していないため、ほかのユーザーや SYSTEM のタスクが出ないことがあります」

## 保存されるファイル

実行するたびに、保存先に `TaskList_<ホスト名>_<日時>` というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容（実行条件・一覧・件数）。一覧は 200 件を超えても省略しません |
| `tasks.csv` | タスクの一覧 |
| `xml\` | タスクごとの XML。タスクスケジューラと同じフォルダの構成で、`xml\集計\毎時集計.xml` のように保存します。ファイル名に使えない文字は `_` にし、別のタスクと同じ名前になるときは `_2` などを付けます。`-NoXml` のときは作りません |
| `skipped.csv` | 読めなかったフォルダ・タスクと、その理由 |

CSV とテキストは BOM 付き UTF-8 で保存します。XML は、タスクスケジューラが書き出すときと同じ UTF-16（BOM 付き）で保存します（取り込むときに文字コードの問題が起きないようにするためです）。保存先に書き込めないときは警告を表示し、画面表示だけで終了します。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `tasks.csv` | フォルダ、タスク名、状態、実行ユーザー、実行の条件、最上位の特権、トリガー、操作、作業フォルダ、前回の実行日時、前回の結果、結果のコード、次回の実行日時、作成者、作成日、説明、隠し、XML ファイル |
| `skipped.csv` | 理由、パス、詳細 |

- 状態は「準備完了」「実行中」「キューに登録」「無効」「不明」のどれかです
- 実行の条件は「ログオンしているときのみ」「ログオンしているかどうかにかかわらず」「パスワードを保存しない」「サービス アカウント」のどれかです（タスクのプロパティの「セキュリティ オプション」に当たります）。どれにも当たらないときは空欄です
- 最上位の特権は「はい」か「いいえ」です。隠しは「はい」か空欄です
- トリガーは、`毎日 03:00` のような文章で書きます（[トリガーの書き方](#トリガーの書き方)を参照）。複数あるときは ` / ` で区切ります
- 操作は、プログラムと引数を空白でつないで書きます。複数あるときは ` / ` で区切ります。プログラムの起動以外の操作は「COM ハンドラー」「メールの送信」「メッセージの表示」と書きます。それ以外の操作は「種類 8 の操作」のように番号で書きます
- 前回の結果は「成功」「失敗」「実行中」「まだ実行していない」のどれかです。結果のコードは `0x00041301` のような 16 進数です（タスクスケジューラの「前回の実行結果」と同じ値です）
- 前回の実行日時・次回の実行日時は、ないときは空欄です
- XML ファイルは、`xml\` から見た XML のパスです。`-NoXml` のときは空欄です
- タスク名・説明など、Excel で数値・日付・数式に変わる値（`2026-10-31`、`=...` など）は、`="..."` の形で書きます
- `skipped.csv` の理由は、「権限なし」「その他のエラー」のいずれかです。XML を保存できなかったタスクも、詳細に「XML を保存できません: …」と書いて残します（一覧には載せます）

### トリガーの書き方

| トリガー | 書き方の例 |
| --- | --- |
| 1 回 | `1 回 2026-11-05 09:00` |
| 毎日 | `毎日 03:00`、`2 日ごと 03:00` |
| 毎週 | `毎週 月・水・金 03:00`、`2 週ごと 月 03:00` |
| 毎月（日にち） | `毎月 1・15 日 03:00`、`毎月 最終日 03:00` |
| 毎月（曜日） | `毎月 第 1 月曜 03:00`、`毎月 最終 金曜 03:00` |
| 起動時 | `起動時` |
| ログオン時 | `ログオン時（すべてのユーザー）`、`ログオン時（CONTOSO\admin）` |
| アイドル時 | `アイドル時` |
| イベント | `イベント発生時` |
| 作成・変更時 | `タスクの作成・変更時` |
| ロック・接続など | `セッションの状態の変更時` |
| それ以外 | `種類 12 のトリガー`（Windows 標準のタスクにある、特別なトリガーなど） |

- 繰り返しの設定があるときは、`毎日 09:00（1 時間ごとに 12 時間繰り返す）` のように添えます
- 無効にしたトリガーには `（無効）` を付けます
- 月の指定が一部だけのときは、`毎月（1・4・7・10 月）1 日 03:00` のように添えます

## 出力のルール

- タスクスケジューラに最初から入っている仕組み（COM の `Schedule.Service`）で読みます。追加のモジュールは使いません
- 隠しタスク（タスクスケジューラの「表示」で「非表示のタスクを表示」にしないと見えないもの）も出力します
- `\Microsoft\` の下は、`-All` を指定したときと、`-Path` で `\Microsoft\` の下を指定したときだけ出力します。Windows やアプリが登録したタスクでも、`\Microsoft\` の外にあるもの（Microsoft Edge の更新など）は、既定でも出力します。Office の更新など、`\Microsoft\` の下にあるものは出力しません
- 権限がなくて読めないフォルダやタスクは飛ばして、件数を表示し、`skipped.csv` に残します
- 途中で中断（Ctrl+C）した場合は、結果を保存しません

## XML を取り込むとき

保存した XML は、移行先のサーバーで次のどちらかの方法で取り込めます。

- タスクスケジューラの右側の「タスクのインポート」で XML を選ぶ
- コマンドで登録する

  ```powershell
  schtasks /create /xml "D:\引き継ぎ\TaskList_SERVER01_20261101_140000\xml\集計\毎時集計.xml" /tn "\集計\毎時集計"
  ```

- **パスワードは XML に入りません。** 「ログオンしているかどうかにかかわらず実行する」タスクは、取り込むときにパスワードの入力を求められます（`schtasks` では `/ru` と `/rp` で指定します）
- 実行ユーザーがドメインのユーザーやローカルのユーザーのときは、移行先にも同じユーザーが必要です
- 操作のプログラムや作業フォルダのパスは、移行先にも同じものがある前提です。ドライブ構成が違うときは、取り込んだ後に直してください

## 使うときの注意

- **管理者として実行してください。** 管理者でないと、ほかのユーザーや SYSTEM で動くタスクが一覧に出ないことがあります（出なかったことは分かりません）。画面にも注意を表示します
- このツールは、実行した PC のタスクだけを出力します。別のサーバーのタスクは、そのサーバーの上で実行してください
- 前回の実行日時と結果は、タスクスケジューラが覚えている最後の 1 回分です。過去の履歴は出力しません

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 出力できた（読めないタスクがあっても 0） |
| 1 | タスクスケジューラに接続できない、`-Path` のフォルダが見つからない・開けないなどで、止まった |
