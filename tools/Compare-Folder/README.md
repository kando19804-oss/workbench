# Compare-Folder（フォルダ差分）

2 つのフォルダの中身を比べて、追加・削除・変更されたファイルとフォルダを一覧にします。結果は画面に表示し、CSV にも保存します。

「サーバーの移行やバックアップの後に、コピー先がコピー元と同じになっているか確かめたい」「作業の前と後で、どのファイルが増えた・消えた・変わったかを確かめたい」というときのための道具です。作業の前にフォルダの状態を保存しておき（スナップショット）、作業の後に今のフォルダと比べることもできます。比べるフォルダのファイルを変更・削除することはありません。

## 使い方

```powershell
powershell -ExecutionPolicy Bypass -File .\Compare-Folder.ps1 -Reference \\old-fs\share\経理 -Difference \\new-fs\share\経理
```

`-Reference`（基準）と `-Difference`（比較）のフォルダを比べます。比較のフォルダにだけあるものを「追加」、基準のフォルダにだけあるものを「削除」と表示します。

実行ポリシーなど、起動方法の詳しい説明は[リポジトリの README](../../README.md#使い方) を参照してください。

### 例

```powershell
# ファイルの内容（SHA-256 のハッシュ）まで比べる（移行の確認や、エビデンスを残すとき）
powershell -ExecutionPolicy Bypass -File .\Compare-Folder.ps1 -Reference D:\data -Difference E:\backup\data -Hash

# 違いのなかったファイルも、ハッシュと一緒に CSV に残す
powershell -ExecutionPolicy Bypass -File .\Compare-Folder.ps1 -Reference D:\data -Difference E:\backup\data -Hash -IncludeSame

# ログと一時ファイルは比べない
powershell -ExecutionPolicy Bypass -File .\Compare-Folder.ps1 -Reference D:\app -Difference \\ap02\D$\app -Exclude "*.log,*.tmp,logs"

# 作業の前に、フォルダの状態を保存しておく
powershell -ExecutionPolicy Bypass -File .\Compare-Folder.ps1 -Reference D:\app -Snapshot

# 作業の後に、保存しておいた状態と今のフォルダを比べる
powershell -ExecutionPolicy Bypass -File .\Compare-Folder.ps1 -Reference .\FolderSnapshot_SERVER01_20261031_220000\snapshot.csv -Difference D:\app

# 結果を保存せず、画面表示だけにする
powershell -ExecutionPolicy Bypass -File .\Compare-Folder.ps1 -Reference D:\data -Difference E:\backup\data -NoSave
```

## パラメーター

| パラメーター | 内容 | 既定値 |
| --- | --- | --- |
| `-Reference` | 基準のフォルダ。ドライブ（`D:\`）や共有フォルダ（`\\server\share`）も指定できます。`-Snapshot` で保存したスナップショットのファイル（`snapshot.csv`）も指定できます | なし（必須） |
| `-Difference` | 比較するフォルダ | なし（`-Snapshot` のとき以外は必須） |
| `-Hash` | ファイルの内容を SHA-256 のハッシュで比べます。ファイルを最後まで読むため、時間がかかります（[比べ方](#比べ方)を参照） | なし（サイズと更新日時で比べる） |
| `-Exclude` | 比べないフォルダやファイル。ワイルドカード（`*`）で、`"*.log,logs,*\cache"` のようにカンマで区切って書きます（[除外の書き方](#除外の書き方)を参照） | 指定なし |
| `-IncludeSame` | 違いのなかったファイルとフォルダも、`differences.csv` に書きます | なし（違いだけを書く） |
| `-Snapshot` | `-Reference` のフォルダの状態を `snapshot.csv` に保存するだけで、比べません（[スナップショット](#スナップショット)を参照） | なし |
| `-OutputFolder` | 結果の保存先 | スクリプトと同じフォルダ |
| `-NoSave` | 結果を保存せず、画面表示だけにします。`-Snapshot` と一緒には使えません | なし |
| `-ConfigFile` | 設定ファイルのパス（[設定ファイル](#設定ファイル)を参照）。コマンドラインで指定した値は、設定ファイルより優先します | 指定なし |

`-Reference` と `-Difference` は、名前を省略して順に書くこともできます（`.\Compare-Folder.ps1 D:\data E:\backup\data`）。

### 除外の書き方

- `\` を含まない書き方は、フォルダ名・ファイル名に対して、どの階層でも当てはめます。`*.log` はすべての階層の `.log` ファイル、`logs` はすべての階層の `logs` フォルダ（と `logs` という名前のファイル）です
- `\` を含む書き方は、基準・比較それぞれのフォルダから見た相対パスに対して当てはめます。`logs\*` は直下の `logs` フォルダの中身、`*\cache` は 2 階層目より下の `cache` です。`\logs` のように先頭に `\` を付けると、直下の `logs` だけに当てはめます
- フォルダが除外に当てはまると、その中はすべて比べません
- 除外は、基準と比較の両方に同じように使います
- `*` 以外の文字（`[` `]` `?` など）は、そのままの文字として扱います。大文字と小文字は区別しません

## スナップショット

作業の前と後で同じフォルダを比べるときに使います。作業の前に、フォルダの状態（ファイルの一覧・サイズ・更新日時）をファイルに保存しておき、作業の後で今のフォルダと比べます。

1. 作業の前に、`-Snapshot` を付けて実行します。`-Hash` を付けると、ファイルのハッシュも保存します

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Compare-Folder.ps1 -Reference D:\app -Snapshot -Hash
   ```

2. 保存先に `FolderSnapshot_<ホスト名>_<日時>` というフォルダができ、その中に `snapshot.csv` を保存します。画面の最後に、作業の後で比べるためのコマンドを表示します
3. 作業の後で、`-Reference` に `snapshot.csv` を、`-Difference` に今のフォルダを指定して実行します

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Compare-Folder.ps1 -Reference C:\tools\FolderSnapshot_SERVER01_20261031_220000\snapshot.csv -Difference D:\app
   ```

- ハッシュを保存したスナップショットと比べるときは、`-Hash` を付けなくても内容まで比べます。ハッシュを保存していないスナップショットで `-Hash` を指定すると、エラーで止まります
- スナップショットを保存したときの `-Exclude` は、比べるときにも自動で使います。比べるときに `-Exclude` を指定すると、両方を合わせて使います
- 作業の前のスナップショットと、作業の後のスナップショットを比べることはできません。比べる側は、今のフォルダです
- `snapshot.csv` は Excel で開けますが、Excel で上書き保存すると、比べるときに読めなくなることがあります。手で直さないでください

## 設定ファイル

同じ条件で繰り返し比べるときは、パラメーターを設定ファイルにまとめておけます。設定ファイルを使わなくても、パラメーターだけで動きます。

```ini
# Compare-Folder の設定ファイル
# 「項目 = 値」の形で、1 行に 1 つずつ書きます。# か ; で始まる行はコメントです

Reference = \\old-fs\share\経理
Difference = \\new-fs\share\経理
Hash = true

# Exclude は、複数の行に分けて書けます（すべての行を合わせて使います）
Exclude = *.tmp
Exclude = Thumbs.db

IncludeSame = false
OutputFolder = .\記録
NoSave = false
```

- 書ける項目は、`Reference`、`Difference`、`Hash`、`Exclude`、`IncludeSame`、`OutputFolder`、`NoSave` です。`Snapshot` は書けません（同じ設定ファイルで、保存と比較の両方に使えるようにするためです）
- `Hash`、`IncludeSame`、`NoSave` は `true` か `false` で書きます
- コマンドラインで `-Exclude` を指定すると、設定ファイルの `Exclude` は使いません（両方を合わせることはしません）
- 設定ファイルで `true` にした `Hash`、`IncludeSame`、`NoSave` は、コマンドラインから取り消せません。元に戻したいときは、設定ファイルを直してください
- そのほかの書き方（空の値、引用符、コメント、環境変数、相対パス、文字コード）と、書き間違いがあったときの動きは、[Get-DiskUsage の設定ファイル](../Get-DiskUsage/README.md#設定ファイル)と同じです

`-Snapshot` で保存したときは、次のように表示します。

```

作業の後で、次のコマンドで比べられます:
powershell -ExecutionPolicy Bypass -File C:\tools\Compare-Folder.ps1 -Reference C:\tools\FolderSnapshot_SERVER01_20261031_220000\snapshot.csv -Difference D:\app
```

パスにスペースや `'` などが入っているときは、そのパスを `"` で囲んで表示します。`$` を含むパス（`\\server\share$` など）は、PowerShell で変数として読まれないよう `'` で囲みます（コマンドプロンプトに貼るときは、`'` を `"` に変えてください）。保存先の行と最後のコマンドは、`summary.txt` にも書きます。

表示の決まりは次のとおりです。

- 結果の行は「違いあり」「違いなし」のどちらかです。違いがなくても、読めなかった場所があるときは「違いなし（ただし、比べられなかった場所が 2 件あります。skipped.csv を確認してください）」と表示します
- 画面に表示する違いは 200 件までです。超えた分は「（ほか 1,234 件は differences.csv を参照してください）」と表示します。`-NoSave` のときと、保存できなかったときは、すべて表示します
- 件数は、ファイル・フォルダ・リンクを合わせた数です
- 調べている間と、ハッシュを計算している間は、進み具合を表示します
- 条件によって、次の行も表示します
  - `-ConfigFile` を指定したとき：比較の行の次に「設定ファイル: C:\tools\migrate.ini」
  - `-Hash` を指定したとき（ハッシュのあるスナップショットと比べたときも）：「比べ方: サイズと更新日時とハッシュ（SHA-256）」
  - `-Exclude` を指定したとき：「除外: *.log, logs」。除外したものがあれば、スキップの行に「除外 35 件」（基準と比較で除外したものの合計）
  - 「種類が違う」「日時のみ」があったとき：結果の行に「種類が違う 1 件」「日時のみ 15 件」
  - 権限なし以外のエラーでも読めなかった場所があったとき：「スキップ 3 件（権限なし 2・その他のエラー 1）」
  - 管理者として実行しておらず、読めない場所があったとき：「※ 管理者として実行すると、読める範囲が広がります」

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 違いがなかった（すべて比べられた）。`-Snapshot` で保存できたときも 0 |
| 2 | 違いがあった（追加・削除・変更・種類が違う）。「日時のみ」は違いに含めません |
| 1 | 引数の誤りなどで、比べる前に止まった。または、違いはなかったが、読めなかった場所がある |

違いがあって、読めなかった場所もあるときは 2 です。バッチファイルやタスクスケジューラから、「違いがあったら通知する」といった判定に使えます。

## 保存されるファイル

実行するたびに、保存先に `FolderDiff_<ホスト名>_<日時>`（`-Snapshot` のときは `FolderSnapshot_<ホスト名>_<日時>`）というフォルダを作り、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `summary.txt` | 画面に表示した内容（実行条件・件数・違い）。違いは 200 件を超えても省略しません |
| `differences.csv` | 違いの一覧（相対パスの順）。`-IncludeSame` を指定すると、違いのなかったものも書きます。`-Snapshot` のときは保存しません |
| `snapshot.csv` | フォルダの状態。`-Snapshot` のときだけ保存します |
| `skipped.csv` | 調べられなかった場所・調べなかった場所と、その理由 |

CSV は BOM 付き UTF-8 で保存するため、Excel でダブルクリックすればそのまま開けます。保存先に書き込めないときは警告を表示し、画面表示だけで終了します（`-Snapshot` のときは、エラーで止まります）。

### CSV の列

| ファイル | 列 |
| --- | --- |
| `differences.csv` | 結果、種類、相対パス、違い、基準のサイズ(バイト)、比較のサイズ(バイト)、基準の最終更新日時、比較の最終更新日時、基準のハッシュ、比較のハッシュ、備考 |
| `snapshot.csv` | 種類、相対パス、サイズ(バイト)、最終更新日時、ハッシュ、状態 |
| `skipped.csv` | 理由、側、パス、詳細 |

- 結果は「追加」「削除」「変更」「種類が違う」「日時のみ」「同じ」のどれかです
- 種類は「ファイル」「フォルダ」「リンク」のどれかです。「種類が違う」のときは「ファイル→フォルダ」のように、基準→比較の順で書きます
- 違いは、「変更」のときに「サイズ」「更新日時」「内容」を `・` でつないで書きます
- サイズは `156,723,000` のように 3 桁区切りで出力します（Excel で 12 桁を超える値が指数表示にならないように）
- ハッシュは、SHA-256 の値を大文字の 16 進数で書きます（PowerShell の `Get-FileHash` と同じ形です）。計算しなかったときは空欄です
- 備考は、「オンライン専用のためハッシュを計算していない」など、補足があるときに書きます
- 相対パスのうち、Excel で数値・日付・数式に変わるもの（`2026-10-31`、`001`、`-old` など）は、`="..."` の形で書きます。Excel ではそのまま表示されます
- `snapshot.csv` の先頭には、種類が「情報」の行で、保存したときのフォルダ・日時・時間帯・ハッシュの有無・除外を書きます。最終更新日時は保存した PC の現地時刻で書き、比べるときはその PC の時間帯で読み直します
- `snapshot.csv` の状態は、空欄か「権限なし」「その他のエラー」（中を読めなかったフォルダ）、「オンライン専用」「読めない」（ハッシュを計算しなかった・できなかったファイル）です。中を読めなかったフォルダは、比べるときに `skipped.csv` に載せ、その中は比べません
- `skipped.csv` の側は「基準」か「比較」です。理由は、「権限なし」「読めない」（ハッシュを計算するときにファイルを開けなかった）「除外指定」「その他のエラー」のいずれかです

## 比べ方

### 突き合わせ

- 基準と比較のそれぞれのフォルダから見た相対パスで、ファイルとフォルダを突き合わせます。大文字と小文字は区別しません（`Readme.txt` を `README.txt` に変えただけでは、違いになりません）
- 同じ相対パスで、片方がファイル、もう片方がフォルダのときは「種類が違う」とします。フォルダの側の中身は、1 つずつ「追加」か「削除」として出します
- フォルダは、あるかないかだけを比べます。フォルダの更新日時や属性は比べません
- 隠しファイルとシステムファイルも比べます

### ファイルの比べ方

| 比べ方 | 「変更」とするもの | 「同じ」とするもの |
| --- | --- | --- |
| 既定 | サイズか更新日時が違う | サイズと更新日時が同じ |
| `-Hash` | サイズかハッシュが違う | ハッシュが同じで、更新日時も同じ |

- 更新日時は、2 秒までの違いを同じとみなします（FAT32 や exFAT の USB メモリは、更新日時を 2 秒単位で記録するため）
- `-Hash` のとき、ハッシュは同じで更新日時だけが違うファイルは「日時のみ」とします。内容は同じなので、終了コードでは違いに数えません
- `-Hash` のとき、サイズが違うファイルは、内容が違うことが明らかなので、ハッシュを計算しません
- 既定の比べ方では、サイズと更新日時が同じで内容だけが違うファイル（ディスクの故障でファイルが壊れた場合など）は見つけられません。コピーが正しくできたかを確かめたいときは、`-Hash` を付けてください

### 飛ばすもの

- **リンク**：ジャンクションやシンボリックリンクはたどらず、「リンク」として、あるかないかだけを比べます。リンク先は比べません。無限ループや、同じファイルを二重に比べることを防ぐためです。OneDrive のフォルダは、リンクではなく普通のフォルダとして比べます
- **オンライン専用ファイル**：OneDrive などのオンライン専用ファイルは、`-Hash` を指定してもハッシュを計算しません（読むとダウンロードが始まるため）。サイズと更新日時で比べ、備考にそのことを書きます。そうしたファイルがあると、結果の下に「※ ハッシュで比べられなかったファイルが 3 件あります」と表示します（ハッシュのないスナップショットの行と比べたときも同じです）
- **読めないフォルダ**：権限がなくて読めないフォルダは飛ばして、件数を表示します。片方でも中を読めなかったフォルダは、その中を比べません（読めなかった中身が、すべて「追加」や「削除」に見えてしまうのを防ぐためです）
- **開けないファイル**：`-Hash` のときに、ほかのプログラムが使っていて開けないファイルは、飛ばして `skipped.csv` に残します
- **このツールの結果**：比べるフォルダの中に、このツールの結果のフォルダ（`FolderDiff_*` と `FolderSnapshot_*`）があっても、その中は比べません
- 260 文字を超える長いパスや、名前に `[` `]` を含むフォルダ・ファイルも比べます
- 途中で中断（Ctrl+C）した場合は、結果を保存しません

## 止まるとき

次の場合は、比べ始める前にエラーを表示して止まります（終了コード 1）。

| 場合 | 表示の例 |
| --- | --- |
| 基準か比較を指定していない | 「比較のフォルダを指定してください（-Difference で指定するか、設定ファイルの Difference に書きます）」 |
| 値に `"` が残っている（コマンドプロンプトで `"C:\data\"` のように最後を `\"` にした） | 「-Reference の値に引用符（"）が残っています: …」と、正しい書き方 |
| フォルダが見つからない・開けない | 「基準のフォルダを開けません: \\old-fs\share\経理」 |
| 基準と比較が同じ | 「基準と比較が同じフォルダです: D:\data」 |
| 片方がもう片方の中にある（`D:\data` と `D:\data\backup` など） | 「基準と比較の片方が、もう片方の中にあります。中にあるフォルダの中身が、すべて違いとして出てしまいます。」 |
| スナップショットのファイルとして読めない | 「スナップショットのファイルとして読めません: D:\memo.csv（Compare-Folder の -Snapshot で保存した snapshot.csv を指定してください）」。Excel で上書き保存して形が変わったときは、何行目かを表示します |
| ハッシュのないスナップショットで `-Hash` を指定した | 「このスナップショットにはハッシュがありません。-Hash を付けずに実行してください」 |
| `-Snapshot` と一緒に `-Difference` か `-NoSave` を指定した | 「-Snapshot のときは、-Difference は指定できません」。設定ファイルの `Difference` は、`-Snapshot` のときは使わずに続けます（同じ設定ファイルを保存にも使えるように）。設定ファイルの `NoSave = true` は、何行目かを添えて止めます |
| `-Snapshot` で、`-Reference` にスナップショットのファイルを指定した | 「-Snapshot のときは、-Reference にフォルダを指定してください」 |
| 設定ファイルの書き間違い | 何行目かを表示します（Get-DiskUsage と同じ） |

ネットワークドライブ（`Z:`）とその共有フォルダ（`\\server\share`）のように、同じ場所を別の名前で指定した場合は、「基準と比較が同じ」を判定できません。

## 共有フォルダを比べるとき

- `\\サーバー名\共有名` の形で指定してください。管理者として開いた PowerShell からは、通常の権限で割り当てたネットワークドライブ（`Z:` など）が見えないことがあります
- 実行したユーザーの権限で読みます。読めない場所は飛ばします
- `-Hash` を付けると、両方のファイルをネットワーク越しに最後まで読むため、時間がかかります。サーバーにログオンできる場合は、片方のサーバーの上で `-Snapshot -Hash` を実行してスナップショットを保存し、その `snapshot.csv` ともう片方のフォルダを比べる方法もあります（読むのは、もう片方のファイルだけになります）。スナップショットには保存した PC の時間帯を書いておくので、時間帯の設定が違う PC で比べても、更新日時はずれません

## 使うときの注意

- **ファイル名の文字の違い**：Mac から保存したファイル名などで、見た目は同じでも内部の文字の表し方（濁点を 1 文字で表すか、2 文字で表すか）が違うと、別の名前として「追加」と「削除」に出ます
- **大文字と小文字だけの変更**は、違いとして出ません
- **大文字と小文字を区別するフォルダ**（WSL で設定したフォルダなど）で、`a.txt` と `A.txt` のように大文字と小文字だけが違う名前が並んでいるときは、後から読んだほうを比べずに `skipped.csv` に「その他のエラー」として残します
- **アクセス権・所有者・属性**は比べません
- **フォルダの一覧をメモリに読み込む**ため、ファイルが多いとメモリを多く使います。ドライブ全体など数十万件を超えるときは、フォルダを分けて実行してください
- 比べている間に書き換えられたファイルは、「変更」として出ることがあります。ログなど、書き込みが続くファイルは `-Exclude` で除いてください
