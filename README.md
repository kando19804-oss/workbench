# workbench

Windows のサーバーやクライアントを扱う SE・運用担当向けの PowerShell スクリプト集です。調査や作業記録を、コマンド1本で済ませられるようにします。

Windows 11 の初期状態のまま、インストールも設定変更もせずに使えることを目指しています。

## 特長

- **追加インストール不要**：OS に最初から入っている Windows PowerShell 5.1 だけで動きます。外部モジュールは使いません
- **オフラインで動く**：インターネット接続は不要です。閉域網でも使えます
- **1ファイルで完結**：設定ファイルは不要です。USB や共有フォルダでそのまま配れます
- **結果を残せる**：画面表示に加えて CSV（BOM 付き UTF-8）で出力でき、Excel でそのまま開けます
- **途中で止まらない**：権限のない場所はスキップし、スキップした件数を表示します

## システム要件

| 項目 | 要件 |
| --- | --- |
| OS | Windows 11、Windows 10（バージョン 1607 以降）<br>Windows Server 2016 / 2019 / 2022 / 2025 |
| PowerShell | Windows PowerShell 5.1（OS 標準） |
| .NET Framework | 4.6.2 以降（上記 OS の標準） |
| 外部モジュール | 不要 |
| インターネット接続 | 不要 |
| 管理者権限 | 原則不要（必要なツールは各ツールの README に記載） |

PowerShell 7 でも動くように作っています。公開前に、Windows PowerShell 5.1 と PowerShell 7 の両方で動作を確認しています。

### 対象外の環境

- **Windows Server 2012 R2 以前**：標準の PowerShell が 4.0 以下のため対象外です
- **グループポリシーで実行ポリシーが指定されている環境**：下記「使い方」の `-ExecutionPolicy Bypass` が効きません
  - `RemoteSigned` が指定されている場合は、ファイルのブロックを解除すれば実行できます（後述）
  - `AllSigned` または `Restricted` が指定されている場合は実行できません
- **AppLocker や WDAC でスクリプトの実行が制限されている環境**：制約付き言語モードになるため、一部のツールが動かない場合があります

## 使い方

Windows 11 の初期状態では、スクリプトの実行が禁止されています（実行ポリシーが `Restricted`）。そのため、次のコマンドで起動してください。

```powershell
powershell -ExecutionPolicy Bypass -File .\<ツール名>.ps1
```

- `-ExecutionPolicy Bypass` は、この実行のときだけ有効です。PC の設定は変わらず、管理者権限も不要です
- コマンドプロンプトと PowerShell のどちらからでも、同じコマンドで起動できます
- オプションは、各ツールの README またはスクリプト冒頭の説明を参照してください

### ブロックを解除して実行する場合

グループポリシーで `RemoteSigned` が指定されている環境では、ダウンロードしたファイルのブロックを解除してから実行してください。

```powershell
Unblock-File .\<ツール名>.ps1
.\<ツール名>.ps1
```

エクスプローラーでファイルを右クリックし、「プロパティ」の「許可する」にチェックを入れても解除できます。
