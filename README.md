# workbench

Windows のサーバーやクライアントを扱う SE・運用担当向けの PowerShell スクリプト集です。調査や作業記録を、コマンド1本で済ませられるようにします。

Windows 11 の初期状態のまま、インストールも設定変更もせずに使えることを目指しています。

## 特長

- **追加インストール不要**：OS に最初から入っている Windows PowerShell 5.1 だけで動きます。外部モジュールは使いません
- **オフラインで動く**：インターネット接続は不要です。閉域網でも使えます
- **1ファイルで完結**：設定ファイルは不要です。USB や共有フォルダでそのまま配れます
- **結果を残せる**：画面表示に加えて CSV（BOM 付き UTF-8）で出力でき、Excel でそのまま開けます
- **途中で止まらない**：権限のない場所はスキップし、スキップした件数を表示します

## システム要件

| 項目 | 要件 |
| --- | --- |
| OS | Windows 11、Windows 10（バージョン 1607 以降）<br>Windows Server 2016 / 2019 / 2022 / 2025 |
| PowerShell | Windows PowerShell 5.1（OS 標準） |
| .NET Framework | 4.6.2 以降（上記 OS の標準） |
| 外部モジュール | 不要 |
| インターネット接続 | 不要 |
| 管理者権限 | 原則不要（必要なツールは各ツールの README に記載） |

PowerShell 7 でも動くように作っています。公開前に、Windows PowerShell 5.1 と PowerShell 7 の両方で動作を確認しています。

### 対象外の環境

- **Windows Server 2012 R2 以前**：標準の PowerShell が 4.0 以下のため対象外です
- **グループポリシーで実行ポリシーが指定されている環境**：下記「使い方」の `-ExecutionPolicy Bypass` が効きません
  - `RemoteSigned` が指定されている場合は、ファイルのブロックを解除すれば実行できます（後述）
  - `AllSigned` または `Restricted` が指定されている場合は実行できません
- **AppLocker や WDAC でスクリプトの実行が制限されている環境**：制約付き言語モードになるため、一部のツールが動かない場合があります

## 使い方

Windows 11 の初期状態では、スクリプトの実行が禁止されています（実行ポリシーが `Restricted`）。そのため、次のコマンドで起動してください。

```powershell
powershell -ExecutionPolicy Bypass -File .\<ツール名>.ps1
```

- `-ExecutionPolicy Bypass` は、この実行のときだけ有効です。PC の設定は変わらず、管理者権限も不要です
- コマンドプロンプトと PowerShell のどちらからでも、同じコマンドで起動できます
- オプションは、各ツールの README またはスクリプト冒頭の説明を参照してください
- パスを引用符で囲むときは、最後に `\` を付けないでください（例: `-Path "C:\data"`）。`"C:\data\"` のように最後が `\"` になると、後ろの引数までパスとして扱われます

### ブロックを解除して実行する場合

グループポリシーで `RemoteSigned` が指定されている環境では、ダウンロードしたファイルのブロックを解除してから実行してください。

```powershell
Unblock-File .\<ツール名>.ps1
.\<ツール名>.ps1
```

エクスプローラーでファイルを右クリックし、「プロパティ」の「許可する」にチェックを入れても解除できます。

## ツール一覧

| ツール | 内容 |
| --- | --- |
| [Get-DiskUsage](tools/Get-DiskUsage/)（容量検索） | 容量を多く使っているフォルダ・ファイル・拡張子を洗い出し、CSV に保存します。条件は設定ファイルにまとめておけます |
| [Get-FolderTree](tools/Get-FolderTree/)（フォルダツリー出力） | フォルダの構成を、罫線を使ったツリーのテキストで出力します。階層の深さや除外を指定でき、フォルダの合計サイズも添えられます。設計書や手順書にそのまま貼れます |
| [Backup-Folder](tools/Backup-Folder/)（フォルダのバックアップ） | フォルダの中身を USB メモリや別のドライブへ差分でコピーします。コピーする件数と容量を確かめてからコピーし、結果を CSV に残します。ダブルクリック用の起動ファイルも作れます |
| [Test-Connectivity](tools/Test-Connectivity/)（疎通一括確認） | 複数のサーバーについて、名前解決・ping・TCP ポートへの接続を一度に確かめ、結果を CSV に残します。対象は Excel で作った CSV にまとめておけます。確かめ続けて、つながる・つながらないが変わった時刻を記録することもできます |
| [Get-PortProcess](tools/Get-PortProcess/)（ポート使用プロセス特定） | 指定したポートを使っているプロセスを、サービス・実行ユーザー・実行ファイルと一緒に突き止めます。ポートを指定しなければ、待ち受けているすべてのポートを一覧にして、CSV に残します |
| [Search-Log](tools/Search-Log/)（ログ横断検索） | 複数のログファイルから、指定した文字列を含む行を、前後の行と一緒に探し出してテキストと CSV に残します。ログの文字コード（UTF-8・Shift_JIS・UTF-16）はファイルごとに自動で判定し、書き込み中のログも読めます |
| [Compare-Folder](tools/Compare-Folder/)（フォルダ差分） | 2 つのフォルダを比べて、追加・削除・変更されたファイルとフォルダを一覧にし、CSV に残します。ハッシュ（SHA-256）で内容まで比べられます。作業の前にフォルダの状態を保存しておき、作業の後に比べることもできます |
| [Export-TaskList](tools/Export-TaskList/)（タスクスケジューラ出力） | タスクスケジューラに登録されているタスクを、いつ・誰の権限で・何を動かすか・前回の結果と一緒に一覧にし、CSV に残します。各タスクを取り込み直せる XML も保存するので、サーバーの引き継ぎや移行の資料に使えます |
| [Convert-TextEncoding](tools/Convert-TextEncoding/)（文字コード判定・変換） | フォルダの中のテキストファイルの文字コード（UTF-8・Shift_JIS など）と改行（CRLF・LF）を判定して一覧にし、CSV に残します。指定すれば、確認したうえでまとめて変換します。元のファイルは控えておくので、元に戻せます |
| [Search-EventLog](tools/Search-EventLog/)（イベントログ抽出） | 指定した期間のイベントログから、エラーなどのイベントを取り出し、どのイベントが何回出ているかを集計して、CSV に残します。レベル・イベント ID・ソース・メッセージの文字で絞り込めます。ほかのサーバーから集めた .evtx ファイルも読めます |

## テスト（開発者向け）

ツールを変更したら、次のコマンドで回帰テストを実行してください。

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\Invoke-Tests.ps1
```

- 各ツールを、Windows PowerShell 5.1 と PowerShell 7（入っている場合）の両方で、ダミー環境に対して実行し、期待値と照合します。失敗した項目があると、終了コードが 1 になります
- ダミー環境は一時フォルダに作り、終了時に削除します
- 「権限なし」を再現するため、テストが作ったフォルダにだけアクセス拒否を設定します（終了時に元に戻します）
- 一部のテストは、このPCの `C:\Users`・`C:\`・管理共有（`\\localhost\C$`）を読み取ります。読めない環境では、そのテストを飛ばします
- Backup-Folder のテストは、ドライブのルートを再現するため、空いているドライブ文字を `subst` で一時的に割り当てます（終了時に外します）。FAT32 のドライブがつながっているときは、そのドライブに対して一覧だけを確かめます（書き込みはしません）
- 管理者として実行すると、robocopy がアクセス拒否を越えて読むため、Backup-Folder の「読めないフォルダ」のテストは飛ばします
- Test-Connectivity のテストは、この PC の中（`127.0.0.1` と `::1`）だけで一時的にポートを待ち受けます。「タイムアウト」の確認には、どこにもつながらない文書用のアドレス `192.0.2.1` への接続を使います（応答が返るネットワークでは、そのテストを飛ばします）
- Get-PortProcess のテストは、待ち受けるだけの PowerShell を別に起動し、この PC の中（`127.0.0.1` と `::1`）だけで一時的にポートを待ち受けます（終了時に止めます）。このPCで待ち受けているサービスのポートも読み取ります
- Search-Log のテストは、Ctrl+C で止める確認のため、一時フォルダに約 110 MB のダミーのログを作ります（終了時に削除します）。リンクの確認のため、テストが作ったフォルダにジャンクションを作ります
- Compare-Folder のテストは、Ctrl+C で止める確認のため、`C:\Windows\System32` と `C:\Windows\SysWOW64` をハッシュで比べ始め、5 秒後に止めます（読み取りだけです）。「大文字と小文字を区別するフォルダ」の確認のため、テストが作ったフォルダにだけ、その設定（`fsutil file setCaseSensitiveInfo`）をします。`C:\Users\Default` の互換用リンクも読み取ります
- Export-TaskList のテストは、タスクスケジューラにテスト用のフォルダ（`\workbench-tests\`）とタスクを登録し、終了時に削除します。ルート（`\`）にも、名前に目印（`-wbt_ET_` と日時）を付けたタスクを 1 つだけ登録します。トリガーは 2099 年などにしてあり、勝手には動きません。前回の結果を作るため、終了コードを返すだけの VBScript を `wscript.exe` で実行します（窓は出ません）。起動時のトリガーや SYSTEM のタスクなど、管理者でないと登録できないものは、管理者のときだけ確かめます
- Convert-TextEncoding のテストは、一時フォルダに文字コードの違うダミーのファイル（100 MB を超えるファイル 2 つを含む）を作り、判定と変換を確かめます（終了時に削除します）。確認の入力を試すため、画面に「変換しますか？」が何度か出ます（5.1 の Read-Host は確認の文を画面に直接書くため）。Ctrl+C の確認のため、見えないコンソールでツールを動かし、そのコンソールの入力に Ctrl+C のキーを書き込みます（`AttachConsole` と `WriteConsoleInput`）
- Search-EventLog のテストは、テスト用のイベントを持つ .evtx ファイルを一時フォルダに組み立てて確かめます。本物のイベントログには書き込みません（System・Application・Security などを読むだけです）。Ctrl+C の確認のため、同じ .evtx のコピーを 200 個（約 65 MB）作ります。ドライブのルートの確認のため、空いているドライブ文字を `subst` で一時的に割り当てます（終了時に外します）。リンクの確認のため、テストが作ったフォルダにジャンクションを作ります
